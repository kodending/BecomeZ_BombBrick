# 정령사슴 4등급: 수호정령 강림

전투 시작 즉시 아군 전체에 모든 디버프·군중제어·강제 이동 면역을 부여한다. 시전자 사망 후에도 전투 종료까지 유지하며, 나중에 합류한 아군도 보호한다. 일반 피해·사망은 그대로 처리하고 선택한 3등급 스킬도 계속 사용한다. 동일 팀에 여러 시전자가 있어도 정령은 하나만 생성한다. 양 팀 모두 사용하면 색상과 부유 위치를 구분한다.

기존 영겁의 성역의 스킬 사용마다 추가 성역 생성, 회복 증폭, 초과 회복 보호막, 1회 죽음 방지는 제거했다. 저장 호환성을 위해 trait_transcend_spirit_deer_eternal_sanctuary ID는 유지한다.

## 구현

- MonsterAutoBattleSpiritGuardian.cs: 전투 소유 팀 보호 상태. BeginCurrentBattleImmediately에서 전투 시작 증강·지역 효과·천지전복보다 먼저 시작한다. SpawnUnitModel에서 신규 아군에게도 보호 콜백을 연결한다.
- CombatStatusRuntime.cs: 외부 디버프 면역을 임시/개인 면역과 합산한다. 개인 면역의 복구가 외부 면역을 복사하지 않도록 분리한다.
- 별도 타이머로 처리하는 도발·공속/이속 감소·능력치 감소·회복 방해·화상·태양 표식·쿨타임 방해·기생 왕관 등에도 면역을 적용했다. 강제 이동과 전장 퇴출을 차단한다. 0초 쓰러짐은 애니메이션을 시작하지 않는다.
- PixelSpiritGuardian.cs: 새로 그린 여신의 16프레임 스프라이트를 초당 10프레임으로 재생한다. 2.4초 동안 하늘에서 내려와 화면 상단 뒤편에서 부유한다. 흰색·금색·청록 예복, 약 46% 불투명도로 배경이 비치고 전투 개체와 공격은 여신보다 앞에 그려진다. 전장 전체로 손끝의 금빛 입자가 내려오며 면역 차단 피드백도 금빛으로 통일했다. 모든 움직임은 전투 시계를 따른다.
- LayeredBattleEnvironment.cs: 분리된 배경에서는 배경과 전투 플랫폼 사이의 그리기 순서를 사용한다. 한 장으로 합쳐진 테스트 배경에서는 GuardianVeil.shader가 원화의 전투 플랫폼 뒤쪽 경계 아래를 가려 같은 공간감을 만든다. 기존 전장·배경 이미지와 바닥 그림자는 수정하지 않는다.
- CombatEffects/SpiritDeer/GuardianGoddess16.png: 내장 image_gen으로 생성한 신규 원화를 96×128픽셀 16칸 아틀라스(384×512)로 준비했다. 최근접 샘플링·Point 필터·무압축·투명 알파를 사용한다. 원본과 최종 생성 프롬프트는 Logs/SpiritDeerGuardian/Goddess에 보관한다.
