# BombBrick UI / UX 공통 규격

## 시각 언어

- 배경은 청흑색, 콘텐츠 표면은 한 단계 밝은 남청색을 사용한다.
- 청록은 정보와 탐색, 라임은 선택 완료와 확정, 주황은 위험·초월, 보라는 특수 규칙을 뜻한다.
- 큰 회색 컨테이너보다 독립된 카드와 충분한 여백을 우선한다.
- 외곽선은 기본 1px, 호버·선택은 2px로 제한한다.

## 타이포그래피

- Display: 24px Bold
- Card title: 20~22px Bold
- Body: 14~16px
- Caption / Badge: 11~12px
- 제목과 효과 설명은 명확히 분리하고, 긴 설명은 좌측 정렬한다.

## 간격

- XS 4px / SM 8px / MD 16px / LG 24px / XL 32px
- 카드 내부 기본 여백은 16px 이상으로 유지한다.
- 세 선택지는 16~24px 간격으로 분리한다.

## 입력과 피드백

- 시각적으로 하나인 카드는 카드 전체를 입력 영역으로 사용한다.
- 호버 시 2~7px 상승과 외곽선 변화만 사용한다.
- 확정 상태는 라임 외곽선으로 통일한다.
- 대상이 필요한 선택은 별도 하단 트레이로 분리한다.
- 취소 가능한 드래그는 임계거리 이전 해제 시 원위치한다.

## 모션

- 마이크로 피드백: 0.12~0.2초
- 카드 등장: 0.4~0.55초
- 카드 간 순차 지연: 0.08~0.12초
- 화면 전환: 최대 0.76초
- EaseOutCubic을 기본으로 사용하고, 핵심 보상 카드에만 약한 EaseOutBack을 허용한다.
- 무한 반복 발광과 큰 바운스는 사용하지 않는다.

## 모달 구조

1. 전체 화면 감광
2. Eyebrow / 제목 / 짧은 강조선
3. 핵심 선택 콘텐츠
4. 필요할 때만 대상 지정 트레이
5. 하단 보조 행동과 오류 메시지

구현 기준은 `Assets/Prototype/BombBrickUiTheme.cs`를 단일 소스로 사용한다.
