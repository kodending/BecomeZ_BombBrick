# 닌자 고양이 기본 스킬 — 통나무 바꿔치기

사용자 요청: 닌자다운 통나무 바꿔치기와 출현 후 날카로운 베기. 대상 선택·피해·기본 쿨타임은 기존 값을 유지한다. 3등급 리뉴얼은 다음 작업이다.

- 그림자 사냥 시작 후 0.10초 본체 소실/픽셀 연막 → 0.18초 출발 위치에 통나무가 ‘푱’ 등장 → 0.32초 현재 대상 위치를 기준으로 겹치지 않는 반대편 공격 위치에 본체 출현. 소실과 통나무 등장을 별도 콜백으로 나누어 빈 자리 0.08초, 통나무 단독 0.14초를 보여준다.
- 통나무는 기존 48×48/9색 Aseprite 도트를 사용한다. 등장 첫 0.05초 납작한 자세에서 세로로 튀고 0.13초까지 원래 비율로 복원. 자주색 외곽선의 크림색 픽셀 연막과 위쪽 짧은 만화식 강조선 5개를 사용한다. 출현에도 짧은 연막과 계열색 강조선을 사용하며, 본체 스프라이트 배율은 유지한다.
- 사용자 추가 조정: 연막 한 조각의 가로/세로 크기를 각각 50%로 축소. 소실 6→8개, 통나무 7→10개, 재등장 5→7개로 소폭 증량. 통나무·강조선 크기 및 단계별 타이밍 유지. 마지막 크기/개수 조정은 Unity 재컴파일 확인, 콘솔 오류/경고 0; 아래 4종 녹화는 크기 축소 전 순서 검증 기록이다.
- 0.40초에 실제 스킬 타격 프레임으로 1회 피해. 0.03초 타격 자세 유지 후 0.61초까지 회수 동작. 기존 6개 스킬 프레임과 프로필별 스프라이트 크기를 사용한다. 시간은 일반 속도 기준이며 전역 애니메이션 속도 보정 적용.
- 통나무는 소품이며 별도 AI·어그로·충돌이 없다. 작게 튀어 오른 후 기울어져 쓰러지고 1.05초 내 정리된다. 캐릭터 이미지의 투명 여백을 감안해 크기를 보정했다.
- 이동 연결선 대신 대상 몸에 짧고 끝이 가는 곡선 칼날, 흰 접촉 섬광, 픽셀 파편, 시각적 피격 반동을 사용한다. 카메라 줌·전역 시간 배율 변경 없음.
- 춘동이 은백/금빛, 설묘 청백, 순동이 녹색, 홍련 주홍. 춘동이 기존 추가 2타는 최초 베기 후 0.06초 간격으로 각각 72% ATK(60%×평타 강화 1.2)를 적용한다. 지연 중 대상/본체 사망·재시전·강제 위치 변경·전투 종료 시 남은 타격 취소. ML/스프라이트 없는 경로는 기존 즉시 2타 유지.
- 홍련의 출발·도착 지점 기존 55% ATK/1.25타일 효과는 유지하며, 붉은 본체 실루엣이 불티로 흩어지는 연출을 사용한다. 설묘 냉기, 순동이 독/치유 감소는 기존 규칙 유지.
- 바꿔치기 소실 시작부터 대상 지정 불가 0.25초와 기존 적 타겟 해제. 준비/타격 전 대상 소실 시 취소. 숨은 도중 사망·비활성화·초기화·취소는 원래 렌더 상태로 복구. 빙결은 현재 프레임을 보이게 유지하고 동작/피해 시계를 함께 정지한다.
