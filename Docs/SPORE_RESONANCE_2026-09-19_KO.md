# 버섯 3등급 1번: 포자 공명

## 동작

- 기존 지하 균사왕국을 포자 공명으로 교체. 저장된 특성 ID는 유지한다.
- 기본 포자 발사체가 도착하면 반경 2타일, 4초 가스 생성. 기본 가스 피해와 종 고유효과 유지.
- 시전자 포함 같은 팀의 기본 공격이 가스 안의 적에게 적중하면 0.08초 수축 후 공명 폭발.
- 적중 위치 중심 반경 1타일과 해당 가스 영역이 겹치는 범위의 적에게 버섯 시전자 ATK 40% 피해. 폭발 시점의 위치로 판정한다.
- 동일 시전자 가스 전체에서 0.7초 발동 간격 공유. 각 기본 스킬 시전의 가스는 최대 6회 발동. 기존 4등급의 메아리 가스는 추가 공명을 발동하지 않는다.
- 기본 공격에 의한 처치와 보호막 적중도 발동. 스킬·지속 피해·공명 폭발은 발동하지 않는다.
- 가스 종료 전에 예약된 폭발은 마무리하며, 종료 후에는 새 발동을 받지 않는다. 시전자 사망·전투 초기화에는 예약 폭발도 취소한다.
- 종 고유효과 제외, 한 적이 기본 가스 8회(160%)와 공명 6회(240%)를 모두 맞으면 총 ATK 400%.

## 연출

가까운 가스 입자가 적중 위치로 0.08초 수축한다. 중심이 짧게 밝아진 뒤 28개 도트 포자 덩어리가 1타일 안쪽부터 불규칙하게 튀어나간다. 빠른 확산 후 감속·소멸하며 원래 가스에 섞인다. 실제 피해 대상에는 밝은 포자 Hit와 짧은 반동·타격음을 적용한다.
기본 가스는 캐릭터 앞의 낮은 불투명도를 유지하고 모든 주요 연출은 가스 전투 시계를 따른다.
