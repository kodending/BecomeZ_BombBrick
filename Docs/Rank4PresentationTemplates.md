# 4등급 필살기 연출 템플릿과 골개비 설계안

## 스프라이트 이펙트 제작 기준 — 2026-10-24 사용자 지시

모든 스프라이트 기반 이펙트는 서로 다른 그림 최소 4프레임을 실제 런타임에서 재생한다. 한 장의 위치·크기·회전·알파만 바꾸거나, 서로 다른 정적 변형 4개를 나열한 것은 애니메이션 4프레임으로 세지 않는다. 준비→변형→명중→잔여처럼 형태가 연결되어야 한다.

프레임 애니메이션에 입자·메시·빛·몸체 반동·카메라 반응을 조합할 수 있다. 실제 명중 순간에 주된 효과가 집중되고 보조 효과가 이를 가리지 않도록 크기·색·시간을 맞춘다. 배경과 고정 접지 그림자는 이펙트 애니메이션과 구분한다. 새 제작·교체부터 적용하고, 기존 전체 계열이 이미 이 기준을 충족한다고 간주하지 않는다.

4등급마다 주목을 끄는 방식과 대표 동작을 다르게 만든다. 확대와 전용무대는 각성에 어울리는 선택지로 남기고, 다른 계열은 전장 현상, 그래픽 컷인, 거대한 형상, 화면 밖의 위협, 동작의 리듬으로 구분한다. 아래 참고 사례와 초기 후보는 2026년 10월 22일 논의 기록이다. 골개비의 최종 선택과 구현은 다음 절을 따른다.

## 골개비 확정 콘티와 구현

사용자가 전장 고정 구도의 새총 안 대신 승인한 콘티는 [하늘에 매달린 전장 4컷](Concepts/FrogRank4/Golgaebi_CaptiveSky_Cinematic_4Panel_v1.png)이다. 같은 전장을 적의 눈높이, 공중 부감, 골개비 발밑의 낮은 시점, 적이 렌즈를 덮는 투척 시점으로 이어간다. 고정된 숲 전용무대를 추가하지 않는다.

`FrogCatchCinematicStage`는 현재 지역에 맞는 전용 지면과 투명 파노라마를 각각 사용한다. `Environments/Floors/`는 원근 없는 정사각 지면만 담고, `Environments/Panoramas/`는 하단이 수풀·바위·건축물의 불규칙한 실루엣을 따라 투명해지는 풍경을 담는다. 두 이미지를 가로로 나눈 아틀라스는 런타임에 사용하지 않는다. 수평 지면, 뒤쪽 곡면 풍경, 가까운 자연물과 약한 거리 안개를 겹쳐 낮은 시점과 공중 시점의 원근을 만든다. 풍경의 원본 비율을 유지하고 뿌리를 지면 아래에 묻어 직선 접합부가 드러나지 않게 한다.

시전자와 실제 포획에 성공한 적, 나머지 생존 몬스터의 외형·방향·색상·크기·전장 위치를 넘겨받아 별도 렌더 카메라에서 연출한다. 사망하거나 제어 면역으로 잡히지 않은 적은 공중 포획 대상에 포함하지 않는다. 변신한 적은 현재 변신 외형을 보존한다. 골개비·킹파·록록·프로스크 일반색은 각 개체의 외형으로 ImageGen 제작한 네 포즈를 포획·버티기·힘주기·투척 순서로 사용한다. 발과 몸 폭을 정규화하고 새 포즈마다 측정한 입 위치에 혀를 붙인다. 이로치는 실제 열린 입 스프라이트와 색상을 유지하며 몸체 동작으로 힘주기와 투척을 표현한다. 짧은 기본 스킬 루프나 입이 닫히는 복귀 프레임은 반복하지 않는다. 혀는 `TongueRibbonV2.png`의 픽셀 질감을 탄력 곡선에 입히고, 뿌리와 끝의 두께를 달리하며 실제 잡힌 적에게 감기는 띠를 붙인다.

| 시간(실시간) | 연출 |
|---|---|
| 0.00~0.85초 | 적의 시점에서 먼 골개비를 바라보며 렌즈 가장자리로 혀가 감긴다. |
| 0.85~1.95초 | 공중 시점으로 올라가 실제 잡힌 적들과 아래 전장을 보여준다. |
| 1.95~3.05초 | 낮은 시점에서 골개비의 버티기·힘주기, 입에서 이어진 혀와 작은 먼지 반응을 보여준다. |
| 3.05~4.00초 | 몸을 비틀어 던지고 실제 적 하나가 렌즈를 덮으며 전장 낙하로 이어진다. |

초타가 적중한 기존 시전 상태를 보존한 채 연출 동안 전투 시계만 정지한다. 마지막 가림 구간에서 같은 시전을 투척 시작인 1.24초 상태로 이어 주고, 실제 전장의 1.45초 낙하 적중으로 마친다. 스킬을 새로 시전하지 않으므로 비용·초타·통계가 이중 적용되지 않는다. 피해량과 쿨타임, 기존 제어·착지 판정은 유지한다.

아군과 적군 모두 몬스터별 웨이브 최초 포획에 긴 연출을 보여준다. 이후 시전은 기존 전장 동작을 사용한다. 다른 4등급 연출과 동시에 시계를 소유하지 않도록 대기시키며, 일시정지·시전자 사망·웨이브 초기화·씬 종료 시 카메라와 속도, 가시성을 복구한다. 포획 상태가 중간에 무효화되면 연출을 정리하고 실제 시전의 제어 해제로 돌아간다.

## 템플릿 8종

다음 템플릿과 적용 예시는 위 사례를 바탕으로 만든 우리 게임용 제안이다. 다른 게임에 아래 이름이나 같은 연출이 존재한다는 뜻은 아니다. 계열 배정도 아직 확정하지 않는다.

| 방식 | 주목시키는 방법과 대표 장면 | 연결 방식 | 어울리는 예시 |
|---|---|---|---|
| 전장 안 연속 액션 | 발을 박고 버티기, 당기기, 던지기를 하나의 큰 동작으로 읽히게 한다. 적의 몸체 반응이 중심이다. | 원래 위치에서 시작해 실제 착지까지 한 화면으로 연결 | 골개비의 공중 포획과 팔방 투척 |
| 전장 현상 | 낙엽과 돌이 먼저 떠오르거나, 바닥에 전류가 번지는 등 힘의 전조가 전장 전체로 퍼진다. | 전조가 실제 공격 범위에 모인 뒤 한 번에 해방 | 중력, 폭풍, 낙뢰 계열 |
| 만화 분할 컷 | 눈, 발, 적의 반응을 좁은 패널로 교차하고 한 장의 강한 실루엣으로 절정을 만든다. | 패널의 움직임 방향이 실제 공격 궤적으로 이어짐 | 닌자, 검격, 빠른 연속 공격 |
| 거대한 상징 형상 | 본체 옆이나 뒤에 턱, 발톱, 수호신 같은 큰 형상이 나타나 본체의 동작을 완성한다. | 본체와 형상의 타격이 실제 명중 순간에 일치 | 검치의 네온 턱, 수호자 계열 |
| 화면 밖의 위협 | 무언가 위로 사라지고 그림자와 바람만 남는다. 잠깐의 기대 후 화면 안으로 강한 일격이 들어온다. | 시선은 전장에 둔 채 그림자와 소리로 귀환을 예고 | 와이번 낙하 공격, 맘모스 투석 |
| 표식 후 일제 발동 | 여러 적에게 연결선이나 인장이 차례로 생기고, 마지막 하나가 닫히는 순간 모두 반응한다. | 표식 설치가 발동 이유를 설명하고 실제 적중으로 연결 | 거미의 실, 마법쥐의 주문 |
| 리듬으로 쌓는 연속 공격 | 짧은 타격들을 점점 촘촘하게 쌓고, 마지막 한 번만 큰 정지 포즈와 충격을 준다. | 실제 타격 순서에 맞춰 동작과 음향을 이어감 | 늑대 추격, 랩터 연속 사냥 |
| 변신과 각성 무대 | 실루엣 자체가 달라지고 새 기관이나 오라가 생기는 과정을 충분히 보여준다. | 마지막 자세와 오라를 전장의 자세로 연결 | 이미 제작한 랩터 각성 |

전장을 유지하는 방식은 새 배경 제작 부담이 적지만 본체와 적의 동작이 분명해야 한다. 만화 컷은 전용 그림과 패널 연결이 필요하고, 거대 형상은 본체와 따로 움직이는 애니메이션이 필요하다. 전용무대는 배경 레이어와 전후 연결까지 제작해야 하므로 실제 변신처럼 볼 이유가 있는 계열에 우선 사용한다.

## 템플릿 선택 기준

1. 각 계열을 한 문장의 행동으로 설명한다. 골개비는 붙잡아 던지기, 검치는 물어 닫기, 랩터는 각성 후 사냥하기다.
2. 먼저 절정에서 남길 한 장면을 정한다. 같은 눈 확대, 포효, 금색 폭발을 모든 계열의 절정으로 쓰지 않는다.
3. 하나의 연출에는 주된 방식 하나와 보조 방식 하나까지만 조합한다. 컷인과 무대, 거대 형상, 표식이 모두 경쟁하지 않게 한다.
4. 준비, 명중, 후속 결과의 모양과 소리를 구분한다. 가장 큰 충격은 실제 명중과 맞춘다.
5. 실제 영향을 받는 적을 보여준다. 보호막이나 제어 면역으로 잡히지 않은 적을 연출에서만 끌고 오지 않는다.
6. 긴 연출의 최초 재생 범위, 반복 시 축약 여부, 여러 4등급 동시 발동 처리는 계열 콘티와 함께 합의한다. 이번 문서에서 새 공통 규칙을 확정하지 않는다.

## 골개비 새 설계안

### 콘셉트

작은 골개비 한 마리가 적 전원을 팽팽한 혀줄에 매달고, 거대한 새총을 튕기듯 사방으로 내던진다. 스킬 이름은 기존 만물 낚시를 유지한다. 연출의 중심은 골개비의 얼굴 확대보다 작은 몸이 전장 전체를 붙잡고 있다는 크기 대비와 혀의 탄성이다.

주된 방식은 전장 안 연속 액션, 보조 방식은 전장 현상이다. 기존 맵과 카메라 구도를 유지하고, 별도 늪 무대나 거대 개구리 머리를 추가하지 않는다.

### 4컷 콘티 초안

| 컷 | 실제 화면에서 일어나는 일 | 힘을 읽게 하는 세부 표현 |
|---|---|---|
| 1 발을 박고 낚아채기 | 골개비가 몸을 낮추고 네 발로 버틴다. 혀가 각 적에게 뻗는다. | 발밑 먼지가 뒤로 밀리고 굵은 혀의 진행 방향을 밝은 맥동이 따라간다. |
| 2 만물을 매달기 | 붙잡힌 적 전원이 공중에 뜬다. 혀줄이 골개비를 중심으로 큰 부채꼴을 이룬다. | 적의 몸체는 선 위에서 식별되도록 남긴다. 주변의 작은 돌과 먼지만 함께 떠 힘의 규모를 보탠다. |
| 3 한계까지 당기기 | 혀줄의 휘어진 부분이 펴지고 골개비의 몸이 뒤로 눌린다. 공중의 적들은 잠깐 매달려 있다. | 탄성이 쌓이는 소리가 올라가고 배경 효과는 잠시 잦아든다. 대표 장면은 작은 골개비와 팽팽한 여러 가닥의 대비다. |
| 4 팔방으로 해방 | 골개비가 몸을 펴며 각 혀가 적을 서로 다른 방향으로 내던진다. 실제 착지점에서 충격이 터진다. | 빠르게 풀리는 혀의 파동, 적의 회전과 짧은 궤적, 착지 먼지와 한 번의 묵직한 충격음으로 끝낸다. |

혀는 적 사이를 촘촘히 가로지르는 그물보다 골개비에서 각 적으로 뻗는 성긴 가닥으로 표현한다. 입을 벌렸다가 이미 같은 공격을 보여준 뒤 전장에서 다시 공격하는 이중 구성을 피한다. 적을 붙잡고 놓는 실제 사건이 곧 연출이 되도록 연결한다.

현재 피해량, 쿨타임, 공중 제어, 팔방 착지 위치와 판정은 유지하는 제안이다. 현재 시전 기준 초타 0.18초와 착지 후타 1.45초에 시각적 명중도 맞춘다. 현재 공격 동작은 약 1.70초이므로 새로운 준비 포즈를 그 안에 충분히 담을 수 있는지 콘티에서 먼저 확인한다. 준비 시간을 추가하거나 실제 동작 시간을 늘리는 안은 별도 논의한다.

### 다른 방향의 후보

- 만화식 포획 장부: 화면 가장자리에 잡힌 적의 실루엣이 차례로 찍히고, 마지막 표식이 닫힐 때 실제 적들을 팔방으로 내던진다. 유머와 수집가의 인상을 강조한다.
- 화면 위에서 드리운 위협: 혀 끝이 화면 위로 사라지고 적들이 끌려 올라간다. 잠깐의 공백 뒤 여러 갈래 궤적이 화면 안으로 돌아와 실제 착지와 이어진다. 미지의 거대한 힘을 강조하지만 적의 위치를 놓치기 쉬워 보조 후보로 둔다.

## 다음 설계 단계

추천한 혀의 탄성 구성을 먼저 4컷으로 비교하고, 대표 장면이 충분히 다르게 보이는지 논의한다. 선택 후에만 픽셀 그래픽과 애니메이션을 제작한다. 완료된 검치와 랩터 연출은 이 설계 때문에 변경하지 않는다.
