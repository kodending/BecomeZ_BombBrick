# 종별 고정 성장 특성 배정 및 적용

2026년 10월 13일 적용 완료. 승인된 20계열 80종 배정을 그대로 사용하여 종마다 2등급 특성 하나와 3등급 특성 하나를 고정했다. 기존 3등급 스킬 60개를 모두 사용하며, 종별 고유특성·주계수·성장 역할에 맞춰 같은 계열의 운용을 구분한다.

**게임 코드·로컬 마스터·기존 Google DB 반영 및 재조회 검증 완료.** 새 게임의 기본 6마리+추가 2마리 전체 무제한 리롤와 탐험 준비·도감 미리보기도 적용했다. 수호 공명과 기술 강화의 확인된 실행 누락을 수정했다. 승률이나 모든 장비·증강 조합의 최종 밸런스를 검증한 것은 아니다.

## 고정 규칙

- 일반 획득과 적은 종별 2등급·3등급 기본 배정을 사용한다. 새 게임 시작 동료 8마리는 개체별 추첨·저장한 특성을 우선 사용하며 이후 탐험에서도 유지한다.
- 1등급에서 두 특성을 미리 보여주되 발동시키지 않는다. 2등급에 첫 특성이 활성화되고, 3등급에서는 첫 특성을 유지하면서 두 번째 특성이 활성화된다.
- 종 고유특성은 별도로 유지한다. 4등급은 기존 계열 특성을 유지하면서 해당 종의 고정된 3등급 스킬과 연계한다.
- 새 게임의 리롤 버튼은 하나이며 8마리를 한꺼번에 무료·무제한 다시 뽑는다. 2등급은 호환 공용 특성 중 1개, 3등급은 해당 계열의 3개 스킬 중 1개를 각각 추첨한다. 확정 후에는 특성이 유지된다.
- 종마다 반드시 다른 특성을 줄 필요는 없다. 같은 3등급 스킬을 쓰더라도 고유효과와 주계수·2등급 조합이 다르면 함께 사용한다.

## 전체 배정 확인

| 현재 특성 호환 조건 | 80종 모두 통과 |

| 미배정 2등급 | 기동 강화 |
| 관련 회귀 검사 | 전투·저장·배정 820개 통과, 추가 배정·번역 14개 통과(중복 제외 총 830개) |

기동 강화는 현 배정안에서 제외했다. 스킬 이동과 고유 추적 효과가 있는 종에 단순 이동속도만 고정하기보다, 전투 역할에 직접 연결되는 특성을 우선했다. 기능을 삭제하자는 뜻은 아니며, 출시 때 고정 성장만 사용한다면 미사용 특성을 도감에 선택 가능한 것으로 노출하지 않아야 한다.

## 함께 해결한 실행 불일치

### 수호 공명의 부여자 기준 처리

등록 설명은 자신이 생성하는 보호막 +40%, 이로운 버프 효과량 +30%다. 변경 전에는 특성 소유자가 받는 보호막이 커졌고, 아군에게 주는 보호막과 포레디어의 가속 등에는 부여자 배율이 빠져 있었다.

변경 후 수호 공명 시전자가 보호막 100을 주면 140이 된다. 수호 공명 수혜자가 일반 시전자에게서 받는 보호막은 100 그대로다. 지속시간도 그대로 유지되는 것을 실제 Unit 기반 검사로 확인했다.

공통 보호막과 별도 보호막 필드의 신규 부여분에 부여자 배율을 적용했다. 왕실 버프·곰의 투지·숲의 가속·훔친 강화·고양과 생명회귀의 초과치유 보호막도 시전자 기준으로 연결했다. 수호 공명으로 치유·피해·적 디버프·지속시간·횟수·면역 범위를 늘리지는 않는다.

영향받는 배정 종: 윌로·킹파·담이·월영·포레디어·앤트포네·금강수.

### 기술 강화의 지원량 누락

등록 설명은 피해·회복·보호막·상태효과 수치 +30%다. 변경 전 `SkillSupportAmount`에는 기술 강화가 반영되지 않았다. 공통 지원량에 시전자 기술 강화 1.3배를 연결했고, 기술 강화·증강·합주 배율이 한 번씩만 적용되는 것을 확인했다.

피해 상한 비율·흡혈 비율·제어 시간까지 일괄 1.3배로 확장하지 않았다. 이번 배정에서는 기술 강화를 피해 중심 종에 우선 배치했다.

## 효과 조합에서 주의할 부분

- 테라칸에는 피의 역류 대신 먹잇감 몰이를 배정했다. 피의 역류는 보호막 흡수량을 제외한 실제 체력 손실이 기준이어서, 방어·보호막을 높이는 테라칸의 주된 장점과 충돌한다.
- 루미룸에는 기생 왕관 대신 포자 공명을 배정했다. 기생 왕관에서 루미룸의 회복은 자신에게만 적용되어 아군 치유 역할이 약해진다.
- 수호 공명은 회복량을 늘리지 않는다. 회복 중심인 콩쥐·모스카·루미룸에는 순환 가속, 루나디어·해타에는 실제 회복 계수인 공격력을 올리는 완력 강화를 배정했다.
- 체력형의 생명 강화, 방어형의 철갑 강화는 생존과 스킬 위력을 동시에 높인다. 기존 계수를 유지하되 릴라스·티노·아이언쿠마·아이언렉스·코가손·아이언터스크·아틀라곤의 고정 조합을 우선 실전 확인한다. 이번 단계에서 환산율을 추가로 올리지 않는다.
- 피해 제어와 빙결은 구분한다. 현 제압 공세의 조건은 공중·쓰러짐·속박·강제 이동이며 빙결 자체는 포함하지 않는다. 원소 공명도 단순 둔화만으로 발동하지 않는다.
- 원소 공명과 다단 적중을 묶은 종은 첫 적중부터 모든 피해가 증가한다고 계산하지 않는다. 상태 부여 순서, 종별 시전당 고유효과 횟수와 기존 발동 상한을 유지한다.
- 순환 가속은 재사용 대기시간 -20%다. 실제 시전 빈도는 동작 시간·사거리·대상 존재 여부에도 영향을 받는다. 제어기·면역·소환을 가진 종에 일괄 배정하지 않았다.
- 3등급 공유 종도 동일한 역할이 되지 않도록 고유효과를 기준으로 나눴다. 예를 들어 록록의 메치기는 폭발 피해, 프로스크의 메치기는 피해 비례 아군 회복을 담당한다.

## 적용 결과와 저장 호환성

1. `Monster_Growth_Master!AB1:AD81`에 고정 2등급·3등급 ID와 버전 1을 기록했다. Google 실제 셀을 CSV로 읽어 에디터 importer를 통과시킨 결과 로컬 80종 배정과 모두 일치한다. 누락·비호환 배정은 저장 전에 거부한다.
2. 아군 새 탐험은 개체에 저장된 특성을 우선 사용하며, 저장된 개체 특성이 없는 일반 획득·적 생성·신규 합류는 공통 종별 배정을 사용한다. 테스트 씬의 명시적 선택은 검수 기능으로 유지한다. 기존 4등급과 소환 개체의 상속 규칙은 유지했다.
3. 새 게임 기본 동료는 벨로스·검치·골개비·아거·콩쥐·웅이다. 종류만 고정하고 평균 능력치는 B−~B+ (품질 점수 30 이상 70 미만), 이로치는 등장하지 않는다. 추가 2마리는 일반 능력치 범위와 이로치 확률을 사용한다. 리롤 버튼 하나로 8마리의 능력치·성격·2·3등급 특성을 모두 다시 뽑고 추가 2마리는 종류도 다시 뽑는다. 8마리 내 종 중복은 제외한다.
4. 후보와 리롤 가능 상태를 저장하여 재접속 시 복원한다. 확정 후에는 리롤할 수 없다. 메인 화면은 ‘새 게임 시작’과 저장 기록이 있을 때만 표시되는 ‘이어하기’로 나눈다. ‘새 게임 시작’ → 튜토리얼 진행 여부 선택 → 바로 동료 선택 씬으로 이동한다. RESET 입력이나 초기화 완료 화면은 없으며 기존 기록은 내부에서 자동 백업한다. ‘이어하기’는 저장된 선택과 진행을 유지한다. 새 게임에서 ‘튜토리얼 진행’을 체크하면 전체 튜토리얼로 이어지고, 해제하면 모든 안내와 강제 조작을 생략한다. 2웨이브의 아이템 합성·장착·이동과 탐험 정산 후 증표 확인·증표 상점 열기까지 포함하며, 상점을 열면 전체 완료된다. 구매는 강제하지 않는다. 이 선택은 저장·백업 복구·동료 확정 후에도 유지된다. 버린 후보는 도감에 등록하지 않는다. 저장 실패 시 후보 또는 확정 상태를 원복한다.
5. 탐험 준비 덱·개체 상세·도감·동료 선택 화면에 2·3등급 성장 특성과 설명 미리보기를 추가했다. 한글·영어와 1920×1080, 1366×768, 1280×960, 2560×1080 화면으로 표시를 확인했다. 기존 재조합 도구는 특성을 바꾸거나 소모하지 않고 고정 규칙을 안내한다.
6. 기존 보유 개체와 진행 중인 탐험의 유효 특성은 보존한다. 다음 탐험에서도 시작 동료는 저장된 개체 특성을, 그 외 개체는 종별 기본 배정을 사용한다. 보유 유효 개체가 0마리인 비정상/구버전 프로필에만 초기 동료 선택을 복구한다. 실제 사용자 저장은 초기화하지 않았다.
7. Google `Localization_Master!A1666:I1698`에 새 UI·설명 번역 33개를 추가하고, 기존 `D1056:E1056,I1056`의 재조합 설명·버전을 수정했다. `등급_획득_성장!A11:G13,A38:G40`에 규칙을 기록했다. 값 재조회와 고정 특성 열의 브라우저 표시를 확인했다.
