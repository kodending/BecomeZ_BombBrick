# 고릴라 3등급 천지 전복 — 2026-09-15

## 확정 구현

- 기본 대지 고동을 한 번의 강한 내려찍기로 대체한다. 준비 0.45초 → 하강 0.08초 → 접촉 유지 0.12초 → 복원 0.18초. 재생 속도에 비례하며 긴 프레임에도 접촉 프레임을 건너뛰지 않는다.
- 반경 3타일, 기본 고동 피해의 200%를 한 번 적용한다. 기본 공식은 ATK×110%+자신 최대 HP×5%이므로 기본 대비 총 200%다. 기본 타격을 별도로 더하지 않는다.
- 범위 안 적에게 1초 쓰러짐. 제어 면역·상태 저항 경로를 유지한다. 기존 띄우기 → 끌어모으기 → 추가 폭발, 보스 예외를 제거했다.
- 기본 쿨타임 8초와 종 고유 효과를 유지한다. 종 고유 효과는 첫 타에서 한 번만 발동한다. 마그릴 고유 용암 등 기존 종 효과는 별개로 유지한다.

## 연출

- 팔을 들어 올리고 힘을 모을수록 스프라이트가 좌우·위아래로 빠르게 떨린다. 전투 본체 위치와 카메라는 준비 중 고정한다.
- 반경 3타일의 80% 영역에서 작은 갈색·밝은 돌색 픽셀 조각이 생성되어 살짝 상승한 뒤 속도가 줄어든다. 반경 표식이나 바닥 패임을 남기지 않는다.
- 접촉 프레임에 부유 파편을 정리한다. 고릴라 몸이 깊게 눌리는 자세, 황토색 확산 충격파, 바깥으로 튀는 파편 27개를 재생한다. 충격파는 실제 반경 3타일까지 약 0.216초에 확산하고 0.36초에 사라진다.
- 적마다 Hit·흰 반짝임·쓰러짐을 보여준다. 접촉 순간 카메라 진동 12px/0.26초, 줌 변경 없음.
- 중단·사망·비활성화 때 부유 파편과 떨림을 정리하고 예약 타격을 취소한다. 비활성화 후 다시 활성화해도 취소된 타격을 보내지 않는다.
- 기존 스프라이트 6장과 파편 소재, 대지 고동 피해/연출 경로를 재사용했다.
