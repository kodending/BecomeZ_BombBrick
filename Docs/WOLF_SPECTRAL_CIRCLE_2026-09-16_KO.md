## 최신 수정 — 늑구 본체와 추격 대상 연결선 제거

- 앞선 잔광·타격 섬광 수정은 이 연결선 문제의 해결이 아니었다. 이전 Camera.Render 캡처에는 OnGUI가 포함되지 않아 놓쳤다.
- 이번에는 UI를 포함하는 실제 Game View 캡처로 확인. 천랑백귀 420 피해 후 강화 추격 잔여 5.18초·대상 참조 정상 상태에서 연결선 없음. 추격 효과와 상태 아이콘 정상 유지, 콘솔 오류·경고 0. 증거 `Logs/WolfChaseConnectionFix/`.
- 수치·규칙·설명 변경이 없는 UI 제거이므로 구글/로컬 DB 버전 7 유지.
