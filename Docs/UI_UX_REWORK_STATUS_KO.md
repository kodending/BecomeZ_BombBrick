버그가 발견되면 현재 단계를 잠시 중단하고 버그를 먼저 수정한 뒤, 위 순서로 복귀한다.

## 2026-07-24 반영 사항

- 보유 증강 HUD를 준비 화면 좌측 `다음 교전` 패널 아래 위치로 복구했다.
- 증강 선택 화면은 헤더·카드·대상 선택·새로고침을 하나의 블록으로 계산해 Safe Area 세로 중앙에 배치한다.
- 전투 데이터는 좌측 슬라이드 서랍으로 열고 닫는다.
- 전투 종료 직전 Wave별 아군의 입힌 피해, 받은 피해, 실제 회복량, 생존 여부를 스냅샷으로 저장한다.
- 서랍 상단의 `W1`~`W12` 탭으로 이전 Wave와 현재 LIVE 기록을 전환한다.
- 같은 Wave 재도전 시 해당 Wave 기록은 최신 시도로 교체한다.
- 성장 카드는 아래에서 분배되는 등장 연출, 방향 무관 드래그, 포인터 중심 임계 링, 선택 직전 강조, 선택 카드 회수 연출을 사용한다.
- 성장 카드 하단은 골드·새로고침 아이콘 중심으로 정리하고, 카드별 보유 중첩을 배지로 표시한다.

## 7단계 완료 조건

- 카드 등장부터 선택 완료까지 별도 선택 버튼이 필요 없다.
- 드래그 거리가 임계치에 도달하기 전에는 선택되지 않는다.
- 드래그 방향과 무관하게 같은 거리 기준을 사용한다.
- 희귀도, 효과, 기존 보유 중첩을 한눈에 비교할 수 있다.
- 선택 확정 시 선택된 카드와 제외되는 카드의 움직임이 명확히 구분된다.

## 8단계 반영 사항

- HP바는 최대 체력 ÷ 150을 올림해 1~10칸으로 균등 분할한다. 최대 체력 1,500을 넘으면 한 칸당 체력이 150보다 커진다.
- 아군 HP는 녹색, 적 HP는 적색으로 구분하고 빈 체력과 칸 경계를 항상 확인할 수 있게 했다.
- 상태·아이템·종족 스킬에서 생성되는 모든 보호막을 합산해 HP바 외곽을 감싸는 보호막 프레임으로 표시한다.
- 보호막 잔량은 HP바 둘레를 따라 채워지며 최대 체력 이상의 보호막은 완성된 발광 프레임으로 표시한다.
- Wave 종료 흐름을 `1초 정리 → 2초 승패 표시 → 전리품 확보 → 성장 카드 → 다음 Wave 진입`으로 통합했다.
- 전리품 확보 화면에서 아이템, 골드, 승급제를 아이콘으로 확인한 뒤 자동으로 원정 가방에 이동한다.
- 패배 화면을 남은 목숨, 전리품 무효, 동일 Wave 재도전 행동 중심으로 개편했다.
- 최종 Wave 완료는 전리품 확인 후 원정 완료 결과 화면으로 연결한다.

## 8단계 완료 조건

- 보호막 존재와 대략적인 잔량을 HP바만 보고 판단할 수 있다.
- 서로 다른 최대 체력을 가진 개체의 체력 구간을 칸 수로 비교할 수 있다.
- 승패 판정부터 다음 행동까지 화면이 겹치지 않고 순차적으로 진행된다.
- 획득하거나 잃은 전리품과 남은 목숨이 다음 행동 전에 명확히 전달된다.

## 9단계 반영 사항

- 전리품 확보 화면을 최대 1080×500 규모의 대형 세리머니 화면으로 확장했다.
- 보상 아이콘을 최대 132px로 확대하고 각 보상이 차례로 낙하·확대되며 충격 프레임이 퍼지는 애니메이션을 적용했다.
- 전리품 제목 확대 각인, 배경 원형 파동, 보상별 순차 등장, 가방 전송 진행 게이지를 하나의 흐름으로 연결했다.
- 캡션은 최소 10px, 본문은 최소 12px, 제목은 최소 13px을 보장하며 화면 높이에 따라 최대 115%까지 확대한다.
- 고해상도에서는 몬스터 드래그와 상점 스와이프 임계 거리를 최대 135%까지 확대해 오작동을 줄인다.
- 모달·전투 결과·전리품 연출 중에는 전장 클릭, 포획 안내, 개발 도구, 잔여 툴팁이 앞에 나타나지 않게 입력·표시 우선순위를 통합했다.
- 아군·적군 HP바에 색상 외에도 좌·우 방향 표식을 추가해 색상 구분 의존도를 낮췄다.
- 16:9, 16:10, 21:9 화면비에서 전리품 화면과 공통 HUD의 Safe Area 및 겹침을 검증했다.
- 레이아웃 자동 테스트에 1920×1200, 고해상도 입력 거리, 접근성 글꼴 크기 검증을 추가했다.

## 9단계 완료 조건

- 16:9, 16:10, 21:9에서 주요 패널이 화면 밖으로 나가거나 서로 겹치지 않는다.
- 작은 보조 텍스트도 정해진 최소 크기보다 작아지지 않는다.
- 고해상도에서 드래그와 스와이프가 지나치게 민감해지지 않는다.
- 최상위 모달이 열리면 뒤쪽 전장과 HUD가 입력을 받거나 앞에 표시되지 않는다.
- 색상만으로 아군·적군과 주요 상태를 구분하도록 강요하지 않는다.
