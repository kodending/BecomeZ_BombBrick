# 아라크네 기본 스킬 대형 포획망 연출 — 2026-09-17

사용자 승인: 실을 모아 던지고, 목표 위에서 그물로 펼쳐져 착지하며 적을 감는 연출. 후속 요청에 따라 속박 표현을 몸통까지 감싸는 고치로 강화하고, 속박 중 공격과 이동을 차단했다.

## 구현

- 기존 SkillAttack 앞다리 동작에 작은 도트 실뭉치의 압축을 연결. 타격 프레임에 발사하며 비행 시간은 기존 거리 기준 0.14~0.34초.
- 목표 상공에서 0.11초 동안 그물로 펼친 후 0.13초 동안 낙하. **실제 착지 콜백**에서 피해와 4초 지대를 시작한다. 적별 짧은 실 파편 타격 추가.
- 바닥 그물 외곽은 실제 반경과 일치한다. 지속 중 크기 맥동 제거. 투명 배경 렌더 순서 0과 캐릭터 10 사이에 그려 배경에 묻히지 않게 보정했다.
- 0.8초 체류 시간에 따라 발목의 실 3겹이 드러나고 실제 Root/Freeze 적용 시 몸통 전체에 교차된 도트 고치가 0.14초 동안 감긴다. 캐릭터가 보이는 반투명 내부/굵은 교차 실과 바닥으로 뻗는 팽팽한 실 4가닥. 해제 시 고치 양쪽과 실이 갈라져 0.24초 동안 사라진다.
- **아라크네가 건 속박 중 이동·일반공격·스킬 사용 불가.** 준비 중인 일반공격/스킬/홀드 동작을 취소하고 Idle 자세에서 멈춘다. 해제하면 정상 행동하며 취소한 공격을 뒤늦게 재생하지 않는다. 공용 Root 중 다른 계열의 이동 제한 효과는 그대로 두고, 시전자 계열로 아라크네 속박을 구분했다.
- 이미 발생한 지대·투사체는 유지하며, 외부 끌어당김/투척은 진행된다. 아라네아 자신의 0.75타일 당김이 속박 때문에 지연되지 않도록 이동 처리의 경계 조건도 검증했다.
- 이탈하면 미완성 실이 풀리고 체류 누적 초기화. 같은 그물의 속박은 1회. 늦게 적용된 속박은 지대 만료 후에도 실제 상태가 끝날 때까지 감긴 실을 유지한다.
- 지대 만료 시 고정된 수의 도트 실 조각이 짧게 흩어진다. 사망·전투 초기화·준비 동작 취소 시 비행/준비 연출을 정리한다.
- 아라네아 흰색, 실란티 모래색, 라곤 분홍빛 보라색, 아이스아라크네 냉기색을 실뭉치/그물/발목 실에 공통 적용.
- 비행 중 재시전이나 메아리가 발생해도 원래 목표/피해/범위가 바뀌지 않도록 발사 시 값을 보관했다.
