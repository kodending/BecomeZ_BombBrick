# 풍뎅이 4등급 — 천지전복

전투 시작에 배치로 선택한 세 열의 적 전후 진형을 뒤집는다. 이전 ‘만유인력의 뿔’의 스킬 사용 후 추가 피해·쓰러짐은 제거했다. 저장 호환성을 위해 특성 ID `trait_transcend_beetle_horn_of_gravity`는 유지한다.

## 확정 동작

- 전투 시작 시 1회. 자신이 배치된 열과 양옆 한 열에서 시작한 적만 선택한다. 끝열에서는 실제 존재하는 두 열만 적용한다.
- 보드의 `x`는 전진/후퇴 방향, `y`는 나란한 전투 열이다. 각 적의 열은 유지하고, 선택한 적 진형의 가장 앞/뒤 배치 칸을 기준으로 `새 x = 최소 x + 최대 x - 기존 x`로 뒤집는다. 동일 깊이에만 배치되었다면 위치는 같고 공중 회전만 발생한다.
- 0.4초 준비·범위 예고 → 0.8초 공중 회전 → 동시 착지. 공중 정점에서 약 0.1초 멈춘다. 앞뒤 적은 다른 높이의 궤적을 사용해 구분한다.
- 제어 면역은 이동 대상에서 제외한다. 착지에 다른 개체가 있으면 같은 열에서 가장 가까운 빈 칸으로 보정한다. 여러 풍뎅이가 같은 적을 중복으로 뒤집지 않는다.
- 추가 피해·착지 쓰러짐 없음. 착지 후 목표를 다시 판단한다. 시전자 사망·해제·외부 이동 시 공중 자세와 상태를 정리한다.
- 기존 첫 스킬의 쿨타임을 소비하지 않는다. 선택한 3등급 스킬을 계속 사용하며, 스킬 사용으로 천지전복이 다시 발동하지 않는다.

## 표현

배치 중 선택/드래그에 맞춰 영향받는 열의 타일을 밝게 표시한다. 전투 시작 시 푸른 네온 테두리·바닥 픽셀 입자와 함께 뿔을 낮췄다 치켜든다. 적은 기존 Drag/Struggle 프레임으로 공중에서 뒤집힌다. 각 적의 착지점에 개별 지면 파티클, 착지 순간 강한 카메라 흔들림 1회를 재생한다. 카메라 줌은 변경하지 않는다.
