# SR-02 플레이 중 저장 실패 안내·재시도

2026-09-25. Google 과제표: https://docs.google.com/spreadsheets/d/YOUR_SPREADSHEET_ID/edit#gid=1950270647

## 변경 결과

- 원정 체크포인트/정산 저장의 I/O 오류는 공통 안내창으로 표시한다. 저장 재시도·저장 폴더 열기를 제공하며, 실패 중에는 전투 시간, 조작, 결과/마을/메인 이동을 막는다. 재시도가 성공하면 기존 시간 배율로 복귀한다.
- 전투 시작은 체크포인트 저장이 성공한 뒤 실행한다. 실시간으로 진행되는 보상 선택/상점 종료 코루틴도 저장 대기 중 다음 작업을 실행하지 않는다.
- 장면 이동과 정상 종료 전에 저장을 확인한다. 실패하면 이동/종료를 취소한다. 씬 파괴/종료 통보 후에 저장하던 처리는 제거했다. 강제 종료하면 미저장 진행이 유실될 수 있음을 안내한다.
- 포획 그물 소모·포획 몬스터 등록·튜토리얼 진행 저장도 원정 체크포인트 재시도 흐름을 사용한다. 체크포인트 저장으로 불필요한 몬스터 능력치 재적용 이벤트가 발생하지 않도록 했다.
- 원정 정산은 정산 대기/결과 영수증을 체크포인트에 먼저 기록한다. 연구 경험치, 토큰, 희귀 그물, 지역/난이도 해금은 복사한 프로필에서 계산하여 한 번에 저장한다. 이후 결과 파일 저장 및 체크포인트 정리가 끝나야 완료/실패 상태와 결과 UI를 확정한다.
- 정산 도중 재접속하면 기존 run ID 정산 기록으로 중복 지급을 막고 정산부터 이어간다. 결과 표시용 경험치/보상 영수증도 보존한다. 원정 저장 버전은 15이며 기존 기록의 정산 대기 기본값은 false다.
- 프로필/체크포인트/결과 파일은 임시 파일과 원자적 교체를 사용한다. I/O 실패 시 파일 복사로 덮어쓰던 fallback을 제거해 정상 원본·백업을 보호한다. 원정 로드의 접근 실패/새 버전은 낡은 백업 또는 새 원정으로 조용히 대체하지 않는다.
- 한·영 안내 4개를 로컬 번역 DB와 `Localization_Master!A1568:I1571`에 동일하게 반영했다.

## 검증 범위

- Windows Unity Editor에서 I/O 오류와 게임 흐름을 검증했다. 디스크 전체를 실제로 채우거나 사용자의 폴더 권한을 변경하지 않았다. Windows 배포 빌드에서 Alt+F4 종료 거부와 OS 강제 종료/전원 차단은 별도 출시 점검에 포함한다.
- 보통 체크포인트의 프로필/원정 두 파일은 순서대로 기록된다. 화면에서 재시도를 완료하면 일치하며, 실패 안내를 무시하고 프로세스를 강제 종료하면 마지막 저장 이후 변경이 유실될 수 있다. 원정 종료 보상은 별도 정산 대기 기록과 run ID로 중복 지급을 방지한다.
