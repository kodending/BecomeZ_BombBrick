# 매머드 4등급 — 거인의 퇴장 명령

기존 대지의 방주를 교체했다. 저장 호환을 위해 `trait_transcend_mammoth_ark_of_earth` ID를 유지한다.

- 각 개체가 전투당 1회, 주변 2타일에서 **체력 20% 미만**의 적 본체를 찾는다. 정확히 20%는 제외한다.
- 현재 대상 우선, 없으면 가장 가까운 적. 근접 접촉 거리까지 이동하며, 진행 중인 기본 공격·3등급 동작은 마친다.
- 0.45초 웅크리기 → 상아 타격 → 0.05초 정지 → 1.8초 포물선 퇴장. 적의 Drag(Struggle) 프레임을 반복 재생하면서 회전·축소한다. 포물선 높이는 7.2타일이며 잔상과 짧은 상아 파편을 더한다.
- 타격 직전 체력·사거리·대상 가능 여부를 다시 검사한다. 회복·도주·시전자 제어에 의한 취소는 횟수를 소모하지 않는다. 빙결은 준비 동작을 정지한다.
- 타격 시 즉시 사망·타겟 해제. 방어·보호막·피해 분담·성역 구원·회귀·사마귀 고치를 건너뛰고, 처치 통계·드롭은 기존 경로로 처리한다. 거미 실인형 재사용과 빙결 파쇄는 발생하지 않는다.
- 이미 무적·대상 제외인 적, 소환체·분신·실인형·고치·날아가는 악어 먹잇감은 제외한다.
- 타격 시 짧은 카메라 진동만 적용한다. 이 처치에는 기존 사망 줌/슬로 모션 이벤트를 발생시키지 않는다.
- 마지막 적이어도 비행 연출이 끝난 후 승패를 처리한다. 전투 정리 시 잔여 이펙트 제거, 다음 웨이브 준비 시 사용 횟수 초기화.

## 데이터

인게임 GameMasterDatabase와 한국어/영어 LocalizationDatabase를 갱신했다. Google DB 기존 파일의 아래 10셀을 동일하게 반영하고 재조회 및 네이티브 화면에서 확인했다. 버전은 2이며 활성화·검토 상태·검증·서식은 보존했다.

- Trait_Master: B197, E197, F197, H197
- Localization_Master: D622, E622, I622, D1177, E1177, I1177

## 검증

`MammothExpulsionTests`에서 엄격한 체력 경계, 대상 제외, 4종 타격 시점/피해/1회 제한, 취소 환원, 3등급 버팀과 양립, 사마귀 고치 차단, 타겟 해제, 전장 밖 종점, 빙결/프레임 동기화를 검사한다.

4종 실제 전투 캡처: `Logs/MammothExpulsion/FinalRuntime`. 각 개체가 20%에서 대기하고 19.98%로 변경된 뒤 접근, 0.4500002초에 타격했다. 마지막 적 검증에서는 비행 전/중 battleEnding=False, 비행 종료 후 True였다. Unity Console 오류 0건. Play Mode는 검증 후 종료했다.

최종 변경 후 EditMode 462/462 통과 (`MonkeyArcTests`, `FamilyTranscendenceRulesTests`, `CombatCameraDirectorTests`). 앞선 계수 회귀 검증을 포함한 476/476도 통과했다. `git diff --check` 통과.

비행 연출 추가 조정: 비행 0.7→1.4초, 높이 3.2→5.2타일. Drag(Struggle) 애니메이션을 원래 FPS로 반복 재생하며 본체가 제거되어도 비행이 유지된다. 4종 시전자·3종 피격자 실제 전투에서 다중 Drag 프레임 및 1.4초 이상 비행 유지 확인 (`Logs/MammothExpulsion/DragRuntime`). 판정·계수·DB 설명은 변경되지 않는다.

장거리 비행 조정: 비행 거리 최소 14타일·전장 경계 밖 여유 8타일(기존 3), 높이 7.2타일, 비행 1.8초. 높이 궤적을 실제 포물선으로 바꾸고 축소를 뒤로 늦춰 크게 뻗은 후 멀어지게 했다. Drag 애니메이션 유지.

장거리 조정 검증: Dismissal 관련 EditMode 31/31 통과, 실전 비행·Drag 반복·정리 확인 (`Logs/MammothExpulsion/WideArcRuntime`), 콘솔 오류 0건.
