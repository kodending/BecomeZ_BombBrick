# 매머드 3등급 두 번째 특성: 쇄벽 돌진

기존 빙하기 장벽을 교체한다. 저장 ID `trait_mammoth_ice_age_wall`는 유지한다.

## 동작

- 0.45초 준비 중 전방 1·2·3타일에 벽 세 개가 순서대로 솟는다.
- 본체가 최대 3.5타일 돌진한다. 각 벽은 상아 앞부분이 닿을 때 한 번만 파괴된다.
- 접촉은 시전 시작 후 0.61 / 0.84 / 1.07초. 충돌마다 0.05초 눌리는 자세로 무게를 주고 다시 전진한다. 도착 1.27초, 회복 종료 1.55초.
- 벽마다 반경 1.5타일에 스킬 위력 100% 피해. 세 폭발에 모두 맞은 적은 300%. 기본 돌진의 경로·도착 피해와 밀치기·쓰러짐은 추가하지 않는다.
- 쿨타임 10초. 고유 스킬 계수 유지: 코가손 최대 체력 7%, 설가손 공격력 100%, 아이언터스크 현재 방어력 35%, 가이아손 최대 체력 5.5%.
- 코가손 보호막은 고유 적중 적당 최대 체력 3%, 아이언터스크 추가 피해는 적마다 시전당 방어력 35% 한 번. 설가손 빙판과 가이아손 선조의 길은 실제 이동 경로에 적용한다.
- 피해, 파괴 프레임, 피격 반응, 카메라 진동을 접촉 이벤트에서 함께 실행한다. 마지막 벽의 진동은 강화하지만 피해량은 동일하다.
- 빙결·일시정지는 공통 동작 시계를 정지한다. 사망·상태 이상·강제 위치 변경·전투 리셋 시 남은 벽과 행동 잠금을 정리한다. 새 지형·적 장벽으로 진행이 차단되면 이후 벽은 폭발하지 않는다.

## 최종 스프라이트

사용자가 코드로 반복 생성한 벽 조각의 외형을 거부했다. 해당 절차적 이미지 생성·조립 코드를 제거했다. 티노 전용 이펙트와 같은 내장 Imagegen 방식으로 벽 전체의 등장·파괴 16프레임 시트를 새로 제작했다.

- `Assets/Resources/CombatEffects/Mammoth/RockWall16.png`: 코가손 암석벽
- `Assets/Resources/CombatEffects/Mammoth/IceWall16.png`: 설가손 반투명 빙하벽
- `Assets/Resources/CombatEffects/Mammoth/IronWall16.png`: 아이언터스크 철판벽
- `Assets/Resources/CombatEffects/Mammoth/RootWall16.png`: 가이아손 뿌리 석벽

원본 RGBA PNG·알파를 보존하고 Point/밉맵 없음/압축 없음으로 가져온다. 그림의 행별 여백에 맞게 Sprite.Create로 잘라 바닥 기준점을 일치시킨다. 벽 하나당 SpriteRenderer 하나를 사용하며 SortingGroup의 기준은 해당 벽의 지면 위치다. 0~4프레임 등장·대기, 5프레임 접촉, 6~15프레임 파괴·파편·소멸. 실제 피해 범위까지 퍼지는 작은 재질별 픽셀 파티클과 개별 피격 연출을 보조로 사용한다.

전체 제작 프롬프트: `Docs/MAMMOTH_WALL_RUSH_SPRITE_PROMPTS_2026-09-19.md`.

### 파괴 파티클 보강

벽마다 픽셀 파편 96개와 픽셀 먼지 48개가 동시에 퍼진다. 큰 파편과 작은 입자를 섞고 내부에도 분포시켜 폭발의 부피를 표현한다. 외곽 파편은 실제 피해 반경 1.5타일(범위 보정 포함) 끝까지 0.16~0.20초 안에 빠르게 도달한 후 감속한다. 입자 크기를 제외한 거리로 제한해 바깥으로 계속 날아가지 않으며, 0.30~0.42초 안에 사라진다. 네 벽 재질의 색상과 기존 제작 스프라이트를 유지한다. 공통 시전 시계에 따라 빙결·일시정지 시 파티클도 정지한다.

파티클 반경·전 방향 도달·내부 분포·소멸 검증을 포함한 쇄벽 돌진 EditMode 15개 통과. 네 종 실제 전투 캡처에서도 세 벽 연속 파괴와 기존 피해량을 확인했다. 근거: `Logs/MammothWallRush/particle-tests.json`, `ParticleBurstFinal/`. 시각 변경만 있으므로 Google DB 수치·설명은 기존 값 유지.
