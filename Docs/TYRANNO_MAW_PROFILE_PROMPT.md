# 시원의 거악 옆모습 재설계

사용자 피드백: 기존 화석 턱은 도트 밀도가 지나치게 높고 정면 구도가 부적합. 캐릭터 수준의 굵은 픽셀, 옆 공간에서 거대한 턱이 갑자기 나타나 옆모습으로 무는 소환 연출로 변경.

내장 Imagegen 사용, 실제 티노 Idle PNG를 스타일/픽셀 밀도 참고로 입력. 원본 결과를 `Assets/Resources/CombatEffects/Tyranno/PrimordialProfile.png`에 저장. Unity Point/512px 최대 크기/압축 없음/알파/밉맵 없음. 위턱·아래턱 두 슬라이스를 카메라와 평행하게 놓고 후방 경첩을 기준으로 회전한다. 공격 방향에 따라 좌우 반전한다. 기존 정면 고밀도 화석 이미지는 런타임에서 사용하지 않는다.
