# 마을 원정덱 슬롯 위치 유지 (2026-09-25)

- 빈 칸 드롭이 명단 끝 추가로 처리되던 동작을 해당 슬롯 대입으로 변경했다.
- `rosterInstanceIds`의 인덱스가 마을 슬롯 번호다. 중간 빈 칸은 빈 문자열로 저장하며, 저장 정규화는 끝의 빈 칸만 잘라낸다. 기존 연속 배치 저장 파일도 그대로 읽는다.
- 빈 칸으로 이동하면 원래 칸만 비워지고, 이미 찬 칸끼리는 맞교환한다. 대기 목록으로 돌려놓아도 다른 슬롯은 움직이지 않는다.
- 표시 인원, 원정 시작 조건, 편성 튜토리얼은 실제 채워진 칸 수(`RosterCount`)를 사용한다. 빈 슬롯은 전투용 배치 데이터에 생성하지 않는다.
