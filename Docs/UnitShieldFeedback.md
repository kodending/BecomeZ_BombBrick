# 공통 보호막 피드백

2026-09-24. 기존 보호막 수치가 있는 모든 개체의 공통 `PixelUnitShield` 연출을 변경했다.

- 생성: 아래에서 위로 0.18초간 헥사가 드러난 뒤, 전체 피막이 0.5초 안에 사라진다.
- 대기: 보호막 수치는 유지하고 MeshRenderer를 꺼서 피막과 테두리가 남지 않게 한다.
- 흡수 피격: 공격자 방향의 헥사가 먼저 반응하고 인접 헥사로 짧게 퍼진다. 0.38초 안에 사라지고 0.4초 후 렌더링도 끈다. 여러 방향에서 맞으면 최대 6개 반응을 독립적으로 표시한다.
- 보호막 소진·만료 시 기존 정리 경로를 유지한다. 소진 후 다시 생긴 보호막은 생성 연출을 다시 보여주며, 재부여 직후 피격도 보존한다. 같은 보호막의 매 프레임 갱신은 생성 연출을 반복하지 않는다.
- 체력·흡수량·보호막 관통 계산은 변경하지 않았다. 상태·스킬·아이템 보호막이 공통 피격 경로를 사용한다. 게임플레이 수치·설명 변경이 없어 Google DB 수정은 없다.

검증: 보호막 관련 EditMode 14개 통과. 실제 셰이더를 RenderTexture로 렌더링한 8개 시점에서 생성·좌우 피격·소멸을 확인했다. 왼쪽 피격은 왼쪽에서만 1,535픽셀, 오른쪽은 오른쪽에서만 1,373픽셀의 변화가 있었으며, 대기 시점 3개 모두 보호막 없는 기준 이미지와 동일했다. 셰이더 컴파일 오류 없음.

재현·결과: `Logs/ShieldReactionReview/render-check.cs`, `render-result.txt`, `stages.png`. 그림은 위쪽 행부터 생성 → 대기 → 왼쪽 피격 시작 → 확산, 아래쪽 행은 왼쪽 감쇠 → 대기 → 오른쪽 피격 → 대기 순서다.

## 피격 헥사 가시성 조정

피격 전용 테두리 폭을 기존 대비 1.5배로 늘리고 밝은 청록색 면·백색에 가까운 민트색 테두리를 사용했다. 피격부의 불투명도도 소폭 높였다. 생성 연출·확산 범위·0.4초 소멸은 유지했다. 같은 8개 시점을 다시 렌더링해 좌우 방향 분리와 대기 시 완전 소멸을 확인했다. 변경 전 비교 이미지는 `Logs/ShieldReactionReview/VisibilityBefore`에 보존했다. 보호막 셰이더 컴파일 메시지는 0개다. 최종 콘솔에는 별도 Vefects 데모 셰이더의 URP include 파일 누락 오류가 있어, 전체 콘솔이 오류 없는 상태는 아니다.
