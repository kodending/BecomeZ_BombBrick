# 정령 사슴 3등급 2번: 불가침 성역

기존 `trait_spirit_deer_inviolable_sanctuary`의 1회 체력 피해 상한을 최대 체력 20%에서 **15%**로 개선했다. 이름과 저장 ID는 유지한다.

## 전투 규칙

- 아군 우선 성역 타겟 선택과 기존 뿔 준비 동작을 유지한다. 반경 **2.5타일**, 지속 **5초**.
- 성역이 퍼져 처음 닿은 아군에게 기존 개체별 축복을 1회 적용한다. 늦은 진입은 허용하며 같은 성역 재진입으로 축복을 반복하지 않는다. 이클립디어의 적 약화도 유지한다.
- 피해를 받는 순간 실제 위치와 퍼진 성역 범위를 확인한다. 방어력·피해 감소·보호막 계산 후 남은 피해를 받는 아군 최대 체력의 **15%**로 제한한다.
- 성역을 벗어나면 즉시 보호가 해제된다. 여러 성역이 겹쳐도 15% 상한을 한 번만 적용한다. 작은 연타는 그대로 들어오며, 남은 체력이 상한보다 낮으면 사망할 수 있다.
- 시전자 사망, 5초 만료, 전투 세대 변경, 전투 초기화 시 보호를 해제한다. 이전 0.35초 잔여 버프 타이머를 제거하고 현재 성역 포함 여부를 피해와 HUD에서 함께 사용한다.
- 기존 매머드 퇴장 처형 예외를 유지한다. 적 및 그림자 복제본에는 보호를 부여하지 않는다.

## 픽셀 연출

바닥에서 옅은 청백색 입자가 낮게 올라와 보호 범위를 보여준다. 실제로 초과 피해를 막은 순간 피격 방향에 정령의 뿔 방벽이 펼쳐지고, 짧게 눌렸다가 충돌 방향으로 빛 조각이 튀며 흩어진다. 막은 피해/최대 체력 비율이 높을수록 밝기·압축·파편 반응이 커진다.

방벽은 수신 캐릭터를 따라가며 한 아군당 한 개만 유지한다. 연속 피격 시 반응을 갱신한다. 파티클 움직임과 소멸은 전투 시간으로 계산해 일시정지 중 멈추고, 사망·대상 제거·전투 변경 시 정리한다. 기존 상태 아이콘 표시 정책을 유지한다.

## 검증

관련 EditMode 테스트 최종 **123개 통과**. 방어·보호막 후 상한, 작은 연타, 사망, 실시간 경계, 장판 퍼짐·만료, 중첩·시전자 사망, 늦은 축복, 상태 아이콘과 초기화, 구 저장 ID 변환, 매머드 처형 예외, 뿔 방벽 위치·갱신·일시정지·소멸을 포함한다.

런타임에서 최대 체력 1,000인 아군이 성역 안에서 400·1,000·400 공격을 각각 150으로 받고, 범위 밖의 400 피해는 전부 받는 것을 확인했다. 성역 안에서의 50 피해도 그대로 적용된다. 누적 차단 피해는 1,350이며, 효과가 중첩 생성되지 않고 최종 만료 후 사라진다. 최종 Unity Console 오류 0건, `CombatEffectTest` 정지 상태 복귀.
