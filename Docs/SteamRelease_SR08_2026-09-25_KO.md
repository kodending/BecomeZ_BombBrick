# SR-08 창 전환 정지·백그라운드 음소거

2026-09-25. [Steam 출시 준비 과제표](https://docs.google.com/spreadsheets/d/YOUR_SPREADSHEET_ID/edit#gid=1950270647)

## 적용 결과

- **설정 → 조작 → 창 전환 시 자동 정지**, **설정 → 소리 → 백그라운드 음소거**를 추가했다. 각각 독립적으로 선택하며 즉시 적용·저장한다. 두 옵션 모두 기본값은 켜짐이고 이전 JSON에 필드가 없어도 켜짐으로 로드한다.
- 생산용 게임 흐름의 `GameFrontend`에서 Unity 포커스/중단 이벤트를 처리한다. 포커스를 잃거나 최소화된 동안 자동 정지하고, 포커스와 중단 상태가 모두 돌아온 뒤 재개한다. 같은 이벤트가 반복돼도 복귀할 배속을 0으로 덮어쓰지 않는다.
- ESC 메뉴의 정지와 SPACE 전투 정지를 보존한다. 저장 실패 재시도나 메뉴 닫기가 백그라운드에서 발생해도 바로 재개되지 않으며, 복귀 시 최종적으로 필요한 정지/배속으로 돌아간다. 씬 전환과 Boot 초기화도 같은 배속 경로를 사용한다.
- 자동 정지는 전투 업데이트와 원정 시간 진행을 막고 Time.timeScale을 0으로 유지한다. 자동 정지를 끄면 백그라운드 전투 진행을 허용한다. 기존 runInBackground 설정은 유지한다.
- 음소거는 저장된 전체 음량을 수정하지 않고 AudioListener의 실제 출력만 0으로 만든다. 복귀하면 설정 음량으로 복원한다. 정지 시에는 전투 음원과 겹쳐 재생하는 보조 음원을 함께 Pause/UnPause한다. 음악 음소거도 전체 출력 경로에 포함된다.
- 창 전환 시 마을 편성, 전투 배치, 아이템/그물, 합성 홀드의 드래그 상태를 기존 메뉴 진입 정리 경로로 취소한다. 복귀에 사용한 클릭·키는 손을 뗀 프레임까지 차단해 의도하지 않은 배치/전투 시작을 방지한다. 자동 정지를 꺼도 이 입력 보호는 적용된다.
- 에디터의 전용 전투 이펙트/밸런스 테스트는 생산용 자동 정지 대상에 포함하지 않았다. 프로토타입 자체의 포커스 상실 시 드래그 취소는 적용된다.
- 한·영 3문구를 로컬 DB와 `Localization_Master!A1631:I1633`에 추가했다. 기존 1,628항목은 변경하지 않았다. Google 27셀 재조회에서 값 일치, Approved 검증, 체크박스, 줄바꿈 서식 보존을 확인했다.

## 검증

- 관련 EditMode **108/108 통과**: GameBackgroundTests, GameFrontendTests, ExpeditionSaveRetryTests, CombatAudioTests, CombatFlashPresentationTests, PlayerProgressResetTests 및 로컬라이제이션 완결성 검사.
- 새 테스트는 이전 설정 기본값과 네 가지 옵션 조합, 0/0.5/2배속, 중복 콜백, 포커스/중단 복귀 순서, 수동 메뉴 정지 보존, 백그라운드 저장 재시도와 메뉴 닫기, 설정 변경 중 음량 복원, 그물·아이템 드래그 취소를 검증한다.
- Boot Play에서 실제 실행 중인 프런트엔드에 Unity 포커스 콜백을 전달했다. 약 0.35초 대기 동안 정지 시 게임 시간 증가량 0, 음량 0, 기본/보조 AudioSource 둘 다 정지. 복귀 시 2배속·기존 음량 0.64·두 소스 재생으로 복원했다.
- 자동 정지 꺼짐/음소거 켜짐에서는 같은 대기 동안 게임 시간이 약 0.70초 진행됐고 2배속·소스 재생 상태를 유지하면서 전체 음량만 0이었다. 수동 메뉴가 열린 상태의 왕복은 정지를 유지했고 메뉴를 닫아야 2배속으로 돌아왔다.
- 네 가지 설정 조합을 실제 PlayerPrefs에 저장→로드했고 try/finally에서 기존 원문을 복원했다. UI 검수 후에도 저장 키 존재 여부와 원문 일치를 확인했다.
- 한국어 1920×1080, 영어 1366×768에서 조작/소리 탭을 각각 캡처해 새 옵션과 기존 문구/버튼이 겹치거나 잘리지 않는 것을 확인했다.
- 실제 사용자 저장 파일 2개는 전후 SHA-256과 개수가 동일하다. 콘솔 오류 0, Boot 정지·한국어·1920×1080 Game View로 복귀했다.
- 별도 Windows 실행 파일은 재빌드하지 않았다. 실행 파일의 실제 Alt+Tab/최소화 조작과 Steam 오버레이 검수는 출시 빌드 통합 검증에 남는다. 이번 실행 검증은 Unity 에디터의 실제 런타임에 포커스/중단 콜백을 전달하는 방식이다.
- Google 시트 검수는 API로 값·서식·입력 검증을 재조회했으며 브라우저 렌더링 검수는 수행하지 않았다.
