# 와이번 기본 관통포

- 대상: 비브르·이그비르·프로비르·템비르. 기존 `basic_wyvern_drake_bolt` ID 유지.
- 기본 공격 애니메이션 타격 프레임에 발사. 그 순간 목표 방향 고정, 유도 없음.
- 실제 기본 공격 사거리 끝까지 직선 관통. `attackRange=3`은 원거리 분류이며 3타일 길이가 아니다. AI의 `AttackDistanceForRange`와 같은 거리 기준을 사용하고 적 충돌 반경을 판정한다.
- 전체 폭 0.35타일. 처음 접촉한 적에게 기본 공격 피해 100%, 이후 각 적에게 60%. 누적 감쇠 없음, 한 발당 대상별 1회.
- 공격 준비 후반 35%(기본 약 0.1초)에 사거리 끝까지 가느다란 실선 표시와 입 주변 픽셀 입자 응축. 타격 프레임에 전체 광선이 즉시 두꺼워진다. 0.08초 유지 후 0.1초 폭·밝기 축소 및 픽셀 소멸. 입부터 끝까지 직선 파티클만 사용.
- 광선 재질은 가산 발광 파티클. 밝은 중심광과 반투명 네온 번짐, 전방으로 흐르는 작은 잔광을 겹친다. 가장자리와 양 끝은 빛이 옅어지며 사라지고, 발사 순간 입 주변에 짧은 섬광을 넣는다. 불투명 사각 띠와 늘린 스프라이트는 사용하지 않는다.
- 광선이 두꺼워지는 타격 프레임에 범위 내 적에게 동시 피해 1회. 가까운 적부터 판정하여 최초 100%·이후 60% 적용. 거리별 도달 지연 없음, 잔광 무피해. 적마다 짧은 밝은 섬광과 전방으로 튀는 픽셀 파편.
- 독보라 / 주황 / 빙청 / 청보라 색상. 기본 관통포 자체는 독·화염·냉기·번개 고유 상태를 추가하지 않는다.
- 치명타 피해는 한 발 전체에 반영. 기존 평타 적중 특성은 첫 접촉에서 한 번, 추가 관통은 기본 공격 피해로만 처리. 기존 4등급 각성의 별도 효과는 유지.
- 적 그리폰 역풍에 막히면 피해 취소, 광선 입자가 바람 방향으로 말려 전장 밖으로 이탈. 아군 역풍은 통과.
- 기존 공격력·공격 간격·이동 속도·사거리 분류 유지. 브레스 스킬과 3등급 선택 스킬은 별도.
- Google DB: `Monster_Master!Q74:Q77`에 한/영 규칙 메모, `T74:T77` 버전 4. 로컬 MonsterDefinition 4개 및 MonsterMasterSnapshot 버전 일치.

검증: 순서별 피해, 타격 프레임에 전 범위 동시 타격, 관통 1회, 아군·후방·범위 밖 제외, 실제 사거리 끝, 잔광 무피해, 치명타, 속성 중복 방지, 역풍 피아 구분, 가는 선→전 길이 순간 확장, 수평·대각선 정렬, 파티클 소멸.
