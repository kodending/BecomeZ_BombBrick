# 성격 전투 반응 (2026-10-15)

기본 전투는 가까운 적을 선택하고, 살아 있는 유효한 표적과 교전을 유지한다. 성격은 주변의 특정 상황에만 반응한다. 신규 배정 6종 및 기존 저장 성격 ID는 유지하며, 능력치와 피해량은 변경하지 않는다.

## 공통 제한

- 성격 표적은 가장 가까운 적보다 한 칸 이상 멀 수 없고, 자신의 공격 사거리 밖 추가 접근도 최대 한 칸이다. 직선 접근 경로가 없는 후보는 제외한다.
- 표적 전환 후 최소 2.4초 유지. 성격 반응 재발동 대기는 5초 또는 6초다.
- 피격·평타 이벤트에서 표적을 예약하고, 진행 중 공격과 스킬을 마친 정상 행동 구간에서 적용한다. 예약은 2초 뒤 만료한다.
- 도발과 사냥 표적은 성격보다 우선한다. 성격 이동이 막히거나 안전한 위치가 없으면 정상 교전한다.
- 보호·대담의 자리 변경은 최대 한 칸, 최대 1.6초다. 겁 많은 성격은 최대 1.6초 후퇴하고 현재 표적과 재교전한다. 후퇴 중에도 스킬은 정상 사용한다.
- 실제 반응이 시작될 때만 느낌표를 1.05초 표시한다. 개체별 느낌표 간격은 최소 5초이며, 기존 효과 알림은 아이콘 표시를 유지한다.

## 검증

`PersonalityCombatTests`에서 최근접 선택·유효 표적 유지·반응 후 대상 고정·공격 완료 대기·도발/사냥 우선·멀리 있는 후보 제외·각 성격의 실제 이동과 전환·한영 느낌표·표시 빈도를 검증한다. `MeleeAttackSlotTests`, `CombatHudIconTests`, `GameLocalizationTests`도 함께 실행한다.

실제 Play Mode 비교는 동일한 8대8 종 구성, 1등급, 기본 능력치, 배치 시드 731245를 사용한다. 아군 성격만 변경하고 적 성격은 집요한으로 고정한다. `Temp/PersonalityCombatQA`에 전투 행동 CSV와 발동 장면을 기록한다. 기존 플레이 저장 데이터를 사용하지 않는 `CombatEffectTest` 장면에서 실행한다.

### 확인 결과

최종 관련 Edit Mode 테스트 127개 통과. 일반 최근접 선택, 유효 표적 유지, 도발·사냥 우선, 공격 완료 대기, 오래된 반응 만료, 마지막 아군의 후퇴 금지, 다음 전투 초기화, 스킬 취소/종료와 사슴 스킬의 기존 성격별 대상 규칙을 포함한다. 넓은 `PlayerProfileV6Tests` 실행에서 기존 드롭 확률·웨이브 수 설정 불일치 2건은 별도로 확인했으며 이번 변경에 포함하지 않았다.

발동 표시 수는 8마리 아군 전체 합계이며, 모든 개체가 매 전투 발동하는 것은 아니다. 보호·대담·겁 많은 성격의 전용 이동을 실제 모델 위치 CSV에서 확인했다. 표적 변경 기록에는 최초 선택·표적 사망·스킬의 강제 목표도 포함하므로 전부 성격 전환으로 해석하지 않는다.

한국어 발동 화면과 1배속 12초 영문 전투를 확인했다. 느낌표는 움직이는 개체를 따라가며, 피해 숫자 위에 마지막으로 그리고 외곽선을 사용한다. 기존 영속 데이터 파일 283개 해시가 유지되었다. 추가된 10개 파일은 격리 전투의 텔레메트리 로그이며, 플레이어 프로필·탐험 저장 파일은 생성하거나 변경하지 않았다. 플레이 모드와 임시 배속을 종료하고 Boot 시작 장면을 복원했다.

여기서 확인한 시간은 한 조합·배치 시드의 관측값이며, 전체 맵과 모든 조합의 밸런스를 보장하지 않는다. EXE 빌드는 이번 검증에 포함하지 않았다.

### 표시 간소화 (2026-10-15)

발동 문구는 모든 성격과 언어에서 `!` 하나로 변경했다. 성격별 색상, 표시 시간 1.05초, 최소 표시 간격 5초, 개체 추적과 외곽선, 실제 행동 규칙은 유지한다.
