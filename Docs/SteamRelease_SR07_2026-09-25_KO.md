# SR-07 강한 섬광 감소 설정

2026-09-25. [Steam 출시 준비 과제표](https://docs.google.com/spreadsheets/d/YOUR_SPREADSHEET_ID/edit#gid=1950270647)

## 적용 결과

- 메인 화면/ESC 메뉴의 **설정 → 화면 → 강한 섬광 감소**에서 켜짐/꺼짐을 선택한다. 선택 즉시 적용·저장하며 화면 설정 적용 버튼은 따로 누르지 않아도 된다.
- 기본값은 꺼짐으로 기존 연출을 유지한다. 새 필드가 없는 이전 설정도 꺼짐으로 읽으며 기존 UserSettings 저장 키를 사용한다. 새 게임 시 유지되는 설정이다.
- `CombatFlashPresentation`에서 밝은 색의 RGB 피크를 0.68로 제한하되 색 비율과 일반 알파는 유지한다. 넓게 번쩍이는 덧광에는 별도로 알파 25%를 적용한다. 매 프레임 저장 파일을 읽지 않는다.
- 공통 스프라이트 타격 이펙트, 초신성, 별자리, 전장 브레스, 티라노 강타, 브레스·포효 파티클, 피격 섬광을 조절했다. 범위선·낙하 그림자·이펙트 크기·피해 및 애니메이션 시점은 유지한다.
- 늑구 분신의 폭발 직전 빠른 점멸은 연속적으로 밝아지는 예고로 대체한다. 폭발 조건과 시점은 그대로다.
- 와이번 레이저는 네온 셰이더의 발광 배율을 낮춘다. 해태 번개는 실제 에셋의 `_EmissiveIntensity` 값을 MaterialPropertyBlock으로 낮춰 공유 머티리얼 원본을 변경하지 않는다.
- 원래 모드로 전환하면 공통 스프라이트 원색·번개 발광·레이저 발광이 복원된다. 생성 시 색을 정하는 짧은 파티클은 다음 생성부터 변경된 설정을 사용한다.
- 한·영 2문구를 로컬 DB와 `Localization_Master!A1629:I1630`에 반영했다. 기존 로컬 1,626항목은 변경하지 않았으며 Google 재조회에서 18셀 일치와 기존 형식/검증 보존을 확인했다.

## 검증

- 관련 EditMode **137/137 통과**. 설정 기본값/JSON 저장·로드, 밝기·알파, 모드 복원, 초신성 그림자/범위, 별자리 경계, 늑구 점멸 제거, 번개 원본 보존과 기존 스킬 시점·판정 회귀 검사를 포함한다.
- Boot Play에서 켜짐/꺼짐을 각각 저장→로드→적용해 런타임 플래그와 셰이더 값을 확인했다. 카메라 흔들림 설정은 유지됐다.
- 초신성·번개·전장 브레스·레이저를 동일한 시점과 카메라로 렌더링해 좌우 비교했다. 이 고정 표본에서 밝기 0.85 초과 픽셀 수는 각각 1,479→362, 175→90, 3,767→0, 1,507→612였다. 이는 대표 표본의 시각 검수이며 모든 전투 조합의 섬광 제거를 의미하지 않는다.
- 한국어 1920×1080, 영어 1366×768 설정 화면을 캡처해 새 행과 주변 옵션이 잘리지 않는 것을 확인했다. 네온 셰이더 컴파일 메시지 없음.
- 실제 사용자 저장 파일 2개는 모두 전후 SHA-256과 파일 개수가 동일하다. 설정 저장 검증은 try/finally로 기존 PlayerPrefs 원문을 복원했고, UI 검수 후에도 원문 일치를 재확인했다.
- Boot 정지 상태, 한국어, 원래 1920×1080 Game View로 복귀했다. 별도 Windows 실행 파일은 이번에 재빌드하지 않았다.
- Google 시트는 제한된 셀 범위의 값·형식·검증을 API로 재조회했다. 브라우저 렌더링 검수는 수행하지 않았다.
- 증빙: `Logs/SteamRelease/SR-07/`의 테스트 결과, 런타임 설정/복원 기록, 저장 파일 해시, Google 동기화 기록, 설정 화면 및 이펙트 비교 PNG.
