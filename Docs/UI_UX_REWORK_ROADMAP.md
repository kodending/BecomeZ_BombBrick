# BombBrick UI/UX 개편 로드맵

최종 갱신: 2026-07-24  
현재 단계: `7단계 대기 - 성장 카드 선택`

## 운영 규칙

- 아래 단계는 선행 관계에 따른 고정 순서다. 순서를 바꿀 때는 이유를 이 문서에 먼저 기록한다.
- 테스트 중 발견된 버그는 현재 단계보다 먼저 처리한다.
- 버그 수정 후에는 중단했던 단계로 돌아오며, 다음 단계로 임의 이동하지 않는다.
- 작업을 마칠 때마다 상태와 검증 결과를 이 문서에 갱신한다.
- 각 단계의 완료 조건을 충족하기 전에는 다음 단계로 넘어가지 않는다.
- 2단계부터는 프로토타입 UI가 아니라 출시 가능한 상용 게임 수준을 품질 기준으로 삼는다.
- 장식보다 직관성, 정보 우선순위, 조작 예측 가능성을 먼저 해결한다.
- 별도 안내문을 읽어야 이해되는 핵심 조작은 UI 실패로 판정하고 다시 설계한다.

상태 표기:

- `[ ]` 대기
- `[>]` 진행 중
- `[x]` 완료
- `[!]` 버그로 일시 중단

## 자가 진단 요약

### 공통 문제

- 고정 픽셀 좌표가 많아 해상도와 화면 비율 변화에 취약하다.
- 준비 HUD, 몬스터 상세창, 에디터 테스트 패널이 우측 상단에서 겹친다.
- 같은 정보가 준비 패널, 월드 라벨, 상세창에 중복되며 중요도 구분이 약하다.
- `GUI.Box`, 개별 `GUIStyle`, 공통 테마가 혼용돼 화면별 밀도와 여백이 다르다.
- 드래그, 스와이프, 선택 완료 상태의 피드백 규칙이 화면마다 다르다.
- 모달 배경, 툴팁, 드래그 오버레이의 계층과 화면 경계 처리가 일관되지 않다.
- 에디터 전용 테스트 UI가 실제 플레이 UI 검증을 방해한다.

### 화면별 문제

- 준비 화면: 좌측 정보가 밀집됐지만 중앙 전장과 하단 아이템 영역의 연결이 약하다.
- 몬스터 상세창: 핵심 정보는 정리됐지만 아이템 슬롯의 의미와 드롭 가능 상태가 약하다.
- 아이템 영역: 아이콘은 생겼으나 일반 아이템, 특수 아이템, 승급제의 상호작용 규칙이 분산돼 있다.
- 전투 HUD: 준비 화면과 시각적 차이가 작고, 체력·보호막·스킬·상태효과 우선순위가 약하다.
- 증강 선택: 카드 상단이 숫자 중심이고 설명 밀도가 높아 선택의 감정적 보상이 약하다.
- 상점: 기본 구조는 정돈됐으나 스와이프 진행, 구매 확정, 구매 불가, 판매 완료 피드백이 부족하다.
- 성장 카드: 현재 가장 완성도가 높지만 드래그 확정 피드백과 하단 골드·새로고침 영역을 더 정리할 수 있다.
- 결과/보상: 승패, 임시 전리품 확정, 성장 카드, 다음 Wave 진입의 흐름을 하나의 시퀀스로 통합할 필요가 있다.

## 고정 개편 순서

### [x] 1단계 - 공통 레이아웃 기반

작업:

- 기준 해상도, UI 스케일, Safe Area, 최소 여백 규칙 확정
- 좌상단 런 HUD, 우상단 상세창, 하단 액션 바의 공통 앵커 정의
- 모달, 툴팁, 드래그 오버레이의 렌더 순서 통일
- 화면 밖으로 나가지 않는 공통 팝업 배치 함수 적용
- 에디터 테스트 패널을 접이식으로 바꾸고 실제 UI 영역과 분리
- 레거시 `GUI.Box`/개별 스타일을 `BombBrickUiTheme` 규격으로 단계적 교체

완료 조건:

- 16:9, 16:10, 21:9에서 주요 UI가 겹치거나 잘리지 않는다.
- 상세창과 테스트 패널이 동시에 열려도 겹치지 않는다.
- 모든 모달에서 배경 입력이 차단된다.

완료 기록:

- `BombBrickUiLayout` 공통 Safe Area 및 앵커 계산 추가
- 준비 HUD, 상세창, 하단 아이템 바, 포획 안내, 개발 패널 연결
- 아이템·특수 아이템·증강 툴팁과 합성 미리보기 경계 처리 통합
- 주요 모달을 Safe Area 중심 좌표로 전환
- 에디터 밸런스 패널을 기본 접힘 `DEV` 도구로 분리
- 1280×720, 1440×900, 2560×1080 자동 레이아웃 검사 통과
- 실제 Game View에서 상세창과 펼친 개발 패널 비중첩 확인

### [x] 2단계 - 준비 화면과 몬스터 상세창

품질 목표:

- 첫 시선에 현재 Wave, 목숨, 골드, 배치 가능 수가 읽힌다.
- 두 번째 시선에 다음 적 구성과 현재 보유 증강을 파악할 수 있다.
- 몬스터를 클릭하면 전투 역할과 강점, 성격, 특성, 장착 아이템을 빠르게 비교할 수 있다.
- 배치, 아이템 장착, 승급, 전투 시작의 가능한 행동과 불가능한 행동이 설명 없이 구분된다.
- 텍스트는 판단에 필요한 정보에만 사용하고 상태·재화·슬롯·행동은 아이콘과 형태로 전달한다.
- 강조 색은 한 화면에서 하나의 주 행동에만 사용한다.

작업:

- Wave, 목숨, 배치 수, 골드를 한 줄의 런 상태 영역으로 재구성
- 다음 전투 정보와 전투 시작 행동의 우선순위 재정리
- 보유 증강을 아이콘 중심의 접이식 목록으로 변경
- 선택 몬스터 상세창의 능력치, 성격, 특성, 초월, 아이템 정보 계층 재구성
- 배치 가능/불가 타일과 드롭 대상 피드백 강화
- 포획 대상 지정 UI와 하단 안내 영역의 충돌 제거

완료 조건:

- 준비 화면에서 `현재 상태 → 몬스터 선택 → 아이템/승급 → 배치 → 전투 시작` 흐름이 시선 이동 순서와 일치한다.
- 선택하지 않은 상태와 선택한 상태의 정보 밀도가 명확히 구분된다.
- 신규 플레이어가 별도 설명 없이 몬스터 배치와 전투 시작을 완료할 수 있다.
- 주요 정보가 작은 본문 텍스트에 의존하지 않고 2초 안에 식별된다.
- 동일 계층의 패널, 버튼, 배지, 아이콘이 같은 규격과 상호작용 피드백을 사용한다.

완료 기록:

- Safe Area 전체를 사용하는 상단 원정 상태 바로 Wave, 목숨, 배치 수, 골드, 전투 시작 행동 통합
- 좌측 `다음 교전` 패널에 적 수, 체력·공격 배율, 위험도, 전투 의뢰, 배치 한도 확장 배치
- 보유 증강을 기본 접힘 아이콘 목록과 확장 상세 목록으로 변경하고 공통 툴팁 연결
- 미선택/선택 상태가 명확히 다른 몬스터 상세창과 8종 능력치, 성격, 고유 특성·스킬, 등급 특성, 3개 아이템 슬롯 구성
- 아이템 드래그 시 대상 슬롯 강조, 몬스터 배치 드래그 시 성공·실패 타일 및 포인터 피드백 적용
- 1400×788 실제 Game View에서 준비 화면과 선택 상세창의 정보 계층 및 비중첩 검수
- EditMode 전체 회귀 테스트 178/178 통과

### [x] 3단계 - 아이템·승급·합성 UX 통합

작업:

- 일반 아이템, 특수 아이템, 승급제의 공통 드래그 규칙 확립
- 원본 이동과 복사본 사용을 시각적으로 명확히 구분
- 장착 가능, 조합 가능, 사용 불가 대상의 색상·커서·외곽선 통일
- 합성 유지 게이지, 결과 미리보기, 툴팁을 하나의 오버레이로 통합
- 3슬롯 중복 장착 제한과 실패 사유를 즉시 표시
- 소모 아이템 사용 완료 애니메이션과 수량 변화 피드백 추가

완료 조건:

- 별도 설명문 없이 드래그 결과를 예측할 수 있다.
- 화면 가장자리에서도 아이콘, 합성 결과, 툴팁이 잘리지 않는다.

진행 기록:

- 의미가 불명확했던 다음 교전의 `적용 1` 위험도 배지 제거
- 몬스터 단순 클릭과 드래그를 14px 임계값으로 분리하여 클릭 시 모델이 들리지 않도록 변경
- 전장↔전장 및 대기석↔전장 몬스터 위치 교환과 최대 배치 수 재검증 적용
- 적 클릭 시 등급·체력·사거리와 첫 장비만 공개하고 나머지 능력치·성격·특성·스킬·장비를 잠그는 제한 정보 패널 추가
- 실제 런타임에서 전장 두 개체 및 대기석↔전장 위치 교환 성공 확인
- 일반 아이템은 원본 이동, 승급제·특수 소모품은 원본 잠금과 복사 토큰 방식으로 시각 구분
- 장착·승급·특수 아이템 드롭 대상을 공통 청록 외곽선과 초록/빨강 상태 배지로 통일
- 모든 드래그 토큰, 합성 결과, 툴팁을 Safe Area 안으로 제한
- 합성 유지 게이지와 결과 미리보기 유지, 사용·승급 완료 시 짧은 애니메이션 피드백 추가
- 원정 가방과 특수 도구 영역을 공통 패널·아이콘 규격으로 개편
- 1400×788 실제 Game View에서 아이템 8종 표시와 화면 경계 비중첩 검수
- EditMode 전체 회귀 테스트 178/178 통과

### [x] 4단계 - 전투 HUD와 전투 피드백

작업:

- 준비 HUD를 전투용 축약 HUD로 전환
- 체력, 보호막, 스킬 준비 상태, 상태효과 아이콘의 공통 규격 확정
- 아군, 적군, 선택 대상, 포획 대상의 식별 계층 강화
- 피해, 회복, 치명타, 방어, 상태이상 피드백 정리
- 전투 중 불필요한 준비 정보와 조작 요소 숨김
- 승리/패배 판정 직전과 직후의 정보 노이즈 정리

완료 조건:

- 전투를 멈추지 않고도 위험한 아군, 스킬 준비 상태, 주요 상태이상을 식별할 수 있다.
- 다수 개체 전투에서도 라벨과 아이콘이 과도하게 겹치지 않는다.

완료 기록:

- 전투 시작 시 준비 화면의 다음 교전·증강·아이템 영역을 숨기고 Wave, 목숨, 생존 아군·적군, 전투 시간만 남기는 축약 HUD 적용
- 아군 체력 30% 이하에 점멸 경고, 스킬 준비 완료 점, 보호막 게이지 및 주요 상태이상 배지 적용
- 일반 피해, 치명타, 완전 방어, 회복을 짧게 상승·소멸하는 전투 숫자로 구분
- 적 머리 위 등급·장비 수 텍스트 제거로 다수 개체 전투의 정보 노이즈 감소
- 적 클릭 시에만 제한 정찰 패널을 표시하고 개체별 무작위 능력치 2종과 장비 1개만 공개
- 쌍두 지휘 타일 아이콘을 제거하고 준비·전투 중 결속된 두 몬스터를 추적하는 연결선 적용
- 미선택 시 표시되던 빈 몬스터 프로필만 제거하고, 아군 선택 상세와 장착 슬롯은 유지
- 쌍두 지휘 연결을 곡선 코어, 교차 에너지 결, 이동 입자, 양끝 맥동 링으로 개편
- EditMode 전체 회귀 테스트 178/178 통과

### [x] 5단계 - 상점 UX

작업:

- 카드 스와이프 거리와 구매 확정 상태를 시각화
- 구매 가능, 골드 부족, 판매 완료 상태 구분
- 구매 애니메이션과 골드 차감 피드백 연결
- 새로고침 비용 상승과 무료 1회를 아이콘 중심으로 표시
- 아이템 툴팁과 보유 중복 여부 표시

완료 조건:

- 잘못된 스와이프로 구매되지 않으며 구매 성공 여부가 즉시 인식된다.
- 5개 상품 비교와 새로고침 비용 판단을 한 화면에서 할 수 있다.

완료 기록:

- 다섯 상품을 한 화면에서 비교하는 반응형 카드 레이아웃과 아이콘·능력치·가격 계층 적용
- 보유 수, 구매 가능, 골드 부족, 판매 완료 상태를 카드 배지·색상으로 구분
- 어느 방향으로든 82px 이상 스와이프해야 구매되는 임계값과 진행률·확정 상태 시각화
- 구매 성공 카드 전환, 가방 추가 문구, 골드 차감 피드백 연결
- 무료 첫 새로고침과 누적 새로고침 횟수·현재 비용을 하단 행동 영역에 통합
- 실제 Game View에서 5개 상품, 구매 완료, 골드 차감 및 쌍두 지휘 링크 검수
- EditMode 전체 회귀 테스트 178/178 통과

### [x] 6단계 - 증강 선택과 보유 증강

작업:

- 증강 유형별 비주얼, 아이콘, 색상 체계 확정
- 숫자 중심 카드 헤더를 효과 중심 이미지와 상징으로 교체
- 몬스터/타일/아이템 지정형 증강의 후속 선택 단계를 같은 모달 안에서 연결
- 즉시 적용, 영구 적용, Wave 제한 효과를 배지로 구분
- 보유 증강 HUD와 상세 툴팁을 선택 화면 규격과 통일

완료 조건:

- 카드 세 장의 차이와 적용 대상을 설명문 전체를 읽지 않고도 구분할 수 있다.
- 증강 선택 후 다음 행동이 필요한지 즉시 알 수 있다.

완료 기록:

- 활성 증강 27종과 비활성 보존 데이터 `완성품 숙성`을 포함한 28종 전용 아이콘 제작·매핑
- 저채도 남색 배경, 로우폴리 결정형 심벌, 청록·보라·주황·금색 발광으로 아트 방향 통일
- 숫자 중심 카드 헤더를 128px 효과 심벌과 카테고리 배지 중심의 정보 계층으로 교체
- 아이템·성장 카드와 다른 `궤도 회전 → 인장 정착 → 정보판 전개 → 동심원 각인` 애니메이션 적용
- 몬스터 지정형 증강은 선택 인장을 유지한 채 대상 트레이로 이어지고, 자동형은 0.58초 각인 후 적용
- 보유 증강 접이식 HUD와 상세 툴팁에도 동일한 개별 아이콘 적용
- 실제 Game View에서 후보 선택, 각인 중 강조, 보유 증강 HUD를 검수하고 28/28 리소스 로드 확인
- EditMode 전체 회귀 테스트 178/178 통과

### [ ] 7단계 - 성장 카드 선택

작업:

- 현재 카드 아트와 희귀도 프레임을 유지하며 반응형 비율 적용
- 어느 방향 드래그든 선택 진행도와 확정 임계값 표시
- 선택 직전 카드 강조와 선택 완료 애니메이션 강화
- 골드와 새로고침 정보를 아이콘 중심 하단 바로 재구성
- 현재 중첩 수의 가독성과 변화 피드백 개선

완료 조건:

- 카드 등장부터 선택 완료까지 버튼 없이 자연스럽게 이어진다.
- 희귀도, 효과, 현재 중첩 수가 한 번의 시선으로 읽힌다.

### [ ] 8단계 - 승패·전리품·Wave 전환

작업:

- 승리/패배 문구, 전리품 확정, 성장 카드, 다음 Wave를 하나의 시퀀스로 연결
- 전투 중 보이던 전리품이 Wave 성공 시 보관함으로 들어가는 연출 추가
- 실패 시 미획득 전리품 소멸 피드백 추가
- 목숨 감소와 재도전 상태를 결과 화면에서 명확히 표시
- `WAVE N` 단독 화면과 전투 시작 문구의 모션·사운드 규격 통일

완료 조건:

- 전투 종료 후 무엇을 얻었고, 무엇을 잃었으며, 다음 행동이 무엇인지 순차적으로 전달된다.

- 16:9, 16:10, 21:9와 최소 지원 해상도 테스트
- 모든 화면의 폰트, 간격, 테두리, 모션 시간 최종 통일
- UI GC 할당과 반복 텍스처 로드 점검

완료 조건:

- 전체 UI 테스트 매트릭스를 통과하고 미해결 P0/P1 UI 버그가 없다.
