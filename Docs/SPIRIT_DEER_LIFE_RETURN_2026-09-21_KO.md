# 정령 사슴 3등급 1번: 생명 환류

기존 **수명 징세령**을 **생명 환류 / Life Return**로 교체했다. 저장된 특성 ID `trait_spirit_deer_life_tithe_decree`와 내부 분류 키는 유지한다. 다른 두 3등급 특성은 이번 변경 범위에 포함하지 않는다.

## 적용 규칙

- 성역 반경 2.5타일, 유지 5초. 기존 아군 우선 타겟 선택과 뿔 준비 동작, 퍼지는 성역 연출을 사용한다.
- 아군 최초 접촉 시 기존 개체별 축복과 **5초 생명 환류**를 부여한다. 이클립디어의 적 약화 효과도 유지한다.
- 기본 공격의 **실제 체력 피해 35%**를 공격한 아군이 회복한다. 방어·피해 감소·보호막·남은 체력을 반영한다. 스킬과 지속 피해는 발동하지 않는다.
- 회복 감소와 기존 회복 보정을 적용한 뒤 남은 초과 회복만 **별도 보호막**으로 전환한다. 받는 아군 최대 체력 **8% 상한**, 보호막 지속 **3초**. 기존 홀리디어 보호막과 공존한다.
- 성역 밖에서도 받은 효과가 남는다. 같은 성역 재진입으로 갱신되지 않는다. 다른 성역을 받으면 지속 시간을 갱신할 수 있지만 35% 회복 비율은 중첩되지 않는다.
- 성역 시전자가 사라져도 이미 받은 환류는 남는다. 전투 리셋에서는 제거한다. 개구리의 모든 강화 훔치기에 환류와 보호막을 포함한다.
- 기존 적 최대 체력 징수·최대 체력 감소·보스별 분기는 제거했다.

## 연출

피격 위치에서 세 개의 작은 연녹색 생명빛이 짧은 곡선을 따라 공격자에게 돌아온다. 도착하면 발밑 빛 조각이 위로 올라오고, 초과 회복이 있으면 보호막 외피에 이어진다. 생명 환류가 남아 있는 동안 몸 아래에 작은 빛 조각이 유지된다. 입자와 수명은 전투 시간에 연결해 일시정지 시 멈춘다. 공격자가 이동하면 도착 위치가 따라가고, 사망·전투 세대 변경 시 정리한다.

## 데이터 및 검증

[기존 Google DB](https://docs.google.com/spreadsheets/d/YOUR_SPREADSHEET_ID/edit) 10셀을 동기화했다.

- `Trait_Master!B169,C169,F169,H169`: 이름·효과 태그·설명·버전 7.
- `Localization_Master!D594,E594,I594`: 한영 이름·버전 2.
- `Localization_Master!D792,E792,I792`: 한영 툴팁·버전 2.

관련 EditMode 테스트 **49개 통과**, 마지막 입자 간격 조정 후 이동·일시정지·도착·제거 테스트 **1개 재실행 통과**. 실제 3등급 성역 시전과 일반 공격을 실행해 체력 `200 → 기본 축복 300 → 환류 510 → 600`, 최대 체력 600의 보호막 상한 48, 늦은 진입, 일시정지, 만료를 검증했다. Google 원본의 두 탭을 100% 배율에서 확인하고 주변 값·유효성 검사가 유지됨을 대조했다.

검증 자료는 `Logs/SpiritDeerLifeReturn`에 저장했다. `verify.py`로 로컬/Google 10셀과 런타임 수치를 재대조할 수 있다. 런타임 최종 캡처와 시간 기록은 `RuntimeFinal`에 있다.
