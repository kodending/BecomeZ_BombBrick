# 버섯 기본 스킬: 포자 군락 가스 개편

## 확정 동작

- 포자가 목표 위치에 도착하면 해당 지점에 가스를 생성한다. 생성된 영역은 이동하지 않는다.
- 반경 2타일, 지속 4초, 확산 0.35초, 사거리 4.5타일, 쿨타임 9초.
- 생성 후 0.5초부터 0.5초마다 ATK 20% 피해를 8회 적용한다. 기본 총량 160%.
- 현재 범위 안의 적만 피해를 받는다. 동일 시전자의 겹친 가스는 대상마다 0.5초에 한 번만 피해·회복한다.
- 네이티브 ParticleSystem의 저해상도 입자가 낮게 부유하며 범위 안에서 개별적으로 흐른다. 0.35초 확산 후 마지막 0.45초에 흩어져 사라진다.
- 사용자 후속 요청: 가스와 포자 입자는 캐릭터 앞에 렌더링한다. 가스 입자 알파 14~20%, 포자 알파 40%로 캐릭터가 비쳐 보이도록 한다.
- 전투 시간으로 입자를 구동하여 일시정지 시 가스 움직임과 피해가 함께 멈춘다. 전투 종료·초기화·시전자 사망 시 정리한다.

| 개체 | 기본 가스에 연결된 효과 |

| 버서스 | 같은 구름의 반복 적중 피해 +20%, 최대 +40%. 8회 전부 적중 시 ATK 212%. |
| 독시룸 | 생성 후 1·2·3초에 범위 안의 적에게 ATK 20%씩 추가 독 피해. 기본 가스 포함 ATK 220%. |
| 루미룸 | 범위 안 아군을 0.5초마다 회복. 8회 모두 받으면 ATK 105% 회복. 동일 시전자 중첩 방지. |
| 킹모어 | 피해에 4초 번식 표식. 표식 중 사망 시 생성된 소형 버섯이 1.2초 후 반경 1타일에 ATK 27.5% 피해. 재증식 없음. |

3등급 선택 스킬 분기와 기존 소형 버섯 공용 처리는 유지한다. 이번 개편 범위는 기본 포자 군락이다.
