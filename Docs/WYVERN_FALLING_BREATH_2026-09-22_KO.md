# 와이번 3등급 두 번째 특성 — 낙하 브레스

기존 용익 선회를 교체한다. 저장 호환성을 위해 ID `trait_wyvern_wing_sweep`와 상수 `WingSweep`는 유지한다. 기본 공격은 관통 광선, 기본 스킬은 속성 브레스다.

## 동작과 수치

- 사거리 5.5타일. 준비 0.35초, 쿨타임 8.5초.
- 시전 시 주 대상 주변 반경 4타일의 적들을 무작위 순서로 선택한다. 한 순회에서 모든 후보를 선택한 뒤 다시 선택하므로 소수 적에게만 편중되지 않는다.
- 6발, 0.26초 간격. 선택한 적 위치 주변 최대 0.65타일 산포. 착탄점은 선택 지역과 전투 영역 안에 고정되고 이후 대상을 추적하지 않는다.
- 각 착탄 0.8초 전부터 픽셀 그림자가 점차 커지고 진해진다. 그림자의 최종 반경과 실제 피해 반경은 1타일로 일치한다(기존 범위 배율 적용).
- 화면 우측 상공에서 좌측 아래로 0.55초간 처음에는 느리게, 착탄에 가까워질수록 가속 낙하. 화면 밖 시작 위치를 현재 카메라로 계산한다. 아군/적군 모두 요청한 우측→좌측 방향이다.
- 착탄 순간에만 공격력 70% 광역 피해. 한 적이 6발을 모두 맞으면 420%. 발당 1회, 아군 피해 없음. 타일 반경에 기존 적 충돌 반경을 더해 판정한다.
- 본체의 스킬 애니메이션과 짧은 상공 토출을 사용한다. 본체 확대/축소 없음. 낙하탄은 속성색 구름 입자와 꼬리, 충돌은 반경까지 빠르게 퍼지는 파편 입자다.

## 기존 시스템 연결

- 독 1중첩, 냉기 2중첩/기존 이동 방해 대상 1초 빙결, 번개 전달은 적 하나당 시전당 한 번이다.
- 이그비르는 포격 종료 후 실제 착탄 지점들에 4초 화염 지대를 남긴다. 초당 공격력 20%, 4회. 겹친 지대는 피해를 중첩하지 않는다. 바람에 막힌 탄은 화염 지대도 남기지 않는다.
- 일시정지/빙결은 시전 시간을 정지한다. 강제 이동/행동 방해/사망/전투 재시작은 남은 시전을 취소하고 이펙트를 정리한다. 기존 선회의 방해 면역은 제거한다.
- 적 그리폰 바람과 낙하 경로가 교차하면 투사체가 전장 밖으로 튕겨 나가며 착탄 피해가 취소된다.
- 4등급의 브레스 재발동은 기존 기본 브레스 경로를 유지한다.
