# TFT 계수 조사와 11계열 성장 구조 제안

후속 결정: 주문력 추가 제안은 채택하지 않는다. 공격력·최대 체력·방어력 중 개체별 주계수를 정하며 성격은 AI 행동만 담당한다. 최신 분류 초안은 [44종 개체별 주계수 제안](SpeciesScalingIdentityProposal.md)을 따른다. 아래 TFT 조사와 AP 제안은 이전 검토 기록이다.

조사 기준: 2026-09-18. Riot 공식 자료의 계산 사례와 현재 프로젝트 코드를 비교했다. 18.2 패치 사례는 2026-09-09 발표 자료이며, 14.18·15.4 사례는 해당 시점의 설계를 보여주는 과거 사례다. 아래 우리 게임 분류와 공식은 제안이며 전투 코드·능력치·Google DB에는 적용하지 않았다.

## 1. 조사 결과

TFT는 스킬마다 AD, AP, 최대 체력, 방어 능력치 등을 다르게 사용한다. 공격 능력치가 같아도 지속 평타, 순간 스킬 피해, 보호막, 회복처럼 결과가 다르다. 역할·계수·피해 종류·사용 빈도를 별도로 정해야 한다.

### 실제 공식 사례

| 사례 | 확인된 설계 | 시점 |
|---|---|---|
| 르블랑 | 스킬 피해에 AP 계수 | 18.2 |
| 쉔 | 보호막 흡수량에 AP 계수 | 18.2 |
| 타릭 | 보호막에 최대 체력 비례 항, 사용 시 회복에 AP 계수 | 18.2 |
| 뽀삐 | 1성 보호막이 280% AP + 최대 체력 10%, 1차 피해는 250% AD | 15.4 당시 |
| 애쉬 | 추가 화살이 30% AD + 5/8/12% AP의 **물리 피해** | 14.18 당시 |

출처: [Riot 18.2 패치](https://teamfighttactics.leagueoflegends.com/ko-kr/news/game-updates/teamfight-tactics-patch-18-2/), [Riot 15.4 패치](https://teamfighttactics.leagueoflegends.com/ko-kr/news/game-updates/teamfight-tactics-patch-15-4-notes/), [Riot 14.18 패치](https://teamfighttactics.leagueoflegends.com/ko-kr/news/game-updates/teamfight-tactics-patch-14-18-notes/).

계수 계산을 풀면 다음과 같다. 아래 숫자는 이해를 위한 가정이며 현재 우리 게임의 확정 수치가 아니다.

- 300% AD 스킬: AD 30이면 90, AD 45이면 135.
- 300% AP 스킬: AP 100이면 300, AP 150이면 450. AP와 연결되지 않은 일반 평타의 피해는 이 AP 변화로 증가하지 않는다.
- 280% AP + 최대 체력 10% 보호막: AP 100, 최대 체력 1,000이면 380. AP 150이면 520, AP 100에서 체력만 1,500으로 올리면 430.
- 각 항을 계산하고 합산한 뒤 해당 피해 유형의 방어·저항, 증폭 등 후속 규칙을 적용한다. 보호막·회복은 각각의 후속 규칙을 따른다. AP가 물리 피해에도 사용될 수 있으므로 계수와 피해 유형은 동일한 개념이 아니다.
- 성급별 280/330/900% 같은 표는 해당 성급의 계수를 선택하는 것이다. AD 성장과 스킬 계수의 성급 성장을 혼동하면 안 된다.

Riot는 12.14에서 마법사까지 성급 상승으로 평타 피해가 지나치게 커지는 문제를 설명하고, 평타 공격력 성장 일부를 스킬 성장으로 옮겼다. 이 사례는 우리 게임에서 평타와 스킬 성장의 분리가 필요한 이유와 맞닿아 있다. 당시 수치를 현재 TFT 규칙으로 사용하지 않는다. [Riot 12.14 AD 성장 조정](https://teamfighttactics.leagueoflegends.com/en-gb/news/game-updates/teamfight-tactics-patch-12-14-notes/).

### 역할에 맞는 스킬 사용 빈도

2025년 역할 개편은 탱커의 피격 마나, 평타형의 공격 마나, 스킬형의 시간당 마나 등 역할별 자원 획득 경로를 구분했다. 이유에는 광역 피해가 적 후열의 스킬을 빨리 충전시키는 문제와 스킬형도 공격속도 장비에 과도하게 의존하는 문제가 포함된다. [Riot 역할 개편 설명](https://teamfighttactics.leagueoflegends.com/en-us/news/game-updates/roles-revamped-and-item-changes/).

이 글의 처음 역할 목록을 현재 고정 규칙으로 복사하면 안 된다. 15.4에서는 암살자 역할을 전사로 통합하고 전사의 흡혈 보너스를 공격속도 성장으로 변경했다. 우리 설계는 역할에 맞는 자원 획득이라는 원칙을 참고한다. [Riot 15.4 역할 변경](https://teamfighttactics.leagueoflegends.com/ko-kr/news/game-updates/teamfight-tactics-patch-15-4-notes/).

## 2. 현재 우리 게임과의 차이

| 항목 | 현재 코드 | 설계상 의미 |
|---|---|---|
| 공격 능력치 | MonsterDefinition에 attackDamage, 독립 AP 없음 | 주문형 피해도 공격력 성장에 의존 |
| 기본 스킬 산출 | ATK 계수 + 지정된 체력 비례 항 | 주문형의 독립된 피해 기준 필요 |
| 스킬 증폭 | ApplySkillDamage에서 skillPowerBonus 등을 곱함 | AP 계수와 별도 최종 스킬 증폭을 구별해야 함 |
| 스킬 충전 | 시간 경과 + 평타 1회당 전체 쿨의 10% 단축 + 피격 체력 비율에 따른 단축 | 표의 쿨타임이 실제 고정 발동 주기는 아님 |
| 피해 종류 | 물리·화염·냉기·번개, 별도 고정 피해 항 | AP 도입과 속성 체계 변경은 별도 결정 |
| 성장 분배 | 체력·공격력·공속·방어·상태저항 가중치 | AP를 넣을 때 기존 성장 예산 안에서 재배분 필요 |

확인 코드: `MonsterDefinition.cs`, `GameMasterDatabase.cs`의 SkillMasterRow/MonsterGrowthMasterRow, `CombatDamageSystem.cs`의 SkillDamageFormulaResolver/CombatStatFormula, `MonsterAutoBattlePrototype.cs`의 ApplySkillDamage/BeginBasicAttackImpact/ApplyDamage.

현재 tactic=Hunter는 레거시 작성 값이다. 실제 전투 행동은 스킬·성격 등으로 결정되므로, 이 문자열이 같다고 44종의 AI가 모두 같다는 의미는 아니다.

일부 3등급 공통 타격 함수는 ApplySkillDamage를 경유하지 않는다. 호출부의 선적용까지 확인해서 증폭 누락이나 중복 여부를 검증한 후 전환해야 한다. 이 조사에서는 개별 경로의 오류를 확정하거나 수정하지 않았다.

## 3. 분류 제안

몬스터는 주 역할 하나와 필요할 때 보조 역할 하나를 갖는다. 사거리와 성장 계수는 별도 속성이다. '원거리'만으로는 평타 딜러인지 누커인지 구분되지 않고, '누커'만으로는 AD형인지 AP형인지 정해지지 않는다.

| 계열 | 역할 중심 | 주 성장 방향 제안 |
|---|---|---|
| 랩터 | 기동 전사·추격 | AD, 공격속도 |
| 검치 | 단일 제압 전사·고체력 적 압박 | AD, 별도 제한을 둔 대상 체력 비례 피해 |
| 개구리 | 포획·지원 | 스킬 피해·회복·보호 효과의 AP, 스킬 충전 |
| 악어 | 근접 AD 누커 | AD, 스킬 충전; 느린 평타 정체성 유지 |
| 고릴라 | 제어 탱커 | 최대 체력, 방어; 체력 기반 충격과 제한된 AP 보조 항 검토 |
| 마법쥐 | 원거리 AP 딜러·누커 | AP, 스킬 충전 |
| 곰 | 지속 전투 전사·보호 | 공격형은 AD, 방어형은 체력·방어, 지원형 보호·회복은 AP 검토 |
| 늑대 | 근접 연격·분신 딜러 | AD, 공격속도 |
| 아라크네 | AP 제어 딜러 | AP, 스킬 충전 |
| 닌자 고양이 | 침투 암살자 | AD, 치명타; 개체별 AP형은 별도 선택 가능 |
| 티라노 | 전열 광역 누커 | AD 중심, 생존 보조 체력; 고릴라와 주 역할 구분 |

이는 계열의 공통 출발점이다. 같은 계열의 4종을 동일 직군으로 고정하지 않으며 개체 고유 효과·성장 성격으로 주·보조 역할을 확정한다. 현재 11계열에는 후열에서 평타를 주력으로 삼는 전형적인 원거리 사수의 자리가 상대적으로 약하다. 이후 계열까지 포함해 전체 역할 분포를 살핀다.

## 4. 권장 계수 구조

효과마다 필요한 항만 사용한다. 처음부터 모든 스킬에 모든 계수를 혼합하지 않는다.

| 효과 | 추천 산출 형태 |
|---|---|
| 일반 평타 | AD × 평타 계수 |
| AD 스킬 | AD × 해당 스킬 계수 |
| AP 스킬 | 공격력과 독립된 스킬 기준량 × AP / 100 |
| 탱커 피해 | 독립 기준 피해 + 자신의 최대 체력 × 정해진 비율; 필요할 때만 AP 항 추가 |
| 회복·보호막 | AP 항, 최대 체력 항 또는 두 항의 합 |
| 제압·처형 | 별도 대상 체력 항, 계수·상한·발동 조건 명시 |
| 속박·쓰러짐·공포 | 정해진 기본 지속시간과 기존 상태저항 규칙; AP에 자동 연동하지 않음 |

AP 기본 100, 추가 AP +20이면 120으로 읽는 체계를 우리 게임의 초안으로 추천한다. AP 스킬의 기준량은 공격력과 분리해 개체·성장 단계에 맞게 정한다. 현재 공격력 값을 계속 참조한 뒤 AP를 곱하면 AD 의존 문제가 그대로 남는다.

예시: 마법쥐 별탄 1발의 기준 피해를 가정상 10으로 잡으면 AP 100에서 10, AP 150에서 15다. AD를 올려도 그 별탄의 기준 피해는 바뀌지 않는다. 10은 계산 예시이며 확정된 밸런스 수치가 아니다.

체력 기반 피해 전체를 다시 AP로 곱할지는 스킬별로 명시한다. 체력과 AP의 곱을 기본 규칙으로 만들지 않는다. 공격력·AP·체력의 합산과 전 효과 공통 증폭도 구분한다.

기존 스킬 피해 증가 옵션을 AP로 옮길 경우 전환된 옵션을 최종 피해 배율로 한 번 더 적용하지 않는다. 독립 피해 증폭 옵션은 별도 의미와 예산이 필요하다. 장비·증강·영구 성장·회복·보호막 설명을 함께 맞춰야 한다.

충전은 현재의 쿨타임/게이지 표현을 유지하면서 탱커는 피격, 평타 딜러는 공격, 누커·지원은 시간과 전용 충전 능력치의 비중을 달리하는 방안을 검토한다. AP/계수 변경과 충전 변경을 따로 비교해 원인을 알 수 있게 한다.

## 5. 다음 설계 순서

1. 44종 각각의 주 역할·보조 역할·AD/AP/체력 중심 성장 방향 확정.
2. AP, 기존 스킬 증폭, 성장 예산의 관계 확정. 개체별 독립 스킬 기준량과 등급 성장 규칙 정의.
3. 마법쥐(AP), 악어(AD 누커), 고릴라(체력 탱커)를 기준 사례로 비교 설계.
4. 장비 없이 현재 기준 피해를 먼저 맞추고 AD/AP/체력 장비를 각각 넣어 성장 방향 확인. 같은 투자 예산으로 비교.
5. 기본 스킬부터 3등급·4등급·분신·지속 피해·회복·보호막까지 적용 경로 검증.
6. 역할별 충전을 별도 조정하고 단일/3명/6명 대상, 짧은/긴 전투에서 피해·흡수·회복·제어 시간을 함께 비교.
7. 확정 수치와 설명을 로컬·Google DB·번역에 함께 반영.

4등급은 기존의 전투 방식 변화와 연출을 유지하면서 새 성장 규칙에 맞춘다. TFT의 수치 크기나 성급 폭증을 그대로 옮기지 않는다.
