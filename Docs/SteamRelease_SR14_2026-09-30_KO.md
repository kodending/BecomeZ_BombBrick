## 검수용 저장 분리

실제 마을 진입은 프로필을 다시 저장하므로 `-qa-profile SR14` 실행 옵션을 추가했다. 이 옵션을 명시했을 때만 실행 파일 옆 `QAData/SR14/UserData`에 저장하며, 기존 저장을 자동으로 가져오지 않는다. 옵션 없이 실행하면 기존 저장 경로와 동작을 유지한다. 설정(PlayerPrefs)은 공유하므로 검수 중 사용자 설정은 바꾸지 않는다.

이름은 1~48자의 영문·숫자·하이픈·밑줄만 허용한다. 경로 이동 문자열, 빈 값, 중복 옵션을 거부한다. 별도 기능 패널이나 상시 검수 루프는 추가하지 않았다.

검수용 프로필에는 기본 몬스터 8종과 튜토리얼 완료 상태를 준비했다. 결과 전환 확인을 빠르게 하기 위한 원정 fixture는 **12웨이브·목숨 1·1등급 아군 1마리 배치**로 만들었다. 이 인위적인 상태는 전체 게임 완주나 밸런스 검증의 근거가 아니다. ZIP에 포함하지 않는다.

## 메인 화면 새 레이어 수정
