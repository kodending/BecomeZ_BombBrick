# 개구리 선택 음원 적용

2026-09-23. `Assets/Sounds/선택된 사운드/03. 개구리`의 MP3 6개 원본을 보존하고, 적용용 stereo 48 kHz PCM WAV를 `Assets/Resources/Audio/Combat/Frog`에 저장했다. 기존 GameAudio 재생 풀·효과음 볼륨·일시정지·테스트 적군 음소거를 사용한다.

| 원본 | 적용 파일 | 재생 시점 |
|---|---|---|
| 기본스킬_혀_발사.mp3 | launch.wav | 스킬 준비 후 실제 혀 발사 |
| 기본스킬_혀_적중.mp3 | hit.wav | 주 대상 접촉, 추가 갈래 접촉, 일반 착지·회수 타격 |
| 기본스킬_혀_당김.mp3 | pull.wav | 당김·후방 점프 시작, 3등급 메치기·4등급 만물 낚시는 들어 올리기 시작 |
| 3등급_날름도둑_흡수.mp3 | steal.wav | 강화 강탈·공속 대체 효과와 청록빛 회수 연출 |
| 3등급_혀메치기_충격.mp3 | slam.wav | 3등급 메치기·모든 4등급 만물 낚시의 내려찍기 착지, 일반 회수 타격음을 대체 |
| 4등급_만물낚시_갈래.mp3 | branch.wav | 전장 전체의 추가 대상에게 혀가 갈라지는 순간 |

찰나의 낚아채기는 기본음을 공유한다. 추가 대상이 없으면 갈래음은 재생하지 않는다. 4등급 만물 낚시는 발사·전체 당김·갈래·동시 착지의 각 주요 cue를 시전당 한 번 재생하며, 추가 대상들의 동시 접촉도 한 번으로 합친다. 선택한 3등급과 관계없이 모든 4등급이 적들을 공중에 포획한 뒤 사방으로 내던져 서로 다른 위치에 내려꽂고, 동시 착지는 충격음 한 번으로 표현한다. 흡수음은 접촉음과 별도 cue로 재생하면서 기존 시전자별 0.6초 제한으로 추가 대상의 흡수음 중복을 막는다. 중도 취소되면 착지음을 재생하지 않는다. 4등급 내려찍기 강도는 1.2, 기본은 1.0이며 피치는 모두 1.0이다. 영혼 합주의 간소화된 개구리 스킬 메아리도 적중음을 사용한다.

## 파형 보정

Unity PCM 디코딩·파형 측정으로 앞 44~56 ms를 제거해 첫 강한 신호를 시작 약 3 ms 뒤에 두었다. 시작 1 ms·끝 15 ms 페이드와 피크 정리를 적용했다. 메치기의 뒤쪽 작은 파편 신호는 보존했다. 직접 청취나 출력 장치의 지연 측정은 수행하지 않았다.

| 파일 | 최종 길이 | 피크 |
|---|---:|---:|
| launch | 0.176초 | 0.60 |
| hit | 0.196초 | 0.68 |
| pull | 0.334초 | 0.55 |
| steal | 0.336초 | 0.60 |
| slam | 0.484초 | 0.78 |
| branch | 0.416초 | 0.65 |

재생 게인은 기존 Cast 0.24, Impact 0.32, Periodic 0.16을 사용한다. 원본 해시·구간·게인은 `Logs/FrogAudioReview/prepared.json`, 측정과 재현 스크립트는 같은 폴더의 `analysis.json`, `prepare.py`에 있다.
