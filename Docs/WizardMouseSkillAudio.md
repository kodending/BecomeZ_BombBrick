# 콩쥐 계열 선택 음원 적용

2026-09-24. `Assets/Sounds/선택된 사운드/06. 콩쥐`의 MP3 10개를 원본 그대로 보존하고, 적용용 stereo 48 kHz PCM WAV를 `Assets/Resources/Audio/Combat/WizardMouse`에 추가했다. 콩쥐·팥쥐·설쥐·별쥐가 공유한다.

| 원본 | 적용 파일 | 재생 시점 |
|---|---|---|

| 3등급_은하수폭우_분열.mp3 | split.wav | 실제 파편 대상이 있을 때 원본 적중마다 한 번. 두 파편이 중복 재생하지 않음 |

기존 GameAudio 풀과 공격자·클립별 중복 제한을 사용한다. 준비/발사/분열/완성/낙하/성좌는 Cast, 별 타격/광역 폭발/운석 충돌은 Impact 채널이다. 기존 Cast 0.24·Impact 0.32 게인에 이벤트 강도와 사용자 효과음 볼륨을 곱한다. 오망성·초신성의 각 피해 대상에는 기본 별 타격음을 덧붙이지 않는다. 같은 프레임에 도착한 같은 시전자의 파편 타격은 합쳐 재생한다. 평타·크리티컬·사망음은 기존 경로를 사용한다.

## 파형 조정

Unity AudioClip.GetData로 디코딩해 분석했다. 앞의 약 43~44 ms 여백을 제거하고 시작 1 ms·끝 15 ms 페이드를 적용했다. 기본 발사·타격·분열은 짧은 연사에 맞춰 꼬리를 정리했다. 음높이는 모두 1.0이다.

기본 타격 원본의 피크가 약 0.050으로 작아 적용본에서 약 11.68배 보정했다. 이는 피크 기준 정규화이며 직접 청취에 의한 음색·최종 청감 검증은 아니다. 원본 10개의 해시가 서로 다르며, 가공 후에도 원본 SHA-256이 일치한다.

## 검증

- CombatAudioTests·WizardMouseBarrageTests 71/71 통과. PCM 로딩·파형·기존 계열 리소스·기본 별 도착 판정·은하수 파편·오망성·초신성·성좌·사망/초기화 취소를 포함한다.
- 격리 Play 모드 8경로 통과: 기본, 은하수, 오망성, 초신성, 4등급, 준비 중 취소, 초신성 튕김, 성좌 시전자 사망.
- 기존 BeginMagicStarBarrage·스프라이트 시전 이벤트·ResolveMagicStarBarrage와 실제 투사체 도착을 사용했다. 비활성 테스트 전투의 코루틴은 활성 테스트 씬 컴포넌트에서 실행했다. 성좌 시각 컴포넌트의 LateUpdate만 비활성화해 비활성 호스트 검사를 피했고, 실제 SetStars·Fire·피해/소리 콜백은 그대로 실행했다.
- 기본 발사 0.255/0.377/0.498/0.619/0.737초, 타격 5회. 은하수는 원본 적중마다 분열 1회, 파편 두 개의 동시 타격은 한 소리로 합쳐 원본 포함 타격음 10회.
- 오망성 완성·첫 폭발 0.878초, 후속 폭발 1.879/2.880초. 적 3명이 있어도 폭발음은 총 3회.
- 초신성 낙하 1.056초 → 실제 충돌 프레임 1.610초. 튕김 경로에는 충돌음 없음.
- 성좌는 3별까지 형성음 3회, 네 번째 갱신은 형성음 없음. 완성 후 자동 발사 2.002/2.670/3.340/4.007초. 첫 자동 별 비행 중 시전자 사망 시 이후 타격음·발사음 없음.
- 최종 stereo 48 kHz PCM/DecompressOnLoad/Preload 설정 10개 확인. CombatEffectTest 씬의 Edit 모드로 복귀했다.
