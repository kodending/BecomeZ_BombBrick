# 와이번 3등급 세 번째 특성 — 용핵 과열

기존 용핵 포격을 교체한다. 저장 호환성을 위해 ID `trait_wyvern_dragon_core_bombardment`와 상수 `DragonCore`는 유지한다. 기본 공격의 광선과 구분되는 연속 속성 브레스다.

## 동작과 수치

- 0.4초 준비 후 2초간 제자리에서 분사. 사거리 4타일, 폭 1.2타일. 기존 범위 배율 적용.
- 2초 동안 균등한 간격으로 6회 타격. 공격력 30% → 40% → 50% → 60% → 80% → 100%, 총 360%. 방어력 20% 무시. 쿨타임 8.5초.
- 살아 있는 목표를 초당 최대 240도로 추적한다. 목표가 죽거나 사거리를 벗어나거나 타겟 불가 상태가 되면 범위 내 가장 가까운 적에게 남은 타격을 이어간다. 피해 증가 단계는 초기화하지 않는다.
- 브레스 경로상의 적 모두에게 타격한다. 시전 중 적이 범위에서 사라져도 시전 시간은 흐르며, 다시 범위에 들어온 적에게 남은 타격을 사용할 수 있다.
- 본체 확대/축소 없음. 작은 자세 반동, 시간이 갈수록 커지고 밝아지는 소용돌이 입자, 적중 시 옆으로 튀는 속성 파편을 사용한다.
- 개체 효과는 직접 적중한 적마다 시전당 1회: 비브르 독 1중첩(4초·초당 공격력 25%), 이그비르 화상(4초·초당 공격력 20%), 프로비르 냉기 2중첩/기존 이동 방해 대상 1초 빙결, 템비르 주변 적 1명에게 공격력 50% 번개 전달.
