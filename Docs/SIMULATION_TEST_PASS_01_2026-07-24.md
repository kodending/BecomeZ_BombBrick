## 수정한 버그

### SIM-001 자동 시뮬레이션이 증강 선택 화면에서 멈춤

- 증상: Wave 1/5/9에서 증강 선택안이 생성되면 자동 전투 시작 조건을 만족하지 못해 `completedRuns=0` 상태로 정지했다.
- 원인: 일반 원정의 증강·상점·성장 선택 인터미션이 Balance/ML 자동 시뮬레이션에도 그대로 생성됐다.
- 조치: 자동 시뮬레이션 전용 `SuppressSimulationIntermissions()`를 추가했다.
- 적용 범위:
  - Balance 반복 시뮬레이션의 각 trial 준비
  - ML episode 준비
- 차단 대상:
  - 상점
  - 성장 카드 선택
  - 승급 후보 선택
  - 증강 선택 및 선택 연출 상태
  - 증강 reroll 상태

- 패배: 목숨 3에서 2로 감소 → Wave 4 유지 → 재도전 후 결과 문구와 전투 종료 상태 정상 초기화
