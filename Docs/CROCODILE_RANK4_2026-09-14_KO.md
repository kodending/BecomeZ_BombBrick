# 악어 4등급 — 심연 데스 롤

> 이전 설계 기록. 2026-10-22부터 아래 3등급 강화형은 4등급 독립 스킬 **심연 잠항**으로 대체한다. 기존 특성 ID는 저장 호환을 위해 유지한다. 현재 설계는 `Docs/Concepts/CrocodileRank4/Ager_AbyssDive_4Panel_v1.design.txt`를 따른다. 기존 3등급 스킬 자체는 유지한다.

확정: 2026-09-14. 기존 ID `trait_transcend_crocodile_abyss_death_roll`와 이름 유지.

## 선택한 3등급 특성 강화

| 선택 | 4등급 변경 | 유지 |
|---|---|---|
| 먹잇감 포탄 | 충돌·착지 광역 반경 1 → 1.5타일 | 광역 ATK 120%, 쓰러짐 기본 0.6초, 투척 최대 2타일 |
| 회전 분쇄 | 두 번째 광역 ATK 80% → 140% | 첫 광역 ATK 80%, 반경 2타일, 추가 제어 없음 |
| 절대 악력 | 마지막 압착 ATK 320% → 400% | 첫 2타 100%·80%, 마지막 잃은 체력 8%, 마지막만 방어력 50% 무시, 전체 1초 |

이 수치는 기존 피해·상태 저항 보정 전 기본값이다. 선택한 3등급 분기만 강화한다. 3등급을 선택하지 않은 테스트 유닛은 기본 데스 롤에 색상 강조만 적용된다.

기존 4등급의 별도 1.5초 지연 광역(반경 2.5타일, ATK 120%, 쓰러짐), 70% 피해 감소, 준 피해 20% 회복은 제거했다. 아거·킴불·크로갈·타르빌의 종 고유 효과는 유지한다. 공통 초월 스탯도 유지하며, 특성의 명시 반경 1.5·2타일에 공통 광역 20%를 추가로 곱하지 않는다.

리뉴얼한 랩터·검치·개구리 4등급과 공통 초월 보정을 비교하여, 악어는 한 스킬에 공격·회복·피해 감소·제어를 중첩하지 않고 선택 특성의 한 축만 올리는 보수적인 초안으로 확정했다. 실제 조합별 승률 동등성까지 검증한 값은 아니며 플레이 피드백으로 조정한다.

## 연출

기존 0.35초 두 바퀴를 유지하고, 회전 이펙트에 청록색을 입힌다.

- 먹잇감 포탄: 기존 돌·흙 파편 18개에 옅은 금빛을 섞고 착지 Hit를 강조한다.
- 회전 분쇄: 첫 회전의 청록 잔상이 두 번째에 금빛으로 밝아진다. 두 번째 잔상은 안쪽으로만 조금 두꺼워지며 바깥 반경은 그대로다.
- 절대 악력: 압착 잔상에 밝은 청록색과 금빛 Hit를 사용한다. 잔상 크기 1.75 → 1.9, 약 9% 확대. 피해 프레임과 압축·복원 시점은 유지한다.

카메라 진동 세기·시간, 줌, 입자 개수는 변경하지 않는다. 개구리 및 일반 착지 파편도 변경하지 않는다. 바닥 패임·먼지 덩어리·방사형 지면 선을 추가하지 않는다.
