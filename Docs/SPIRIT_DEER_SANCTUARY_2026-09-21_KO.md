# 정령 사슴 기본 성역 개선 — 2026-09-21

버프가 적용되는 순간과 유지 중인 상태를 구분하도록 기본 스킬 「정령의 성역」과 네 개체의 고유 효과를 수정했다.

## 기본 스킬

- 쿨타임 10초, 시전 거리 4.5타일, 반경 2타일, 성역 지속 5초.
- 0.35초 동안 뿔에 빛을 모은 뒤 시전 거리 4.5타일 내 다른 아군 위치에 성역 생성. 다른 아군이 없을 때만 자신에게 사용한다.
- 후보가 여러 명이면 성격별 우선 대상 80%, 나머지 아군 중 균등 선택 20%. 후보가 한 명이면 해당 아군에게 확정 시전한다.
- 빛 물결이 0.38초 동안 퍼지며 닿은 아군에게 회복·정화·버프를 적용한다.
- 모든 해로운 효과를 최초 진입 시 제거한다. 늦게 들어온 대상도 적용되며 같은 성역에 재진입해도 반복 적용하지 않는다.
- 범위 증폭을 포함한 최대 반경은 2.5타일.

| 개체 | 회복량 | 추가 효과 |
|---|---|---|
| 홀리디어 | 시전자 최대 체력 10% | 시전자 최대 체력 8% 보호막 4초, 디버프 면역 2초 |
| 루나디어 | 시전자 공격력 100% + 대상이 잃은 체력 12% | 회복과 정화에 집중 |
| 포레디어 | 시전자 최대 체력 6% | 공격속도·이동속도 20% 증가, 4초 |
| 이클립디어 | 시전자 공격력 60% | 최초 진입 적의 회복량 25%·상태저항 15% 감소, 4초. 디버프 면역 적 제외 |

공통 지원 효과 보정은 기존 `SkillSupportAmount`를 유지한다. 성장 계수는 홀리디어 `MaxHealth × 0.10`, 포레디어 `MaxHealth × 0.06`, 루나디어·이클립디어 `Attack × 1`이며 각 고유 회복식은 위 표를 따른다.

## 연출

기존 픽셀 파티클 소재를 재사용한다. 뿔에 빛이 모이고, 입자 물결이 지면으로 퍼지며, 받는 아군에게 빛이 차오른다. 성역 내부에는 적은 수의 빛 입자가 남다가 사라진다.

홀리디어는 금색 보호 외피, 루나디어는 푸른 회복 빛, 포레디어는 발밑에서 올라오는 초록 입자, 이클립디어는 적에게 내려앉는 보라 입자로 구분한다. 대상 효과는 캐릭터를 따라다니며 보호막 파괴·가속 종료·약화 정화 시 사라진다. 전투 시계를 사용해 일시정지 중 효과 수명도 멈춘다.

3·4등급 특성 자체의 재설계는 다음 단계다. 해당 특성이 호출하는 공통 축복·저주에는 이번 수치와 수신 연출이 적용된다.

## 후속 수정: 아군 우선 타겟

기존에는 자신이 후보에 포함되었고 독립적 성격의 직접 자기 선택, 충동적·신중한 성격의 후보 부재 처리에서도 자신을 선택했다. 다른 아군 후보가 있으면 모든 자기 선택 경로를 제외하도록 공통 성역 타겟 선택기를 수정했다. 자신의 체력이 가장 낮아도 다른 아군이 있으면 해당 아군 위치를 선택하며, 자신이 성역 범위에 함께 들어가는 것은 허용한다. 거리 판정에는 기존 대상 충돌 반경을 반영한다.

| 성격 | 80% 확률로 고르는 우선 대상 |
|---|---|
| 집요함 (`persistent`) | 이전에 선택한 아군, 없으면 체력 비율이 낮은 아군 |
| 침착함 (`calm`) | 체력 비율이 낮은 아군 |
| 도전적 (`challenger`) | 등급·최대 체력이 높은 아군 |
| 복수심 (`vengeful`) | 누적 피해가 많은 아군 |
| 변덕 (`fickle`) | 이전 대상과 다른 아군 |
| 협동적 (`cooperative`) | 성역이 가장 많은 아군을 덮는 위치 |
| 독립적 (`independent`) | 주변 아군이 적어 고립된 아군 |
| 보호적 (`protective`) | 적이 집중해서 노리는 아군 |
| 기회주의 (`opportunist`) | 약화된 적이 주변에 많은 아군 |
| 충동적 (`impulsive`) | 가까운 부상 아군, 없으면 가장 가까운 아군 |
| 신중함 (`cautious`) | 부상 아군 중 적에게서 먼 아군, 부상자가 없으면 전체 후보에서 선택 |
| 대담함 (`bold`) | 적이 많이 모인 위치의 아군 |
| 겁 많음 (`timid`) | 적에게서 먼 아군 |
| 기이함 (`eccentric`) | 가까움·낮은 체력·아군 밀집·적 근접 기준을 시전마다 순환 |

같은 개체·시전 횟수·전투 세대에서 확률 선택이 재현되도록 기존 `StableSeed`와 `System.Random`을 사용한다. 매 프레임 다시 추첨하지 않는다.

관련 테스트 40개 통과: 14개 성격의 아군 우선/자기 대체, 만피 아군·사망·분신·거리 경계, 침착/보호 성격 각 1,000회 선택의 확률 분포, 기존 성역 회복·버프 회귀 검사. Google `Skill_Master!K22,X22` 및 `Localization_Master!D918:E918,I918` 5셀 동기화. 스킬 버전 8, 번역 버전 3. 후속 검증 자료는 `Logs/SpiritDeerTargeting`에 보관한다.
