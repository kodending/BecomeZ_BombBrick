## 판정

**사용자가 승인한 남은 연계 문제 5개를 모두 수정했다.** 활성 로스터는 20계열·80개체다. 앞선 담이·콩쥐 수정에 이어 춘동이·홍아·빙가르·마그릴·모스카의 연계와 공통 출처 판정을 정리했다. 관련 회귀 검사 38개가 통과했고, 로컬 데이터와 기존 Google DB도 일치시켰다.

### 공통 처리

- 독·냉기는 현재 효과에 기여한 시전자와 유효 시간을 추적한다. 마지막 시전자만 바뀌어도 아군 연계가 사라지지 않으며, 원래 아군 효과가 만료되면 자기 효과가 남아 있어도 연계 자격은 사라진다. 피해 귀속과 기존 중첩 수식은 유지한다.
- 노출은 기존 여섯 부여 경로(개체 스킬·3등급·아이템)를 공통 적용 함수로 연결했다. 정화·초기화·만료 시 출처도 지운다.
- 보호막은 실제 잔여량을 갱신하는 보호막의 제공자를 저장한다. 더 약한 자기 보호막이 아군 보호막 출처를 덮어쓰거나 반대 경우로 잘못 판정하지 않는다.

## 의도된 차이로 유지한 항목

- 닌자 3등급의 설묘 냉기 횟수, 홍련의 즉시 양끝 피해 → 화상, 순동이의 독 적용 시점은 각 리뉴얼 문서에 명시되어 있다. 이번 감사에서 기본 스킬과 똑같이 되돌리지 않았다. 다만 개체 고유 설명만 읽으면 3등급에서 달라지는 내용을 알기 어려운 점은 남는다.
- 4등급 추가 공격마다 고유특성을 무조건 다시 발동시키지는 않는다. 기본/선택한 3등급의 발동을 유지하는지, 추가 공격이 재귀적으로 특성·소환·처치를 중복 발동시키지 않는지 구분해 확인했다.
- 사마귀 새끼는 개체 고유특성과 선택한 3등급을 상속하되 4등급 재탈피는 상속하지 않는다. 실인형은 고유특성을 복사하지 않는다. 합주 영혼은 고유특성을 복사하되 전용 지원 효과와 지속시간 보정을 사용한다.
