# Steam 출시 전 준비 점검 — 2026-09-25

## 2026-10-18 최신 확정 방향 — 유료 얼리 액세스 공개 후 확장

**이 절이 이전의 즉시 정식 판매 계획과 전체 콘텐츠 무료 데모 우선 계획을 대체한다.**

### 확정한 방향과 미정 항목

- 출시 방식은 **유료 Early Access**다. 현재 제공되는 게임을 판매하고, 피드백을 받으며 콘텐츠와 시스템을 확장한 뒤 정식 버전으로 전환한다.
- 한국 판매 **목표 가격은 3,500원**이다. Steam 가격 입력·승인·해외 통화 가격·정식판 가격·할인은 미확정이다.
- 현재 탐험 콘텐츠 전체를 얼리 액세스의 기준 범위로 삼는다. 구현 자료상 5지역·4난이도·지역당 12Wave·80종·8동료 편성과 수집·성장·합성·포획·영구 연구가 있다. 모든 범위의 최신 완주 검증 완료를 뜻하지 않는다.
- 이전에 정한 현재 콘텐츠 전체 무료 데모 우선 공개는 진행 기준에서 제외한다. 별도 무료 체험판의 제작 여부와 범위는 이후 결정한다.
- 유튜브 개발일지와 Steam 커뮤니티에서 변경 내용과 이용자 피드백을 공유하는 방향이다. 펀딩·후원 보상 제작은 이번 출시의 필수 단계로 잡지 않는다.
- 현재 빌드 기준 버전 표기는 0.1.0이다. 얼리 액세스 공개일·개발 기간·정식 전환일·공개 업데이트 주기는 미정이며, 이번 문서 변경으로 게임의 버전이나 규칙을 바꾸지 않는다.

### 2. 얼리 액세스 공개 후 — 업데이트 권장 순서

아래는 날짜나 기능 완료를 보장하는 약속이 아닌 개발 목표와 순서다. 각 단계는 시범 적용 → 테스트 → 이용자 피드백 → 배포를 거치고, 우선순위 변경은 공개한다.

| 단계 | 개발 목표 | 완료 판단 |
|---|---|---|
| U-01 | 이동감 | 가속·감속·방향 전환으로 스케이트처럼 이어지는 움직임을 만든다. 사거리·충돌·가까운 적과 교전 유지가 흔들리지 않는지 확인한다. |
| U-02 | 연계 패시브 | 발동 조건·이벤트 순서·재발동 대기·중첩/연쇄 한계를 정한다. 대표 조합부터 상호작용이 보이게 하고 무한 발동·과도한 피해 누적을 검사한다. 기존 특성과 저장의 이관 정책도 정한다. |
| U-03 | 필살기·액션감 심화 | 현재 4등급 스킬을 기반으로 계열별 준비·절정·명중·회복을 확장한다. 8대8에서 대형 연출의 우선순위·중복 간격·가독성을 검증한다. U-02와의 규칙·타이밍 변경을 함께 정리한다. |
| U-04 | 성격별 ML 전투 행동 | 6성격의 관측·행동·보상과 기본 교전 제한부터 정의한다. 작은 보호/협공/후퇴 상황 학습 뒤 지역·조합·장비 범위를 넓힌다. 동일 시드의 기존 규칙 AI와 A/B 비교하여 성격 행동 차이와 전투 품질을 검증한다. 훈련량 자체를 완료 기준으로 삼지 않는다. |
| U-05 | 점수 모드 | 제한 시간·웨이브 등 핵심 규칙과 점수 기준을 먼저 결정하고, 한 판 종료·점수 정산·재도전으로 완결한다. 온라인 리더보드와 서버 운영은 이번에 확정하지 않았다. |
| 정식 전환 | 핵심 목표와 안정성 마감 | 현재 플레이 경험의 완결성, 광고/상점과 구현의 일치, 저장·진행·지원 환경과 콘텐츠 검수를 기준으로 판단한다. 정식 가격과 날짜는 별도 결정한다. |

ML은 이동·패시브·필살기의 주요 전투 규칙을 정한 뒤 훈련 조건을 고정한다. 단계별 공개 범위는 테스트 결과와 이용자 피드백에 따라 조정한다. 긴급 버그 수정은 기능 로드맵보다 우선한다.

### 3. 업데이트와 저장·소통 원칙

- 현재 수집·편성·탐험의 기본 경험을 제공하면서 전투 시스템을 확장한다. 대규모 변경은 테스트 버전에서 먼저 확인하고, 정상 플레이 가능한 공개 버전을 유지한다.
- 수집 몬스터·연구·해금의 이관을 우선 검토한다. 업데이트로 저장 호환 문제가 예상되면 판매 안내와 업데이트 전 공지에 반영한다. 실제 무손실 이관·초기화 방지 보장은 아직 검증하지 않았다.
- 새 탐험마다 성장·등급·장비가 초기화되는 기존 규칙과 업데이트에 의한 저장 호환 문제는 구분해서 설명한다.
- 업데이트마다 바뀐 내용·바꾼 이유·조합에 주는 영향·알려진 문제를 기록한다. 유튜브는 한 개선점의 전후 비교와 피드백 반영 과정을 중심으로 준비한다.
- 현재 기능과 개발 목표를 분리하고, 상점 Q&A를 실제 상태에 맞게 갱신한다. 확정되지 않은 일정·모든 의견 반영·매출 규모를 약속하지 않는다.
- 이미 발사한 투사체/원거리/장판의 독립 수명, 와이번의 시전자 종속 브레스 예외, 결과창 즉시 표시와 잔여 사운드·이펙트 자연 종료, 다음 Wave 초기화를 보존한다. 흔들림·섬광 감소 옵션도 유지한다.

### 4. 현재 코드·기존 자료와의 연결

[CombatCameraDirector](../Assets/Prototype/CombatCameraDirector.cs)에는 연출 기반이 있고, [CombatFlashPresentation](../Assets/Prototype/CombatFlashPresentation.cs)에는 섬광 감소 설정이 있다. 현재 실전은 automaticFraming:false로 초기화하며 일반 스킬 보고의 흔들림 값은 0이다. EA-01은 기존 시전/명중 훅에서 박자와 반응을 다듬고, 대형 흔들림의 공통 간격·우선순위 및 반복 배경 Pulse를 검토하는 데서 시작한다. 피해량·시전 시간을 일괄 변경하거나 매 타격에 전역 시간 정지를 추가하는 방식으로 시작하지 않는다.

현행 [BombBrickBalanceAgent](../Assets/Prototype/BombBrickBalanceAgent.cs)는 전투 전 배치를 학습하며 Battle 단계의 행동 입력을 적용하지 않는다. [현재 6성격](PersonalityCombat.md)은 규칙 기반 반응이다. 전투 중 성격 ML은 별도 개발이며 기존 모델의 재학습 횟수만 늘려 해결된 것으로 표기하지 않는다.

## 2026-10-17 이전 정식 출시 계획 기록

사용자 확정: **첫 Steam 출시는 0.1.0 정식 출시**이며 현재 콘텐츠 범위를 완성품으로 판매한다. Steamworks는 아직 등록 전이고 App ID는 미발급 상태다. 얼리 액세스 관련 상점 문구·설문은 이번 출시 범위에 포함하지 않는다.

현재 기준 후보는 [영어 UI 마감 배포 ZIP](../Builds/BecomeZ_WildCrew_Windows_20261017_EnglishUi.zip)이다. Windows x64 비개발 빌드·LZ4 압축·패키지 검사를 마쳤으며 빌드 오류·경고는 모두 0개다. SHA256은 `3fd164aa89d6215356f5eb7de746f44178109f9b40b51ea7b8b70f13a3bd9421`이다. 이전 FreshStart 빌드의 신규 프로필 검증 기록은 유지하되, 이번 영어 UI 작업에서는 사용자가 플레이한 실제 저장 5파일을 초기화하거나 수정하지 않았다. 최신 후보의 신규 튜토리얼부터 전체 지역·난이도 진행과 실제 Steam 설치·업데이트 검증은 출시 전 완료 기준으로 남는다. 최신 근거는 [영어 UI 통합 검증](../Logs/EnglishUiReleaseQA/20261017/verification.json), [빌드 보고서](../Logs/EnglishUiReleaseQA/20261017/EnglishUi/build-report.json), [패키지 검사](../Logs/EnglishUiReleaseQA/20261017/package-verification.json)다.

**Steam 연동은 필수와 선택을 나누기**

현재 Assets/Packages에서 Steamworks 연동 코드·관련 파일을 찾지 못했다. 로컬 VDF 배포 설정도 발견하지 못했지만 Steamworks 웹 관리 화면에서 설정한 내용은 확인하지 못했다.

- Steamworks API를 게임에 연결하는 것 자체는 출시 필수 조건이 아니다. 도전과제·클라우드·패드·리더보드를 한꺼번에 만들 필요는 없다. [Steamworks API 공식 안내](https://partner.steamgames.com/doc/sdk/api?l=english)
- 클라우드는 수집 진행을 오래 보존하는 이 게임에 권장한다. 다만 Auto-Cloud는 웹 설정만으로도 가능하므로 API 코드가 없다고 미설정으로 확정할 수 없다. 현재 로컬 저장은 OS 사용자 아래 공용 Profiles/default 구조여서 같은 Windows 계정에서 Steam 계정을 바꾸는 경우의 분리가 필요하다. 다른 PC 복원·충돌·오프라인 후 재연결까지 확인하고 지원 표기를 결정한다. 화면 해상도 같은 기기 전용 설정 및 개발 중 만든 복구 보관 폴더까지 통째로 동기화하지 않는다. [Steam Cloud 공식 안내](https://partner.steamgames.com/doc/features/cloud?l=english)
- 도전과제는 수집·지역/난이도 클리어와 잘 맞는 선택 기능이다. 출시를 지연시킬 정도로 범위를 크게 잡을 필요는 없다.
- 별도 로그인 서버, 온라인 계정, 멀티플레이, DRM, 거래 카드, 리더보드는 현재 게임의 첫 출시를 위한 기본 필수 기능으로 보지 않는다.
