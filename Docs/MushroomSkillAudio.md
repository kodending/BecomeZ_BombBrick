# 버서스 계열 선택 음원 적용

기존 GameAudio 음성 풀·효과음 볼륨·적군 음소거 설정을 사용한다. Resonance/Bloom/King/Sprout은 Impact, 나머지는 Cast다. 원본 피치 1.0, 루프 없음. 가스 확산 강도 0.75, 분출 0.8, 착생 0.85, 공명 0.85, 전이 0.8, 발아 0.85. 약한 메아리 발사·확산은 각각 0.6·0.5다. 번식으로 생긴 작은 균왕의 등장음은 0.7이다.

광역 대상 수만큼 소리를 겹치지 않으며 지속 피해·독 피해·회복 틱은 별도 소리 없이 유지한다. 공명은 기존 시전자별 0.7초 간격과 최대 6회 제한을 따른다. 균왕은 16회 피해 틱과 4회 분출음을 구분한다. 긴 프레임에서 건너뛴 분출음을 한꺼번에 몰아 재생하지 않는다.

면역으로 부착이 거절된 왕관에는 착생·성장·개화음이 없다. 침식이 숙주를 처치해 즉시 개화했다면 뒤늦은 성장음을 겹치지 않는다. 다음 대상이 없으면 전이음도 없고, 이동 도중 시전자 사망·전투 초기화로 번식이 취소되면 발아음도 없다. 균왕 사망 후 분출음이 계속되는 루프나 독립 타이머는 없다.

기본공격·크리티컬·사망의 공통 사운드와 전투 수치·스킬 판정은 유지한다. 사운드 연결 작업으로 Google DB 수정은 없다.

## 음원 준비

Unity AudioClip.GetData로 읽은 원본은 모두 48 kHz stereo, 0.528초이며 10개 파일의 내용은 서로 다르다. 적용본은 48 kHz stereo 16-bit PCM, DecompressOnLoad·Preload. 시작 여백 약 44~124 ms를 정리하고 피크·길이를 조정했다. 시작 1 ms·끝 15 ms 페이드로 클릭을 방지했다.

적용 길이: Launch 0.136초, Spread 0.36초, Resonance 0.28초, Attach/Grow 각 0.23초, Bloom 0.236초, King 0.40초, Breath/Sprout 각 0.33초, Transfer 0.30초. 파형 측정에 근거하며 직접 청취에 의한 최종 청감 평가는 아니다.

원본 해시·가공 수치·재현 스크립트는 `Logs/MushroomAudioReview/prepared.json`, `prepare.py`, `decoded.txt`에 보관한다.
