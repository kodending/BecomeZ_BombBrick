# SR-16 — 전체 진행 및 UI·UX 검수

2026-09-30. **진행 중.** 사용자가 직접 플레이하며 수정 목록을 전달하고, 목록별로 수정·확인한다. 전체 진행 완료 판정과 밸런스 검증은 이번 부분 수정에 포함하지 않는다.

## 1차 — Boot·메인화면

1. Pang 로고 마우스오버 색상 반응 제거: 공통 `BombBrickUiTheme.Label`에서 일반·호버 색상에 동일한 지정 색상을 적용하고 사용 후 스타일을 복원한다. 버튼의 호버 동작은 유지한다.
2. 메인화면의 별도 문의 버튼 제거. 게임 도움말·크레딧을 같은 너비의 두 칸으로 배치했다. 도움말 안의 문의·오류 신고 페이지는 유지한다.
3. 메인화면의 “보유 몬스터와 원정 기록은 유지됩니다.” 문구 제거.
4. 설정의 “언어는 즉시 적용됩니다. 번역 문구는 Google DB와 동기화됩니다.” 문구 제거. 언어 전환 및 저장 동작은 유지한다.

검증: Unity 컴파일·콘솔 오류/경고 없음, `GameFrontendTests` 25/25 통과(작업 ID `64f09e11b5834473b582f37b33fb07fe`). Editor 1920×1080 실제 화면에서 메인 메뉴·언어 설정·도움말 문의 페이지를 확인했다. 로고 호버는 공통 글자 표시 경로의 스타일 처리로 수정했으며 실제 포인터 조작 재검수는 사용자 플레이에서 확인한다.
