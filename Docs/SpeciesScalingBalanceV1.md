2026-09-18. 코드·로컬 DB·기존 Google DB 반영 완료. 공격력 35종 / 자신의 최대 체력 6종 / 현재 방어력 3종. 성격은 AI를 담당하며 계수를 바꾸지 않는다.

## 적용 계수

`스킬 위력 = 현재 주능력치 × 개체 환산율`. 기본·3등급·4등급에서 같은 위력을 사용하고, 계열 스킬의 각 타격 배율을 곱한다. 공격력형은 위력=공격력. 화면 툴팁에 주계수·환산율·현재 위력을 표시한다. 이것은 새 능력치나 별도 주문력 육성 항목이 아니다.

전투 체력 ×1.8, 방어력 ×2.0 적용 후 수치. 테라칸·아이언쿠마의 위력은 자신의 스킬 방어 증가 35%가 활성화된 상태. 기본 스탯 자체는 변경하지 않았고 9종 성장 비중을 주계수에 맞춰 조정했다. 모든 성장 가중치 합계는 100이다.

|---|---|
| 테라칸 | 3타 합계 현재 방어력 45% 물리 + 대상 최대 체력 20% 고정 피해 |

| 담이 | 투지 중 평타 행동당 최대 체력 1.3% 추가 / 주변 최대 체력 1.95% |

고릴라 수치는 원래 있던 최대 체력 5% 항을 합한 값이다. 일반 평타는 공격력 100%를 유지한다. 원래 있던 대상 체력 피해·피해 비례 회복·고정 버프·군중 제어는 별도 효과다.

## 중복 강화와 보호막 조정

- 체력·방어형 스킬에는 공격력 증가/감소가 섞이지 않는다. 능력치 투자에 따라 해당 주계수만 성장한다.
- 곰의 체력·방어형 백련타는 기본공격 70% / 기본공격 30%+위력 40% / 위력 150%로 분리한다. 세 타격에 걸쳐 원래 평타는 총 100%, 추가 스킬 위력은 총 190%. 투지 20% 추가와 고유 효과는 첫 타격에 한 번만 적용한다.
- 아이언쿠마 고유 추가 피해: 현재 방어력 75% → 35%. 방어 성장과 공격이 동시에 증가하는 중복 이득을 줄였다. 방어 증가 35%는 유지한다.
- 테라칸 종료 보호막: 최대 체력 12% → 방어력 60%. 붙잡기 방어 버프가 끝난 후 산출한다.
- 아이언렉스 보호막: 적중 대상당 최대 체력 4%, 최대 12% → 현재 방어력 20%, 최대 60%. 기본·3등급 공통이며 5초 유지한다.
- 곰 4등급 공포는 추가 피해 없이 유지한다. 기존 연출·범위·제어 시간은 이번 계수 작업에서 변경하지 않았다.

## 검증과 DB

- Unity 관련 EditMode 테스트 238/238 통과. 새 검증은 9종 실제 능력치 연결, 공격력 투자 분리, 3·4등급 공통 피해 경로, 곰 강화 평타/백련타 중복 방지, 방어 보호막 상한을 포함한다.
- 종별 성장 0/3/9/12 × 44종 × 기준/체력25%/공격25%/방어25% = 704개 수치 비교를 CSV로 기록했다. 성장 예산 80, 균일 개체값·장비 없음 기준의 수학적 민감도 비교이며 승률 시뮬레이션이 아니다.
- 실제 Google 성장 CSV 구조로 80행 재수입: 등록44, 체력6, 방어3, 가중치 합계 오류0. 나머지 미개편 종은 이전 공격력 동작을 유지한다.
- Monster_Growth_Master의 Y:AA에 skill_scaling_stat, skill_scaling_ratio, scaling_version 추가. 성장249 + Skill8 + Trait24 + Localization48 = 총329셀. 반영 후 329셀 전부 재조회 일치.
- 최신 티라노 3·4등급 설명도 실제 코드와 일치하도록 갱신했다. 수정 전후 데이터·정확한 셀 변경 목록과 요청은 Logs/SpeciesScaling에 보관한다.

이번 결과는 수치·기능 검증을 마친 첫 밸런스다. 팀 조합별 승률·장비 최적 조합·장기 전투의 광역 적중 수를 포함한 전체 메타 균형을 보장하는 결과는 아니다. 특히 아이언쿠마의 지속 피해 감소와 체력형 탱커의 장기 생존 가치는 플레이 결과로 추가 조정한다.
