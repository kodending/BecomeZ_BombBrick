# 검치 선택 음원 적용

2026-09-23. `Assets/Sounds/선택된 사운드/02. 검치`의 MP3 5개를 사용한다. 원본 파일은 보존하고 적용용 stereo 48 kHz PCM WAV는 `Assets/Resources/Audio/Combat/Sabertooth`에 저장했다.

| 원본 | 적용 파일 | 재생 시점 |
|---|---|---|
| 기본스킬_엄니_시작.mp3 | start.wav | 엄니 고정 시전 시작 |
| 기본스킬_엄니_타격.mp3 | bite.wav | 실제 세 번의 물기 타격 |
| 3등급_먹잇감몰이_끌기.mp3 | drag.wav | 실제 끌기 이동 동안 반복, 종료·중단 시 정지 |
| 3등급_피의역류_맥동.mp3 | reflux.wav | 역류 피해가 실제 전달됐을 때 |
| 4등급_절대포식_마무리.mp3 | finish.wav | 대포식의 한 번 강한 물기에서 재생 |

숨통 끊기는 기본 시작·타격음을 공유한다. 먹잇감 몰이와 피의 역류는 기본음을 유지하면서 각각 이동·피해 전달 이벤트에 전용음을 추가한다. 역류음은 시전자별 최소 0.6초 간격으로 제한한다. 4등급 대포식은 선택한 3등급 강화 대신 전용 들숨·끌기·고정·마무리 동작을 사용하고, 한 번의 강한 물기에 마무리음을 재생한다.

## 재생과 파형 보정

Unity PCM 디코딩과 파형 측정으로 시작 지연·피크·끝부분을 조정했다. 직접 청취를 통한 음색 평가는 수행하지 않았다.

| 파일 | 시작 제거 | 최종 길이 | 피크 |
|---|---:|---:|---:|
| start | 37.90 ms | 0.232초 | 0.60 |
| bite | 53.02 ms | 0.177초 | 0.68 |
| drag | 39.04 ms | 0.489초 | 0.50 |
| reflux | 44.06 ms | 0.256초 | 0.50 |
| finish | 87.63 ms | 0.342초 | 0.78 |

약한 꼬리를 정리하고 시작 1 ms(끌기 5 ms), 끝 15 ms 페이드를 적용했다. 음높이는 1.0배다. 게인은 시작·끌기 0.24, 타격·마무리 0.32, 역류 0.16이며 사용자 효과음 볼륨과 이벤트 강도를 곱한다. 강도는 첫 두 물기 0.9, 일반 마지막 물기 1.1, 대포식 1.2, 끌기 0.7, 역류 0.8이다.

기존 GameAudio의 12개 음성 풀을 사용한다. 반복음 정지는 시전자 ID·클립·loop 상태가 모두 일치하는 슬롯에만 적용하므로 재사용된 다른 개체의 소리를 끊지 않는다. 내부 전투 일시정지, 끌기 종료·중단·사망, 전투 종료·초기화 시 끌기음을 정리한다. 슬롯을 일반 타격에 재사용할 때 반복 설정을 해제한다.
