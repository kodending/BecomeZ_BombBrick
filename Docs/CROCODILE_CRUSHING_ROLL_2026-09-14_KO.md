# 악어 3등급 두 번째 특성: 회전 분쇄

역회전 지옥을 교체한다. 저장 ID `trait_crocodile_reverse_hell`을 유지하여 기존 선택 개체에도 적용한다.

- 기본 데스 롤의 주 대상 100% → 80% → 180% + 당시 잃은 체력 8%를 유지한다. 기존 추가 역회전 3타·1.6초 구속·사망 시 대상 이전은 제거한다.
- 접촉 0.08초 후 0.35초 두 바퀴. 각 회전 완료에 주 대상의 지면 위치 중심 반경 2타일 다른 적 모두에게 ATK 80%, 최대 두 번. 몸체 반경과의 접촉까지 포함한다.
- 타격마다 범위를 다시 검사한다. 주 대상·아군·사망·비타겟·먹잇감 포탄 비행 중인 적은 제외한다. 주변 피해에는 잃은 체력 추가 피해가 없으며, 스킬 피해 보정은 적용한다.
- 주변 적에게 추가 경직·쓰러짐·밀치기를 부여하지 않는다. 기존 개별 Hit, 흰 피격 반짝임, 시각 전용 0.12 이동량의 짧은 움찔 반응을 재사용한다.
- 지면 위 0.55 높이에 실제 반경까지 뻗는 굵은 두 회전 잔상을 표시한다. 회전과 피해가 같은 진행도를 사용하며 큰 프레임 간격에서도 두 타격을 누락하지 않는다. 외곽의 작은 파편이 퍼지고 마지막 압착에서 전용 카메라 진동을 한 번 요청한다.
- 바닥 링·방사형 선·흙 패임을 생성하지 않는다. 사망·위치 행동 중단 시 남은 회전 피해와 회전 잔상을 취소한다. 기존 개별 피격 효과는 짧은 수명을 마치고 소멸한다.
- 킴불의 실제 피해 기반 회복은 주변 피해도 포함한다. 크로갈의 시전 보호막은 1회, 아거의 스킬 중 피해 감소와 타르빌의 고유 표식은 유지한다.
