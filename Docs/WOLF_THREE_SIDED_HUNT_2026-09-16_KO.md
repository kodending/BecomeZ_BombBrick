# 늑대 기본 스킬 — 삼면 사냥 연출 개선

최신 승인 흐름: 타겟 중심 삼각 포위 → 본체 돌진 → 두 잔상 직선 관통 → 본체의 착지 거리만큼 적 뒤에 정지 → Idle → 픽셀 파티클 소멸.

- 본체 준비 약 0.1초, 기존 0.12초 돌진 및 0.18초 간격 3회 적중 유지.
- 준비 단계부터 본체의 현재 출발 위치를 기준으로 같은 반경의 120도·240도 위치에 잔상 2개 표시. 세 꼭짓점의 중심이 타겟과 일치한다. 스킬 0번 프레임으로 대기하고 도약 시 2번 프레임으로 전환한다.
- 잔상은 0.18초 동안 직선으로 타겟에 도착하며 알파가 0.42에서 1로 증가. 접촉 후 같은 직선을 따라 적 뒤로 0.18초에 통과한다. 이동 거리는 각 잔상 출발 시 본체와 타겟 사이의 실제 착지 거리로 정하며, 긴 접근 거리만큼 반대편까지 달리지 않는다. 마지막 접촉 0.04초 유지.
- 반대편 도착 후 돌진하던 방향을 유지하며 원본 Idle 애니메이션을 0.28초 재생한다. 적 쪽으로 돌아보지 않는다. 이때 위치는 고정하고 Idle 스프라이트의 텍스처·UV 영역도 함께 전환한다.
- Idle 후 각 잔상에서 실제 픽셀 파티클 24개를 흩뿌린다. 몸은 0.12초 동안 분해되고 파티클은 0.28~0.44초 동안 불규칙하게 퍼져 소멸. 소멸 단계 0.46초 후 오브젝트와 자식 파티클 정리.
- 큰 송곳니 도형 제거. 32×32 Point 프레임의 작은 백색 중심 섬광과 진행 방향으로 뻗는 청록빛 파편으로 교체. 0.12초 재생, 세 번째 타격 1.15배. 효과는 적중 위치에 남고 방향별 시각적 반동을 적용한다.
- 설랑 청백색, 홍아 마지막 붉은 타격, 월영 보라색 잔상 유지. 기존 고유 특성과 3등급 피해 규칙 유지.
- 준비·돌진·연타 도중 위치 행동이 중단되면 남은 잔상과 타격 취소. 사망·전투 교체 시 유효성 검사로 잔상 정리.
- 기존 PixelCombatEffect 풀·잔상 컴포넌트·실루엣 셰이더 재사용. 새 셰이더 속성은 기본 0이어서 곰 연출에 영향 없음.

## 데이터

기본 쿨타임 8.5초, 사거리 4.5타일, ATK 60% × 3회 = 180%, 적중 간격 0.18초 유지.
로컬/Google DB에 기록된 전투 수치와 효과 설명을 바꾸는 변경은 없다. 준비 동작과 픽셀 연출은 런타임 표현만 수정한다.
