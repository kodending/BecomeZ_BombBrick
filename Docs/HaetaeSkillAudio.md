기본/일갈 타격과 정화는 캐스트별 한 번이다. 정화 대상이 없으면 정화음이 없고 여러 아군의 정화가 순서대로 일어나도 중복되지 않는다. 천벌은 첫 예고에 새 준비음을 한 번, 첫 실제 낙뢰에 기존 PixelHaetaeThunder.ImpactClip을 한 번 재생한다. 낙뢰 타격에 기본 Hit를 더하지 않는다. 신수의 위압은 전개와 5개 파동을 사용하며 기본 포효·대상별 Hit·무한 유지음은 겹치지 않는다. 메아리는 준비 없이 기본 포효·접촉·정화를 강도 0.45로 재사용한다.

심판의 일갈이 임시로 공유하던 곰 포효 연결을 제거했다. 새 일갈 음원을 전용 채널에 연결하고 PixelHaetaeBellow의 사용하지 않는 곰 음원 로더도 제거했다. 곰 원본 파일과 곰 스킬 사운드는 변경하지 않았다.

탐식 신수는 팀당 하나여서 동시 해태 수만큼 등장음이 겹치지 않는다. 흡수·삼킴은 기존 Periodic 채널의 같은 시전자·클립당 0.6초 제한을 따른다. 효과 차단과 입자 생성의 기존 판정은 그대로이며, 소리만 묶어서 재생한다. 삼킴은 고정 타이머 대신 실제 입자 도착/애니메이션 전환 콜백으로 연결했다. 최초 소환자가 사망해도 같은 팀의 다른 해태가 살아 있으면 그 시전자에게 소리 소유권을 넘긴다. 마지막 시전자 사망·초기화·전투 종료로 사라지는 신수는 대기 중인 삼킴음을 내지 않는다. 부활 후 신수가 새로 등장하면 등장음도 새로 재생된다.

## 음원 준비

Unity AudioClip.GetData로 원본 PCM을 읽었다. WAV는 44.1 kHz stereo, MP3는 48 kHz stereo다. 원본 12개는 서로 다른 내용이다. 적용본은 48 kHz stereo 16-bit PCM, DecompressOnLoad·Preload이며 재생 속도·음높이를 바꾸지 않았다.

낙뢰 예고는 긴 원본의 1.10~1.45초 상승 구간을, 일갈 압축은 0.50~1.00초 구간을 사용해 실제 준비 시간에 맞췄다. 다른 음원은 앞의 여백과 긴 잔향을 정리했다. 시작 1ms, 끝 WAV 30ms·MP3 15ms 페이드로 가장자리 클릭을 줄였다.
