# 방출된 스킬의 수명

첫 투사체·파동·장판이 방출된 뒤에는 시전자의 사망, 기절, 빙결, 넘어짐, 위치 중단이 그 효과의 비행이나 피해 판정을 취소하지 않는다. 하나의 스킬에 묶인 연속 발사, 착탄 후 분열, 장판의 후속 폭발도 기존 간격과 수명으로 완료한다.

방출 전 준비 동작과 새 공격의 시작은 기존 행동 중단 규칙을 따른다. 신체 돌진·도약·잡기·혀 공격·개인 버프는 시전자와 연결된 행동을 유지한다. 전투 전체 일시정지는 방출된 효과도 멈추며, 전투 종료·리셋·다음 전투 전환에서는 정리한다.

수정 범위:

- 마법쥐: 별 연사·굴절·은하수 파편·오망성·초신성·발사된 백조 별.
- 원숭이: 콩 연사·튀는 과일·귀환 과일·곡사 과일·후속 구름 튕김.
- 사마귀: 방출된 낫바람·두 번의 부채꼴 연사·발사된 사신 추격 잔상. 다음 연사도 시전자 애니메이션의 빙결에 묶이지 않는다.
- 버섯: 비행 중 포자·가스·공명·기생 왕관·이미 부여된 죽음 씨앗·포자 전파. 균사왕은 소환자 사망에도 유지하되, 균사왕 자체의 사망·교체·만료는 기존 정리 규칙을 따른다.
- 거미: 투척 거미줄·착지 장판·천망·여덟 방향 거미줄·고치의 압축·폭발·사막 거미줄.
- 사슴: 성역·불가침 성역·생명 환류·합주 장판. 합주 영혼의 신체 행동은 원래 주인이 죽으면 중단하되, 숨긴 시전자 데이터는 전투 정리까지 유지해 발사된 효과가 끝날 수 있게 한다.
- 와이번·해태: 첫 방출 이후 브레스·압력파·낙하 브레스·과열 연타·불길·이미 생성된 천상 브레스·포효·영역·경고된 번개.
- 그리핀·매머드·티라노·곰·킹콩·닌자·재규어: 발사된 왕권 돌풍·던진 바위·생성된 얼음길/벽·지면 파동·용암·방출된 포효·잔상 장판. 생성된 딱정벌레 중력장과 폭풍 아이템 장판도 시전자 사망과 독립한다.
- 원거리 기본 공격: 발사된 돌·별·포자·거미 바늘·사슴 빛 등은 시전자 사망 뒤에도 적중한다.

`ReleasedSkillValid`는 시전자 데이터, 전투 종료, 전투 세대를 검사한다. 독립된 코루틴과 투사체는 완료/취소 시 추적 수를 한 번만 해제한다. 상태 목록으로 관리하는 장판은 해당 목록을 함께 확인한다. 한 팀의 마지막 몬스터가 죽으면 그 팀의 남은 방출 효과가 끝날 때까지 승패 확정을 기다린다. 기존 양 팀 전멸 판정은 유지한다.

검증:

- 관련 EditMode 테스트 932개 통과. 시전자 사망·기절·빙결·넘어짐, 기존 시전 전 중단, 전투 일시정지, 세대 변경, 피해 중복 방지, 효과 추적 해제를 검증했다.
- 체력 비례 스킬의 이전 성장 조정 전 기대값은 현재 설정에 맞췄으며 이번 수정으로 능력치·피해 배율·성장 수치는 변경하지 않았다.
- 격리된 1배속 실제 전투에서 마법쥐·버섯·거미 사망 뒤, 원숭이·와이번 빙결 뒤, 사마귀·해태 기절 뒤의 추가 적중과 피해를 기록했다. 사슴 성역도 방출 후 기절 상태에서 유지했다.
- 마지막 시전자의 원거리 공격은 사망 뒤 적중했고 약 0.2초 뒤 전투가 정상 종료됐다. 완료 시 남은 효과 추적 수는 0이었다.
- 기존 저장 파일 316개 해시가 모두 동일하다. 검증 중 전투 텔레메트리 파일 1개만 추가됐다. 에디터는 Boot 씬·1배속·기본 프레임 시간으로 복원했다.

위 기록은 최초 공통 수명 수정 당시 검증이다. 실제 전투 기록과 캡처는 `Temp/ReleasedSkillQA/`, 회귀 검증은 `Assets/Tests/Editor/ReleasedSkillLifetimeTests.cs`에 있다.

## 2026-10-15 상위 스킬·Wave 탭·사운드 추가 검증

20계열 80종의 Rank 3 선택 스킬 3종을 각각 정상·사망·기절·빙결로 검증했다. 총 960건이며, 모든 종에서 실제 방출 시점을 확인하고 그 뒤 상태를 적용했다. 검증은 별도 프로필의 Unity Play Mode에서 수행했다. 전체 행렬은 4배속으로 진행하고, 수정한 세 독립 진행 경로와 원숭이 세 스킬은 1배속 96건으로 다시 확인했다.

발견하고 수정한 경로:

- 사마귀 신벌 단두: 첫 칼날 방출 뒤 낙하·두 번째 칼날·착지 판정을 애니메이션 시간에서 분리했다.
- 닌자 고양이 팔문 폭살진: 쿠나이 발사 뒤 이동·경로 적중·최종 폭발을 독립 진행한다.
- 티라노 소환 턱: 턱 개방 뒤 당김·닫힘·피해를 독립 진행하며, 시전자가 죽어도 당김 대상 연결을 유지한다.
- 원숭이 화과산 붕괴: 이미 시작한 연사에서 시전자 사망 때문에 마지막 대형 과일을 생략하던 조건을 제거했다. 세 번의 착지와 후속 과일도 완료한다.

수정한 스킬들은 해당 계열의 4종 모두 사망·기절·빙결 후 정상 상태와 같은 적중 횟수와 피해를 기록했다. 곰의 방출된 시작 포효도 끝까지 도달한다. 곰의 투지 종료 시 새로 발생하는 포효, 돌진·잡기·변신·개인 강화 등 신체 행동은 기존 생존·행동 규칙을 유지한다. 유도 귀환 과일은 시전자의 이동 위치에 따라 피해 대상이 달라질 수 있다. 불가침 성역의 사망 검증은 피해 상한을 존중해 여러 번의 피해를 적용했고, 빙결 면역 상태에서는 검증용으로 면역을 해제한 뒤 빙결 적용을 확인했다.

Wave 데이터는 준비 중 마지막 완료 Wave를 보여주고, 실제 `BeginSavedBattle` 진입 때 해당 Wave를 선택한다. 전투 중 사용자가 다른 Wave를 선택하면 그 선택을 유지한다. 재시도는 직전 시도의 완료 기록을 보여주고 첫 Wave에 기록이 없으면 준비 정보를 보여준다. 실제 화면에서 Wave 3 준비 중 W2 완료 기록, 전투 시작 후 W3 LIVE, 전투 중 W2 직접 선택 유지까지 확인했다.

승패 확정 시 전투 음원과 반복 루프를 즉시 정지하고, 늦게 남은 효과의 전투 사운드 재생을 막았다. 전체 240전투와 재검증 24전투 모두 종료 후 반복/재생 중 전투 음원이 0개였다. 종료 뒤 오디오 일시정지·재개에서도 되살아나지 않았다.

- 관련 EditMode 테스트 917개 통과. 전체 검사 2,377개에서 발견한 이전 사망 취소 기대값 3건은 현재 규칙으로 맞춰 재검증했다.
- 이번 변경과 무관한 기존 기대값 불일치 4건은 수정하지 않았다: `Rank3TraitTooltipUsesConcisePlayerFacingSummary`(100자 이하 기대, 현재 124자), `ShadowCloneUsesApprovedPureGrowthRatiosAndFallbackRule`(데이터 버전 2 기대, 현재 3), `EnemyCurrencyDropsAreRareAndNeverExceedTwoGold`(확률 0.25 기대, 현재 0.7), `EveryRegionHasTwelveCompositionDrivenWavesUsingItsOwnPool`(2 기대, 현재 3).
- 프로필·탐험 진행·설정 저장은 동일하다. 검증 전 파일 327개 중 경제 텔레메트리 1개에 검증 전투 로그가 추가됐고 나머지는 동일하다. 새 전투 로그는 별도 검증 기록이다.
- 에디터는 Boot 씬, 1배속, 기본 프레임 시간으로 복원했다. 별도 패키징 빌드는 실행하지 않았다.

몬스터별 최종 기록은 `Temp/UpperSkillQA/final-results.csv`, 최초 전체 결과는 `full-after/`, 수정 경로 재검증은 `fixed-paths-final/`, Wave UI 캡처와 선택 기록은 `ui/`에 있다. 핵심 스킬의 수정 전 재현 기록은 `critical-before/`에 보존했다.
