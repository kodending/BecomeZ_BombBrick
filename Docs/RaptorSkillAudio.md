4등급은 3등급 선택 특성을 유지하면서 4등급 음원 쌍을 우선 사용한다. 파일명에 맞춰 도약 동작에 연결했으며, 정점 포식자 강화의 갱신이나 강화 평타마다 같은 도착음을 추가 재생하지 않는다. 3등급과 4등급 시작 MP3의 SHA-256은 동일하다.

관통사냥은 이동 중 실제로 맞은 대상에서 재생하고 마지막 착지에 중복 재생하지 않는다. 같은 프레임의 다중 대상은 기존 source gate로 한 번 합친다. 집요한사냥은 실제 타격 시점(0, 0.14, 0.32초)에 도착음을 사용한다. 첫 두 타 강도 0.8, 마지막 1.15이며 대상 사망/이탈로 타격이 취소되면 소리도 추가되지 않는다. 복귀 도약은 재생하지 않는다.

## 파형 보정

직접 청취 평가가 아닌 Unity PCM 디코딩과 파형 측정으로 보정했다. MP3 앞의 약한 시작 부분을 출발 39~83 ms, 도착 44~95 ms 잘라냈다. 각 파일의 서로 다른 피크를 출발 0.65, 도착 0.72로 정리하고, 1 ms 시작 페이드와 15 ms 끝 페이드를 적용했다. 실질적인 감쇠 이후의 약한 꼬리와 기본 도착 파일의 약 2.04초 끝부분 스파이크를 제외했다.

최종 길이: 기본 시작 0.227초 / 도착 0.146초, 3등급 시작 0.431초 / 도착 0.146초, 4등급 시작 0.431초 / 도착 0.205초. 음높이는 1.0배이며 재생 게인은 출발 0.24, 도착 0.32에 사용자 효과음 볼륨과 위 타격별 강도를 곱한다.

기존 `GameAudio`의 12개 음성 풀·일시정지·볼륨·테스트 적군 음소거를 사용한다. 명시적으로 지정한 Cast/Impact 클립만 재생하도록 확장했고, 다른 미작업 스킬의 기본 음원은 계속 재생하지 않는다. 지정 클립은 서로 다른 시전자의 전역 35 ms 제한에서 제외하되 동일 시전자·같은 cue·같은 프레임의 중복 방지는 유지한다.

## 검증

- `CombatAudioTests`와 `RaptorBiteEffectTests`: 99개 통과. 6개 Resources 로딩, 첫 10 ms 신호, 피크, 끝 페이드, 짧은 길이 검사 포함.
- 격리된 실제 전투에서 기본/세 특성/초월 조합 8개 모두 올바른 출발·명중 클립과 원본 피치 확인.
- 실제 도약 경로: 준비 중 0회 → 출발 1회 → 명중 1회 추가 → 복귀 중 추가 0회 확인.
- 스킬 출발·명중과 공통 평타·사망음의 동시 재생, 미지정 Cast 음소거, 일시정지 확인. 최종 Unity 오류·경고 없음.
- 재현·측정 기록: `Logs/RaptorAudioReview/runtime-check.cs`, `prepare.py`, `prepared.json`, `analysis.json`. prepare.py 입력은 Unity AudioClip.GetData로 내보낸 같은 폴더의 stereo float32 PCM이다.
