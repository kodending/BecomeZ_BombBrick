기존 GameAudio 풀과 효과음 볼륨·적군 음소거를 사용한다. 모든 클립 피치는 1.0이며 루프는 없다. 반복 가능 피드백 Bless/Return/Shield/Guard/Appear/Depart/Block은 기존 Periodic 채널을 사용해 동일 소유자·클립당 0.6초 간격으로 묶고, 나머지는 Cast다. 방어 강도 1.4, 준비·영혼 출현/소멸·면역 차단 0.85, 나머지는 1.0이다.

기본·3등급 성역은 준비·전개·축복음을 공유한다. 여러 아군이 거의 동시에 축복받아도 전개/축복음을 아군 수만큼 겹치지 않는다. 늦게 진입한 아군은 실제 축복 시점에 피드백을 받는다. 불가침 방어음은 작은 피해나 성역 밖 피해에는 나지 않는다.

생명 환류의 실제 회복·보호막 계산은 기존 공격 적중 시점 그대로다. 소리만 귀환 입자의 도착 콜백에 연결한다. 실제 회복이나 보호막 증가가 없으면 귀환음이 없고, 기존 보호막이 있다는 이유만으로 생성음을 반복하지 않는다. 도착 전에 수혜자가 사망하거나 전투가 초기화되면 도착음도 취소된다.

만령 합주의 출현/소멸은 성역 시전자를 소리 소유자로 사용해 동시 생성된 영혼들을 묶는다. 정상 소멸만 소리를 내며 원본 사망·전투 초기화로 강제 정리할 때는 후속 소멸음을 내지 않는다. 정령사슴 영혼의 즉시 축복 파동에도 준비·전개·축복음을 연결했다. 영혼이 복제한 스킬의 기존 전용 소리는 공통 재생 진입점에서 강도 55%로 낮춘다.

수호정령 강림은 팀당 한 번이다. 가호음은 여신의 전투 시계를 따라 빛의 시작에 재생하며, 일시정지 중에는 시점이 진행되지 않는다. 시전자가 먼저 사망해도 여신이 유지되는 기존 규칙대로 가호음과 아군 차단음이 동작한다. 가호는 전투 내내 반복 재생하지 않는다.

기존 평타·크리티컬·사망 음원과 스킬 수치, Google DB는 변경하지 않았다.

## 음원 준비
