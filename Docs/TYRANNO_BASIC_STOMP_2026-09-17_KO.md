# 티라노 기본 스킬 — 폭군의 진동

**최신 준비 범위 연출:** 발밑 열 개의 돌 대신, 실제 피해 반경을 전달받은 흙·돌 파편이 안쪽부터 네 겹으로 순서대로 나타난다. 준비 애니메이션의 40% 시점에 반경 절반, 80% 시점에 2타일 경계까지 도달하고 접촉 전까지 유지한다. 애니메이션 진행률을 직접 사용해 행동속도 변화나 빙결 중에도 확산 위치가 준비 동작과 맞는다. 접촉 이후의 빠른 지면 충격은 유지. 게임 수치·설명 변경이 없어 Google DB 추가 변경은 없다. 관련 6/6 테스트 통과 (`1c2ec1bce3034617bfe0c5340a2ac98d`).

티노 실전 348프레임/화면 10장 추가 검증: 준비 완료 전 반경 3.4m(2타일)까지 파편 112개 표시, 접촉 전 피해 없음, 접촉 피해 240, 범위 밖 피해 0, 종료 후 파편 0 확인. `Logs/TyrannoStompVerification/WindupRange/verification.json`, 준비 초기 `tino/view_1.png` 및 경계 도달 `tino/view_4.png` 참조.

기본 스킬 준비 1.5초 → **1초**, 피해 ATK 160% → **240%**. 반경 2타일, 쓰러짐 0.75초, 기본 쿨타임 9초 유지. 티노·마그노·아이언렉스·본렉스의 종별 효과는 유지한다.

기존 발 들기/접촉 스프라이트를 재사용한다. 몸을 살짝 낮춘 뒤 힘을 싣고, 접촉 직전 마지막 0.1초에는 흔들림을 멈춘다. 접촉 프레임은 0.055초 유지하고 빠르게 회복한다. 전역 시간 변경 없이 시전자 애니메이션만 조정한다. 발 주변의 고정된 작은 돌 열 개가 떨다가 접촉하면 중심부터 2타일 끝까지 네 차례(0/0.055/0.11/0.165초) 흙·돌 픽셀이 낮게 솟는다. 접촉 카메라 진동, 기존 타격음과 환경 반응, 각 적의 압축 타격 섬광 및 쓰러짐을 연결했다. 범위 밖 피해는 없다.

3등급 세 특성은 별도 준비 시간 **1.5초**, 기존 피해/범위/연출 유지. 4등급 군림 시작 대기도 실제 선택된 준비 시간에 맞춘다. 새 파편은 준비 중 사망/행동 취소/전투 초기화에 정리되고, 이미 일어난 충격은 짧은 수명을 끝낸다. 스프라이트 크기 기준은 기존 ScaleFor를 유지하며 시각적 눌림만 적용한다.

## 변경 파일

- `TyrannoCombatRules.cs`: 기본/3등급 준비 시간 분리.
- `MonsterAutoBattlePrototype.cs`, `MonsterAutoBattleTranscendence.cs`: 기본 연출 분기 및 기존 특성 타이밍 유지.
- `SpriteMonsterAnimationDriver.cs`: 기본 짓밟기 자세/접촉 정지/회복/취소.
- `PixelTyrannoStomp.cs`: 기존 픽셀 파티클 재사용, 준비 돌 및 바깥으로 퍼지는 충격.
- `PixelCombatEffect.cs`: 소유자가 정리하는 파티클의 자동 파괴 선택만 추가. 다른 호출 기본값 유지.
- `GameMasterDatabase.asset` 스킬 v3, `LocalizationDatabase.json` 해당 설명 v2.
