# 닌자 고양이 3등급 — 무영십자멸 리뉴얼

대상 하나를 본체가 사방에서 연속으로 베고, 마지막에는 적 뒤에서 일섬을 넣는다. 고정 잔상·직선 연결선으로 대신 공격하던 기존 경로를 교체했다. 흑월 대사냥·팔문 폭살진은 이번 범위에서 제외했다.

- 일반 속도 기준: 소실 0.10초 → 통나무 0.18초 → 첫 위치 출현 0.32초 → 0.36/0.45/0.54/0.63초 4연격 → 뒤쪽 출현 0.68초 → 일섬 0.78초 → 회수 완료 0.93초.
- 본체가 매번 안전한 빈 공격 위치로 이동하고 대상을 바라본다. 막힌 위치는 기존 빈 자리 탐색을 사용하고, 자리를 확보할 수 없으면 취소한다. 마지막 위치는 대상이 바라보는 방향의 뒤쪽을 우선한다.
- 기존 스킬 프레임과 크기를 유지하며 실제 타격 프레임에서만 피해를 준다. 연격마다 짧은 잔상·곡선 베기·개별 적중 파편, 마지막 출현에는 작은 연막, 일섬에는 1.45배 베기와 강한 시각 반동. 카메라 줌/흔들림 추가 없음.
- 연격 공격력 70%×4회, 각 경로의 다른 적에게 50%. 마지막 공격력 220% + 적중 직전 잃은 체력 12%, 방어력 50% 무시. 기본 스킬 피해를 중복 가산하지 않는다.
- 대상 지정 불가·강제이동 면역은 소실부터 마지막 적중까지만 유지하며 회수 동작에는 종료한다. 대상 사망/대상 지정 불가, 본체 사망/중단/강제 위치 변경, 전투 종료 시 남은 공격과 보호가 해제된다. 빙결은 동작 시계를 정지하며 빙결 중 대상이 소실되어도 정리된다.
- 마지막 타격 후 평타 2회 +20%. 마지막 타격에서 살아남은 적에게 설묘 냉기 2중첩, 순동이 기존 3초 독, 홍련 기존 3초 화상을 한 번 적용한다. 홍련은 새 픽셀 화염 잔상을 사용한다. 이전 DB에 있던 미구현 즉시 강화 평타/대형 양끝 화염 잔상 문구는 실제 유지된 동작으로 정정한다.
- 스프라이트 없는 시뮬레이션도 같은 위치/피해 함수를 순서대로 사용한다.
