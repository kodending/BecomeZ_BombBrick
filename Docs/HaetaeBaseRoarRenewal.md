# 해태 계열: 계수 및 기본 포효 리뉴얼

2026-09-22 구현. 기본 스킬과 고유 효과를 수정했다. 이어서 첫 번째 3등급 천벌의 포효도 리뉴얼했으며 상세 내용은 HaetaeHeavenlyThunder.md에 정리했다. 다음 대상은 두 번째 3등급 신수의 위압이다.

| 개체 | 스킬 위력 | 기본 포효의 고유 효과 |
|---|---|---|
| 해타 | 공격력 | 닿은 아군에게 공격력 60% 회복. 정화 성공 여부와 무관 |
| 염해 | 공격력 | 적에게 공격력 25%/초 화상, 4초 |
| 금강수 | 자신의 최대 체력 5.5% | 닿은 아군에게 자신의 최대 체력 8% 보호막, 5초 |
| 묵령 | 공격력 | 적이 받는 회복 40%·새 보호막 25% 감소, 4초 |

기본·3등급·4등급 피해에 동일한 종별 스킬 위력을 사용한다. 평타는 공격력 그대로이며 성장 비중은 유지한다. 금강수의 기본 포효 피해는 최대 체력 6.6%다.

정의의 포효는 0.35초 준비 후 0.25초에 걸쳐 반경 2.5타일로 퍼진다. 적에게 닿을 때 스킬 위력 120% 피해를 한 번 주고 공격력을 15% 낮춘다(4초). 자신을 포함한 아군에게 닿으면 해로운 효과를 모두 제거한다. 쿨타임은 10초다. 범위 내 적이나 정화할 아군이 있으면 시전하고, 해타는 체력이 80% 이하인 아군에게도 시전한다.

기존 파티클 재질을 사용한 반투명 압력 파동·입 주변 응축·대상별 타격 및 정화 파편. 기존 스프라이트의 포효 프레임을 파동에 맞춰 유지한다. 본체에 추가 회전·확대는 넣지 않는다. 파동의 시계와 적중 판정을 공유하며 일시정지·빙결·위치 변경·전투 초기화에 대응한다.

기존 3등급 지원 수치는 유지한다. 4등급 추가 포효는 기존 70% 위력과 정화·공격력 감소를 유지하며 고유 효과를 중복 발동하지 않는다. 3등급의 기존 상세 기획 설명과 실제 지원 수치 차이는 다음 3등급 재설계 시 함께 정리할 대상이다.

기존 Google DB의 Monster_Growth_Master 78~81행, Skill_Master 25행, Trait_Master 120·122·123행, Localization_Master 898·900·901·921행 총 43셀을 수정하고 읽기 검증했다. 금강수 성장 메모가 잘리지 않도록 80행 높이만 84px로 조정했다.
