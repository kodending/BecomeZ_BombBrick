## 음원 준비

Unity AudioClip.GetData로 원본 파형을 읽었다. MP3는 48 kHz stereo·0.528초, 급강하 WAV는 44.1 kHz stereo·2초다. 원본 14개는 서로 다른 내용이다.

적용본은 48 kHz stereo 16-bit PCM·DecompressOnLoad·Preload다. 시작 여백을 정리하고 피크를 조절했다. 급강하는 0.05초 낙하 뒤 짧은 여운을 남기는 0.12초로 정리했다. 유지음은 원본의 비교적 일정한 0.12~0.48초 구간을 사용한다. 시작 페이드 1 ms, 끝 MP3 기반 15 ms·급강하 30 ms·유지음 3 ms다.
