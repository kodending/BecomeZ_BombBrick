# 메인·로딩·설정·사운드 1차 적용

## 적용 범위

- Boot를 메인 화면으로 사용: 모험 시작, 설정, 종료 확인.
- 메인 → 원정 준비 → 전투 → 결과를 공통 비동기 로딩으로 연결.
- ESC/상단 메뉴: 일시정지, 계속하기, 설정, 메인 복귀, 종료 확인.
- 메뉴가 열린 동안 전투 업데이트와 뒤쪽 UI 입력 차단. 배치/아이템 드래그 취소.
- 화면 설정: 해상도, 전체/창 화면, 수직 동기화, 30/60/120 FPS, FPS 표시.
- 화면 설정 적용 후 12초 확인. 확인하지 않거나 ESC로 취소하면 이전 설정 복원.
- 소리 설정: 전체/BGM/효과음 분리, 즉시 적용. 조작 설명 탭 추가.
- 게임 설정은 `BombBrick.UserSettings.v1`에 별도 저장. 몬스터/원정 저장 구조는 변경하지 않음.

## 사운드

외부 음원이나 패키지 없이 Unity AudioClip으로 만든 1차 칩 사운드.

- 공통 버튼, 전투 시작, 타격, 스킬, 포획 성공, 승리/패배.
- 메인·마을과 전투용 기본 루프 각각 1개.
- 타격/스킬 동시 재생 간격 제한. 볼륨 조절 및 효과음 미리듣기.
- 리스너가 없는 전투 카메라는 실제 게임 진입 시 리스너 추가.

이는 기본 사운드 연결 단계다. 몬스터별 전용 음색, 맵별 완성형 BGM, 실제 청취 후 믹싱은 별도 마감 항목이다.

## 성능 관련 변경

- 색이 매 프레임 변하는 UI 테두리마다 텍스처를 생성·캐시하던 경로 제거. 공용 흰 텍스처와 색상으로 네 변을 그림.
- 피격마다 실행되던 복수 대상 LINQ 정렬을 한 번의 순회로 변경. 최대 누적 피해/동률 ID 우선순위 유지.
- 기본 프레임 제한 60 FPS, 사용자 선택 가능.
- ML/효과 테스트 전용 실행에서는 메인 메뉴/사운드가 자동 개입하지 않도록 분리.

전체 전투 FPS 향상 수치를 측정한 결과는 아니다. 장시간·최대 이펙트 상황의 빌드 성능 측정은 플레이 검수 단계에서 추가해야 한다.

## 검증 기록

- 설정값 정상화, 독립 복사/직렬화, 화면 비율 및 기존 UI 배치: 37개 통과.
- 1366×768, 1920×1080 게임 화면 캡처로 메인/설정/메뉴 확인.
- 해상도 비율 테스트: 960×540부터 3440×1440까지 7개 조건.
- Boot → Town → 테스트 전투 비동기 이동 확인.
- 30 FPS 미확정 적용 후 12초 뒤 60 FPS 복귀 확인. 미확정 설정은 저장되지 않음.
- 8:8 테스트 전투에서 메뉴 개방 전후 전투 시간 4.502386초로 동일. 메뉴 닫기 후 TimeScale 1 복귀.
- 전체 EditMode 테스트 **460/460 통과**, 실패/스킵 0 (108.8초).
- 리스너 보완 후 Boot → 8:8 테스트 전투 → Result → Boot 이동 확인. 각 씬 리스너 1개, 최종 콘솔 오류/경고 0.
- 전투용 BGM 재생 상태 확인. 테스트 전투 13.25초 진행 후 결과 이동 확인.
- 테스트 실행은 원정 저장 비활성 조건으로 진행했으며, 전투 테스트 설정은 해제 후 Boot로 복귀.

캡처: `Captures/FrontendQA/` (배포 에셋에 포함되지 않음).

## 유지한 부분

Unity 2022.3.62f2 및 manifest/packages-lock 원본 해시 유지. 난이도, 몬스터/아이템/증강 수치, 성장 규칙, 저장 데이터 초기화는 이번 작업 대상이 아니다.
