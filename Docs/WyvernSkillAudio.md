기본 공격 광선의 기존 공통 Hit·크리티컬은 유지한다. 스킬 피해의 공통 타격음을 대상마다 겹치지 않도록 와이번을 authored family로 등록했다. 기본/용핵 타격음은 피해 틱당 최초 대상 한 번이며, 아무도 맞지 않으면 재생하지 않는다. 낙하 착탄·폭압 방출·천룡 폭발은 해당 이펙트가 발생할 때 한 번 재생하므로 빈 지면에서도 소리가 난다. 그리폰 역풍에 차단된 낙하탄은 이후 착탄음을 내지 않는다. 화염·독·연쇄 번개에 별도 반복음을 추가하지 않았다.

Breath/Overheat만 반복 재생한다. 캐스트의 실제 종료·방해·사망·초기화에서 기존 GameAudio.StopCombatLoop로 정리한다. 빙결 중에는 분사 루프를 끄고 해제 후 남은 시전 동안 다시 재생하며, 일시정지는 기존 GameAudio.Pause/UnPause를 따른다. 메아리는 별도 준비 없이 기본 분사/타격을 강도 0.45의 유한 음원으로 재사용하여 본체 루프와 수명이 충돌하지 않는다. 4등급은 기존 전투당 한 번 조건을 유지하며 취소 후 낙하·폭발음을 예약 재생하지 않는다.

기존 효과음 볼륨·적군 음소거·영혼 복제 음량 배율·12개 음성 풀을 공유한다. 피치는 1.0이다. Hit/Pressure/RainHit/OverheatHit/HeavenHit는 Impact, 나머지는 Cast다. 강도는 준비·기본 분사·용핵 분사 0.8, 기본 접촉 0.7, 용핵 중간 접촉 0.65, 낙하 발사 0.85·낙하 0.65·착탄 0.8, 천룡 그림자 0.9·폭발 1.1, 나머지 1.0이다.

## 음원 준비

Unity AudioClip.GetData로 원본 PCM을 읽었다. WAV는 44.1 kHz stereo, MP3는 48 kHz stereo다. 원본 13개 중 폭압 폭발과 낙하 착탄은 같은 파일 내용이다. 적용본은 서로 다른 길이·피크로 정리했다.

48 kHz stereo 16-bit PCM, DecompressOnLoad·Preload로 저장했다. 음높이·재생 속도는 바꾸지 않고 시작 여백·잔향을 정리했다. 용핵 분사는 원본 0.30~0.75초의 유지 구간, 천룡 그림자는 긴 원본 중 1.75~2.65초의 지나가는 구간을 사용한다. 기본 분사는 0.65초, 용핵 루프는 0.45초다. 낙하음은 실제 비행 시간에 맞춰 0.55초다.

적용본 길이: prepare 0.35초, breath 0.65초, hit 0.23초, compress 0.5초, pressure 0.6초, rainlaunch 0.38초, rainfall 0.55초, rainhit 0.42초, overheat 0.45초, overheathit 0.65초, shadow 0.9초, heavenfall 0.55초, heavenhit 1.6초. 피크 범위 0.49~0.76, 시작·종료에 짧은 페이드를 적용했다.

가공 코드·원본 해시·측정 수치는 `Logs/WyvernAudioReview/prepare.py`, `prepared.json`, `decoded.txt`에 기록한다. 이는 파형·실제 재생 이벤트 검사이며 직접 청취한 최종 청감 평가는 아니다.
