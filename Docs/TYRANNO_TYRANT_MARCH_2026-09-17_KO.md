# 티라노 3등급 — 폭군 대행진

사용자 승인 설계: 준비 0.6초 → 출발 시 방향 고정 → 1초 동안 최대 4타일 전진. 폭 2타일 경로에서 몸에 닿은 적에게 공격력 200%를 한 번 주고 앞쪽으로 밀고 간다. 도착 후 앞발을 0.18초 들어 올려 멈췄다가 주변 반경 2타일에 260% 피해·기본 0.8초 쓰러짐. 두 타격 모두 적중 시 460%. 기본 쿨타임 9초.

준비·행진 중 받는 피해 50% 감소와 강제이동 면역은 실제 동작 상태에 연결한다. 시간제 공통 보호 필드를 덮어쓰지 않는다. 빙결은 애니메이션과 이동을 함께 정지시키고 행동속도는 공통 타임라인에 반영한다. 출발 뒤에는 대상이 움직여도 방향을 바꾸지 않는다.

기존 2타일 단위 위치 변경을 연속 이동과 경로 충돌 판정으로 교체했다. 한 프레임의 이동도 작은 구간으로 검사하여 빠른 이동 중 적/지형을 건너뛰지 않는다. 이미 맞은 적은 중복 피해를 받지 않으며 아군은 피해 대상에서 제외한다. 밀리는 적은 일반 이동을 멈추고 행진과 같은 이동량으로 이동한다. 전장 경계·막힌 지형·강제이동 면역 대상 앞에서는 전진을 멈춘다. 사망·행동 중단·전투 초기화 시 붙잡힌 적과 보호 상태를 정리한다.

연출(후속 무게감 개선): 몸을 낮추는 준비 후 SkillAttack의 발 들기/내려찍기 자세로 두 번 전진한다. 보폭마다 0.34초 동안 부드럽게 가속·감속하여 2타일 이동하고, 착지 후 0.16초 제자리에 버틴다. 발을 들 때 몸이 0.12만큼 올라갔다가 빠르게 내려오고, 착지 순간 몸이 좌우 114%/높이 82%로 눌린다. 각 착지에 반경 0.95타일의 짧은 흙빛 도트 충격파, 낮고 넓게 튀는 흙먼지, 0.12초 중간 진동을 동기화했다. 스킬 스프라이트의 원래 배율을 사용한다. 적별 충돌 섬광, 마지막 앞발 들어 올리기/0.085초 접촉 유지/짧은 회복, 반경 2타일의 더 큰 충격파와 강한 진동으로 마무리한다. 기존 ExtinctionBurst 투명 시트 재사용. 총 전진 시간·거리·피해·범위는 같고 발걸음 이펙트에 추가 피해는 없다.

고유 효과는 마무리에서 고유 적중 수로 적용한다. 티노: 포식 준비/HP 5% 회복. 마그노: 도착 지점 반경 2타일에 4초 용암. 아이언렉스: 적당 HP 4%, 최대 12% 보호막. 본렉스: 생존 적중 대상에게 방어력·저항력 20% 감소/5초. 기본 스킬·대멸종 진동·시원의 거악은 보존한다.
