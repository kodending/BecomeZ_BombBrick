# 지역 맵과 전장 표현 통합

2026-09-23. 밸런스 수치는 변경하지 않았다.

## 적용 범위

현재 지역 카탈로그에는 총 5개 지역이 등록되어 있다. 초원 외 4개를 재제작했으며, 여섯 번째 지역의 추가 여부는 사용자 확인 대기다.

| 지역 | 맵 원화 | 공중 환경 입자 | 착지·이동·지면 파편 |
|---|---|---|---|
| 태초의 초원 | 기존 저밀도 테스트 초원 채택 | 잎·꽃가루, 불규칙한 낙하 | 풀·잎, 흙먼지 |
| 독안개 습지 | 동일 구도의 신규 원화 | 작은 포자, 느린 상승·표류 | 녹갈색 진흙 덩어리·수초 |
| 붉은 밀림 | 동일 구도의 신규 원화 | 재·작은 불씨, 상승 | 어두운 암석·붉은 흙먼지 |
| 얼어붙은 고원 | 동일 구도의 신규 원화 | 작은 눈송이, 비스듬한 낙하 | 각진 얼음·눈 조각, 흰 먼지 |
| 천공 성역 | 동일 구도의 신규 원화 | 금빛 가루, 수평 표류 | 밝은 석재 조각·석분 |

맵은 `Assets/Resources/Environment/{PrimordialMeadow,PoisonFogSwamp,CrimsonJungle,FrozenHighlands,SkySanctuary}/BattleBackground.png`에 저장했다. 기존 GUID를 유지하고 Point 필터, 무압축, 밉맵 없음, NPOT 크기 유지로 설정했다. 신규 원화 4개는 내장 image_gen으로 제작했으며 프롬프트는 `BattlefieldMapImagePrompts.md`에 기록했다. 원본 백업은 `Logs/MapIntegration/Before/`에 있다.

## 실제 원정과 테스트의 공통 동작

- 같은 지역 맵과 `LayeredBattleEnvironment.BuildMaster`를 사용한다. 초원만 테스트 전용 리소스를 사용하던 분기를 제거했다.
- 8열 × 5행, 간격 1.2배, 9칸 대기석, 위쪽 이동 경계 확장, 전투판·대기석 위치 보정, 카메라 구도를 공통 적용했다. 카메라 프레이밍의 기준 4행은 원화 정합을 위해 유지한다.
- 대기석의 가로 보정에도 같은 간격 배율을 적용해 전투판과 중심을 맞췄다.
- 실제 원정의 자동 줌·자동 초점 전환을 끄고 명시적인 타격 진동은 유지한다. 캐릭터 그림자도 배경 위에 그린다.
- 테스트 화면의 `맵: … ▶` 버튼으로 지역을 순환하고 해당 지역의 전투를 다시 배치한다.
- 테스트용 능력치·편성·프로필과 실제 원정의 진행·저장·경제 분기는 그대로 유지한다. 테스트 모드를 실제 게임에 켜는 방식으로 이식하지 않았다.

## 환경과 스킬의 연동

`MeadowAmbientParticles`의 기존 고정 풀을 재사용한다. 공중 입자는 총 10개, 지면 입자 풀은 48개로 유지한다. 지역마다 입자의 픽셀 모양, 색, 이동 방향과 흔들림을 바꾼다. 공통 `Impact`를 사용하는 모든 착지 스킬과 `Footstep`이 현재 지역을 사용한다.

별도로 흙색을 지정하던 개구리·악어·고릴라 착지 파편, 티라노 지진, 매머드 돌진·버티기·추방의 발밑 먼지, 장풍이의 부유 지면 조각, 사마귀 절단 파편, 그리폰 강하의 지면 파편과 바람 먼지, 해태 포효의 지면 먼지도 `TerrainColor`로 지역에 맞춘다. 마법 본체·깃털·뿔·종족별 소환 벽의 색은 각 스킬의 표현을 유지한다.

지역 변경 시 이전 배경과 환경 입자는 즉시 비활성화한 뒤 정리한다. 이전 환경이 늦게 파괴되어도 새 지역의 지면 색 연결을 지우지 않는다. 환경 난수는 전투 난수와 분리되어 있다.

## 검증

- Unity 컴파일 오류 및 런타임 콘솔 오류 없음.
- 관련 테스트 128개 실행: 127개 통과, 기존 툴팁 길이 실패 1개. 환경 연동 신규 6개 모두 통과.
- 전체 1,978개 회귀 실행: 1,970개 통과, 8개 실패. 기존 실패 7개(툴팁·번역·이전 수치 기대값)가 남아 있다. 이번 전장 변경과 관련된 기존 대기석 중심 테스트는 통과했다. 추가로 늑대 테스트 1개가 300프레임 제한에 걸렸으나 늑대 묶음 재실행에서는 21개 전부 통과했다. 새 지속 실패는 재현되지 않았다. 상세 결과: `Logs/MapIntegration/verification.json`.
- 실제 원정 표시 경로에서 격리된 테스트 프로필로 16개체 전투를 실행했다. 7.37초 시점 피해를 입은 개체 12명, 카메라 FOV 36 유지, 저장 가능 상태 false를 확인했다. 실제 사용자 원정 저장은 변경하지 않았다.
- 테스트와 실제 원정의 40개 배치 좌표 및 카메라 위치 일치. 지역 선택으로 설원 런과 설원 환경이 함께 생성되는 것 확인.
- 다섯 지역의 실제 카메라 렌더와 설원의 착지 파편·부유 지면 조각을 확인했다. 캡처는 `Logs/MapIntegration/`에 있다. `*-terrain.png`는 서로 다른 스킬 파편을 강제로 띄운 진단 화면이며, 설원의 정리된 최종 화면은 `frozen-terrain-final.png`다.

## 지역별 배치 마커

헥사 모서리 마커는 사용자 피드백에 따라 기존의 얇은 선 두께·옅은 가장자리·Bilinear 필터로 복원했다. 맵별 색상은 유지한다. 초원·습지·밀림은 밝은 청록 계열 아군과 산호·분홍 계열 적군, 설원·성역은 짙은 청색 계열 아군과 자주 계열 적군으로 구분한다. 대기석·중립 지역과 배치 가능/불가·뒤집기 예고·지휘 칸 강조색도 바닥 밝기에 맞춰 적용한다. 테스트와 실제 원정의 공통 마커 경로를 사용한다.

다섯 지역의 마커 표시·아군/적군 색상 구분·배치 가능/불가 강조를 런타임에서 확인하고 카메라 화면을 검수했다. 당시 확인 코드와 캡처는 `Logs/MapIntegration/HexMarkers/`에 있다. 해당 코드의 Point 필터 검사와 `*-final.png`의 두께는 얇은 선 복원 이전 기록이다.

## 사운드 후속 범위

현재 전투 사운드 실행 코드는 테스트와 실제 원정에서 공유한다. 기본 타격·사망과 일부 전용 스킬 음원은 연결되어 있다. 실제 원정의 배경음은 `GameAudio.SetScene`에서 꺼져 있으며, 일반 시전·지속음에는 의도적인 음소거 조건이 있다. 이번 변경은 맵·환경·전장 표현에 한정했고 음원 교체나 전체 시전음 해제는 하지 않았다. 다음 작업은 지역별 환경음·전투 배경음과 스킬별 타격음의 밀도·우선순위를 정하는 것이다.
