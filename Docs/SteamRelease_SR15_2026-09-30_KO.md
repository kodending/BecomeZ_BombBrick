# SR-15 — 설치·저장·이어하기·업데이트 검증

2026-09-30. **사용자 검증 확인으로 완료.**

설치·실행, 저장·종료·재실행, 전투 복귀 정책, 오프라인, 업데이트 후 진행 보존의 검수 범위를 안내한 뒤 사용자가 “다른 PC에서 이미해봤었어 이상없었어.”라고 확인했다. 이 사용자 검증 결과를 근거로 Google `Steam_출시준비`의 SR-15를 완료 처리했다.

외부 PC 사양, 실제 검수 날짜·빌드 버전, 항목별 로그는 별도 제공되지 않았다. 에이전트가 외부 PC에서 직접 실행한 결과로 기록하지 않는다. Steam 클라이언트를 통한 설치·업데이트 검증은 SR-19에서 반복한다.

다음은 **SR-16: 신규 시작부터 전체 진행 검수**다. 튜토리얼 → 편성 → 원정 → 성공/패배 → 귀환 → 성장 → 지역/난이도 해금까지 진행하며 막힘, 보상 중복·누락, 복귀 오류를 확인한다. 밸런스 수치 검증은 기존 결정대로 별도 보류한다.
