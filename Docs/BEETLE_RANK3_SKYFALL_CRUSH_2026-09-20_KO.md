# 풍뎅이 3등급 두 번째 특성 — 천공 압살

기존 황금 갑각관을 천공 압살로 변경했다. 저장된 선택과의 호환을 위해 `trait_beetle_golden_carapace_coffin` ID와 내부 category는 유지한다.

## 동작과 판정

- 0.30초: 뿔로 주 대상을 들어 올리며 스킬 위력 60% 피해.
- 0.30~0.84초: 대상이 2.4타일 높이까지 뒤집혀 올라간다.
- 0.70~0.86초: 시전자도 도약해 적 가까이 접근하고 뿔로 받친다. 이동은 기존 장애물·개체 충돌 판정을 사용한다.
- 0.86~1.06초: 공중 정점에서 붙잡은 자세로 정지한다.
- 1.06~1.12초: 뿔을 아래로 향하게 몸을 숙이며 급강하한다.
- 1.12초: 주 대상은 스킬 위력 300% 피해와 기본 0.4초 쓰러짐. 착지 반경 1타일의 다른 적은 120% 피해. 주 대상에게 주변 피해를 중복 적용하지 않는다.
- 적이 땅에 닿을 때 강한 짧은 카메라 진동·범위까지 퍼지는 픽셀 흙 파편·대상별 타격 입자를 발생시킨다.
- 1.15초: 시전자가 착지하고 몸을 낮춘 뒤 회복한다. 1.45초에 동작 종료.

주 대상 기본 총 피해 360%, 쿨타임 8.5초. 장풍·뇌풍·솔라비틀은 공격력, 아틀라곤은 현재 방어력 40%를 스킬 위력으로 사용한다. 기본 스킬의 종 고유 효과는 유지한다. 기존 봉인·압착 6회·추가 피해 감소 효과는 제거했다.

시전 중 시전자는 다른 행동을 하지 않는다. 양측은 공격 대상이며 새로운 무적 효과를 부여하지 않는다. 제어 면역 대상에게는 피해만 적용한다. 빙결 시 동작 시계가 정지한다. 시전자 사망·강제 이동·행동 중단 시 양측 공중 자세와 붙잡기를 해제한다. 주 대상이 죽거나 강제로 이동하면 해당 대상을 원격으로 내려찍지 않고 예정된 착지 범위 피해만 처리한다.

## 데이터

로컬 GameMasterDatabase, LocalizationDatabase, 한국어 UI 대체 문구를 변경했다. 기존 Google DB 10셀 반영 후 10셀 모두 재조회 일치 확인:

- Trait_Master!B167,C167,F167,H167: 이름·태그·설명·현재 버전 7.
- Localization_Master!D592,E592,I592: 한영 이름·버전 2.
- Localization_Master!D790,E790,I790: 한영 간결 설명·현재 버전 3.

기존 서식·유효성 검사·번역 승인 상태를 유지했다. 실제 Sheets 표시도 확인했다. 변경 전과 요청·재조회 자료는 `Logs/BeetleCrush/google-before.json`, `google-requests-and-readback.json`에 있다.

## 확인 자료

네 개체의 좌우 방향 실제 전투 캡처와 피해·공중 높이·동작 기록은 `Logs/BeetleCrush/TempoRuntime`에 있다. `capture-tempo.cs.txt`는 해당 테스트 장면에서 사용하는 검사 스크립트다. 관련 EditMode 검사는 `BeetleCrushTests`, 기존 `BeetleFlipTests`·`BeetleSweepTests`·`FamilyRank3TraitTests`를 함께 실행한다.

최종 관련 검사 51개 통과, 콘솔 오류 0건. 네 개체 실제 전투에서 0.30초 들어 올리기와 약 1.12초 착지에만 피해가 발생하며 종 고유 효과를 포함한 수치가 일치했다. 후속 자세 보정으로 착지 직전 몸을 135도까지 숙여 뿔이 아래를 향하고, 적 착지 순간 시전자의 추가 높이가 0.35로 줄어든 뒤 0.03초 안에 지면에 닿도록 했다. 결과 요약은 `Logs/BeetleCrush/tempo-runtime-check.json`, 테스트 결과는 `tempo-tests.json`에 있다.

## 속도 보강

따라 도약을 0.50초에서 0.16초로, 정점 정지를 0.26초에서 0.20초로, 급강하를 0.12초에서 0.06초로 줄였다. 도약과 낙하는 시작부터 빠르게 움직이고 정점에서는 위치를 고정한다. 피해·범위·쓰러짐·쿨타임은 유지하며 전체 동작은 1.80초에서 1.45초로 단축됐다. 기본 뒤집기와 첫 번째 특성의 동작 시간은 그대로다.

관련 검사 51개 통과. 네 개체 모두 정점 높이가 고정되고 60fps 기준 1.133초에 착지 피해가 발생하며, 동작 종료 후 붙잡기와 공중 자세가 해제되는 것을 확인했다. 기존 Google DB의 설명·한영 간결 설명·버전 5셀(Trait_Master!F167,H167 및 Localization_Master!D790,E790,I790)을 수정하고 재조회 일치 확인했다. 검사 자료: `Logs/BeetleCrush/TempoRuntime`, `tempo-tests.json`, `tempo-requests-and-readback.json`.
