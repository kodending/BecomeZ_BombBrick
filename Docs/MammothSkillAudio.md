기존 GameAudio 음성 풀·효과음 볼륨·적군 음소거를 사용하고 피치는 1.0, 루프는 없다. Collision/Shatter/WallBreak/Guard/Counter/Launch는 Impact, 나머지는 Cast다. 반복 벽 생성은 강도 0.6, 앞의 두 벽 파괴 0.85·마지막 1.1, 분담 0.65·방어 0.75로 조절한다.

범위 적 수만큼 충격음을 겹치지 않는다. 기본 경로 충돌과 투석 관통은 첫 적중에만 재생한다. 분담·방어는 각각 시전자별 동작 시간 0.12초 간격으로 묶는다. 방어음은 실제 외피 반응 콜백에 연결해 분담 피해 계산 순간에 앞당겨 재생하지 않는다.

동작 시계를 따라 빙결·일시정지 중에는 다음 단계 소리가 진행되지 않는다. 시전 취소 후 아직 발생하지 않은 발사·파괴·반격음은 없다. 이미 던져진 바위와 확정된 퇴장 비행은 기존 동작대로 시전자 사망 후에도 끝까지 진행하며 소리도 함께 난다. 전투 초기화로 취소된 비행에는 퇴장 마무리음이 없다. 체력이 20% 이상으로 회복되거나 접촉 범위를 벗어나 퇴장이 거절되면 쳐올리기·퇴장음 모두 없다.

일반 공격·크리티컬·사망 공통음은 유지한다. 퇴장의 기존 일반 사망음 생략 경로도 유지한다. 전투 수치와 Google DB 변경은 없다.

## 음원 준비

Unity AudioClip.GetData로 원본 파형을 읽었다. MP3는 48 kHz stereo·0.528초, 들어올리기 WAV는 44.1 kHz stereo·3.972초, 쳐올리기 WAV는 44.1 kHz stereo·2초다. 원본 13개는 서로 다른 내용이다.

적용본은 48 kHz stereo 16-bit PCM·DecompressOnLoad·Preload로 맞췄다. 시작 여백을 정리하고 피크를 조절했다. 시작 1 ms, 끝 MP3 기반 15 ms·WAV 기반 60 ms 페이드. 들어올리기는 0.62초로 동작의 실제 바위 출현부터 투척 직전까지 맞추고, 쳐올리기는 불필요한 후반 무음을 제외한 약 0.995초를 사용한다.

길이: Prepare 0.29초, Charge 0.38초, Collision 0.236초, Lift 0.62초, Throw 0.27초, Shatter 0.346초, Wall 0.19초, WallBreak 0.25초, Share/Guard 각 0.22초, Counter 0.35초, Launch 0.995초, Exit 0.29초.

이는 파형 측정과 재생 이벤트 검증이며 직접 청취에 의한 최종 청감 평가는 아니다. 원본 해시·가공 수치와 재현 코드는 `Logs/MammothAudioReview/prepared.json`, `decoded.txt`, `prepare.py`에 보관한다.
