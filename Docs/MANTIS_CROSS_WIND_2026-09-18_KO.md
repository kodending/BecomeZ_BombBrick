# 사마귀 기본 스킬 — 십자 낫바람

## 확정 구현

- 준비 0.12초 → 첫 낫바람 → 0.1초 뒤 두 번째 낫바람. 기존 스킬 스프라이트를 움츠림/첫 베기/되감기/반대 베기/복귀로 재생한다. 몸의 짧은 반동과 날 끝 빛을 추가했다.
- 각 80% 공격력, 8초 쿨타임, 기본 3.5타일 사거리와 기존 폭을 유지한다. 두 칼날 모두 맞으면 3초간 매초 공격력 20% 출혈.
- 발사 즉시 전체 경로를 타격하던 처리를 제거했다. 실제 투사체의 직전~현재 이동 구간으로 판정하며 칼날 하나당 같은 적을 한 번만 타격한다. 진입/이탈하는 적의 현재 위치를 사용한다.
- 칼날은 초당 30 월드 유닛으로 이동한다. 밝은 날과 짧은 두 겹 잔류물을 가진 Point 필터 픽셀 스프라이트를 사용하며, 화면에 투영한 실제 판정 폭과 크기를 맞춘다.
- 적별 절단 섬광/짧은 픽셀 조각/피격 반동/타격음. 두 칼날 적중은 더 선명한 섬광과 출혈로 구분한다.
- 맨티우스: 두 번째 칼날 금빛, 두 번째 피해 +40% 유지. 플로티스: 이중 적중 시 꽃가루 약화 유지. 샌티우스: 모래색/사거리 +1.5타일/폭 1.5배 유지. 네크티스: 처치 후 60% 재시전은 보랏빛 칼날로 구분한다.
- 기존 3등급 별도 스킬 효과는 유지. 전투 세대 변경/시전자 사망/코루틴 취소 시 남은 칼날을 정리한다.

## 검증

- 가까운/먼 적의 접촉 순서, 관통/아군 제외/범위 밖 제외, 칼날별 중복 방지, 긴 프레임의 이동 구간 판정, 이동 회피/진입, 사망/전투 초기화 취소, 고유 피해/꽃가루를 EditMode 테스트로 검증했다.
- 네 개체 실제 스프라이트의 전투 화면 216장과 타임라인: `Logs/MantisCrossRenewal/Frames/`. 첫 발사 20프레임, 두 번째 26프레임. 근거리/중거리/원거리 첫 피해 22/26/29프레임. 네크티스 처치 후 재시전 관측. 카메라 FOV 36 고정, 종료 후 칼날 0개.
- 시각 검증은 임시 HP 5000/피해 100/방어 0/자동 공격 억제로 분리했으며 테스트 종료 시 플레이를 종료해 임시 전투 수치를 제거했다. 연속 촬영 시 이전 출혈의 잔여 틱이 다음 케이스에 남을 수 있으므로 총 피해 계수는 독립 EditMode 테스트를 기준으로 한다.
- 최종 테스트 결과는 `Logs/MantisCrossRenewal/tests.json`에 저장한다.
