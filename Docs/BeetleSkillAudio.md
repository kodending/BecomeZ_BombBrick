기존 GameAudio 음성 풀·효과음 볼륨·적군 음소거를 사용한다. 피치 1.0, Hover만 루프다. Land/Crush/GravityLand/OverturnLand는 Impact, 나머지는 Cast다. 준비·강화 강도 0.8, 휩쓸기·도약·급강하·부양·4등급 예고 0.85, 유지 0.4, 4등급 착지 1.1이다.

범위 적 수만큼 접촉음을 쌓지 않는다. 뇌풍의 고유 연쇄 낙뢰는 실제 피해가 발생한 시전에 한해 기존 `PixelHaetaeThunder.ImpactClip`을 강도 0.35로 한 번 재사용한다. 메아리는 기본 뒤집기·착지음을 강도 0.55로 사용한다. 질량 강탈의 주 대상 평타 Hit·크리티컬은 기존 공통음을 유지하고 주변 범위 피해의 기본 Impact는 생략한다.

천공 뒤집기·압살은 실제 애니메이션의 동작 시계를 따라가므로 빙결 시 다음 단계 소리도 지연된다. 무중력 유지음은 낙하 시작·시전자 사망·전투 세대 변경·정리 시 중단한다. 같은 시전자의 무중력 영역이 겹치면 하나의 유지음을 공유하고 마지막 부유 영역이 끝날 때 끊는다. 천지전복은 대상이 전부 면역이면 소리가 없고 취소되어 착지하지 않은 대상에는 착지음이 없다.

일반 공격·크리티컬·사망 공통음, 스킬 수치와 Google DB는 변경하지 않았다.

## 음원 준비

Unity AudioClip.GetData로 원본 파형을 읽었다. MP3는 48 kHz stereo·0.528초, WAV는 44.1 kHz stereo이며 휩쓸기 1.333초·급강하 2.667초·전복 5.333초다. 원본 14개는 서로 다른 내용이다.

적용본은 48 kHz stereo 16-bit PCM·DecompressOnLoad·Preload로 맞췄다. 시작 여백과 후반 무음을 정리하고 동작에 맞춰 길이·피크를 조절했다. 시작 1 ms, 끝 MP3 기반 15 ms·WAV 기반 30 ms 페이드. 전복 끝은 60 ms, 유지음 끝은 짧은 루프를 위해 3 ms다. 피치는 바꾸지 않았다.

길이: Prepare 0.28초, Flip/Land 각 0.27초, Empower/Sweep 각 0.30초, Jump 0.24초, Dive 0.15초, Crush 0.38초, Lift 0.40초, Hover 0.44초, GravityLand 약 0.206초, Warning 0.35초, Overturn 0.80초, OverturnLand 0.40초.

이는 파형 측정과 재생 이벤트 검증이며 직접 청취에 의한 최종 청감 평가는 아니다. 원본 해시·가공 수치와 재현 코드는 `Logs/BeetleAudioReview/prepared.json`, `decoded.txt`, `prepare.py`에 보관한다.
