# 닌자 고양이 4등급 — 인법·삼중 바꿔치기

## 후속 수정 및 Google 반영 완료

- 같은 공격자에게 두 번째부터 제자리에서 반격하던 오류 수정. `RotateUnit`이 스프라이트 표시/모델을 회전시켜도 `facingDirection`은 3D 랩터의 회전 보조 컴포넌트가 있을 때만 갱신하고 있었다. 공용 회전 함수에서 모든 유닛의 전투 방향을 갱신하도록 수정했다. 착지 계산과 충돌 검사는 유지한다.
- 같은 적이 매번 닌자를 향해 돌아서는 회귀 검사(정면/73도)에서 수정 전 실패를 확인했다. 수정 후 닌자/초월/늑대 관련 **101/101** 통과: `fac6f1c13b364f4a954c49fc4090cf97`.
- 실제 일반공격 애니메이션으로 같은 공격자에게 3회 연속 반격: 착지 X **+1.382 → -1.382 → +1.382**, 각각 120 피해. 초기 스킬 후 적 HP 9580→9460→9340→9220. 네 번째 일반공격 정상 피해. `SameAttacker/` 438프레임 및 2·3번째 반격 화면 확인. 콘솔 오류·경고 0, Edit 모드/정상 시간 복원.
- 사용자 명시 승인 후 기존 Google DB **9셀 반영·재검증 완료**. 이름·설명·한영 번역·버전 2가 로컬과 일치한다. 주변·헤더 86셀 값, 총 95셀 서식/검증/노트 보존. 두 시트 100% 배율 표시 확인.
- 이전 자동 승인 차단은 해결되었다. `google-approved-*.json`이 최종 동기화 근거다.

## 구현 완료

- 기존 무한 암살을 교체했다. 기본/3등급 스킬의 회수 동작까지 끝난 뒤 **5초·3회**를 준비한다. 기존 특성 ID `trait_transcend_ninja_cat_infinite_assassination`은 저장 호환성을 위해 유지한다.
- 일반공격 적중 시 1회를 소모해 그 공격을 회피한다. 즉시 소실 → 0.08초 뒤 통나무 → 0.22초 뒤 공격자 후방 등장 → 0.30초에 실제 SkillAttack 타격 프레임으로 **120% ATK** 반격 → 약 0.51초에 동작 종료. 이후 공격자를 대상으로 유지한다.
- 발동 간격 **0.7초**. 반격에는 일반공격·스킬 시전·연쇄 바꿔치기 판정을 부여하지 않는다. 기존 기본공격 추가 80% 순간이동 효과는 제거했다.
- 회피한 한 공격만 무효화한다. 반격 중 별도의 대상 지정 불가를 부여하지 않아 다른 일반공격, 스킬, 지속 피해는 정상 적용된다. 보호막을 소모해 대신 막는 방식이 아니다.
- 스킬/반격 도중, 빙결·속박·쓰러짐·공중·강제이동·공포 상태, 안전한 후방 착지 공간이 없는 경우 발동하지 않는다. 공격자 소실·시전자 사망·동작 중단·강제 위치 변경·전투 종료 시 남은 반격을 취소한다.
- 재시전은 스킬 종료 후 최대 3회/5초로 갱신한다. 기존 발동 간격은 초기화하지 않는다.

## 연출

- 16×24 Point 필터 두루마리 3개가 120도 간격, 초당 70도 속도로 낮은 타원 궤도를 돈다. 작은 양피지·보라색 인법 문양이며, 앞/뒤 절반에 맞춰 캐릭터보다 앞/뒤로 그린다.
- 소모 시 해당 두루마리 하나만 즉시 숨긴다. 문양 점멸·펼침·추가 섬광은 없다. 시간 만료 때 남은 두루마리만 0.28초 동안 옅어지고 작은 픽셀로 흩어진다.
- 통나무는 승인된 기존 도트 원본을 좌우로 나눠 짧게 벌어지고 회전하며 사라지게 했다. 기존 연막과 후방 등장·타격 효과를 사용한다.
- 캐릭터별 기존 스프라이트 크기와 3등급 특성 동작은 유지한다.
