기존 GameAudio 풀과 공격자·클립·프레임별 중복 제한을 사용한다. hit/rushhit/spectralhit/alphahit는 Impact(0.32), 나머지는 Cast(0.24) 게인에 이벤트 강도와 사용자 효과음 볼륨을 곱한다. 동일 프레임의 돌진·접촉처럼 서로 다른 클립은 함께 재생된다. 짧은 연타를 막는 Periodic 채널은 사용하지 않는다.

늑대 스킬에는 피해 대상별 공통 스킬 Impact를 더하지 않는다. 일반 공격·크리티컬·사망음은 기존 공통 경로를 유지한다. 월식의 군체 종료는 피해 없는 소멸 연출이며 별도 소리를 추가하지 않았다. 스킬 수치·판정·연출은 변경하지 않았다.

## 음원 준비

Unity AudioClip.GetData로 디코딩해 파형을 분석했다. 앞 여백 약 44 ms를 제거하고 시작 1 ms·끝 15 ms 페이드를 적용했다. 짧은 돌진·협공은 꼬리를 정리했다. 원본 음높이는 1.0으로 유지한다.

| 파일 | 길이 | 피크 상한 |
|---|---:|---:|
| dash | 0.160초 | 0.46 |
| hit | 0.140초 | 0.60 |
| rush | 0.376초 | 0.54 |
| rushhit | 0.160초 | 0.66 |
| formation | 0.380초 | 0.48 |
| spectralhit | 0.360초 | 0.76 |
| companion | 0.360초 | 0.46 |
| alpha | 0.426초 | 0.60 |
| alphahit | 0.180초 | 0.58 |

만월 협공 원본의 피크는 약 0.132여서 적용본에서 약 4.39배로 정규화했다. 이는 파형에 근거한 조정이며 직접 청취에 의한 최종 음색·음량 검증은 아니다. 원본 9개는 서로 다른 해시이며, 가공 후에도 원본 SHA-256이 모두 일치한다.

## 검증

- CombatAudioTests·WolfHuntEffectTests·WolfPackRushTests·WolfSpectralCircleTests·WolfAlphaHuntTests: 96/96 통과. 리소스 로딩·파형·기존 계열·쇄도 범위·동시 타격·분신 협공·만월 횟수/취소를 포함한다.
- 격리 Play 모드 10경로 통과: 기본, 무리 쇄도, 천랑백귀, 월식의 군체, 만월의 알파, 시전 준비 취소, 천랑 준비 취소, 월식 협공 중 사망, 만월 분신 공격 전 사망, 만월 재시전으로 이전 분신 취소.
- 실제 스프라이트 시전 콜백·코루틴·분신 공격 프레임을 실행하고 오디오 풀의 클립·재생 시각·횟수를 관찰했다. 테스트 전투의 AI만 일시정지하고 격리 유닛 목록으로 교체한 뒤 복원했다. 만월 협공은 아군이 다른 적에게 가한 실제 일반 공격 피해 경로로 유발했다. 월식 지속시간은 QA에서 직접 감소시킨 뒤 기존 종료 함수를 호출했다.
- 기본 타격 0.229/0.413/0.596초. 무리 쇄도는 첫 접촉의 적 3명에 관통음 한 번, 뒤쪽 적에 한 번.
- 천랑백귀 형성 0.000초 → 쇄도 0.385초 → 일제 접촉음 0.449초 한 번.
- 월식 동행 0.593초, 협공 1.490/1.553초. 첫 협공 후 사망하면 두 번째 소리 없음. 자연 소멸에는 추가 소리 없음.
- 만월 협공 1.314/1.869/2.414/2.962/3.513/4.065초. 일곱 번째 아군 공격에는 횟수 소진으로 분신 타격음 없음. 만월 재시전은 새 발동음만 나고 이전 분신 타격음은 취소됨.
- 원본 보존과 적용본 9개의 PCM/DecompressOnLoad/Preload 설정 확인. 작업 전 상태인 CombatEffectTest 씬 Edit 모드로 복귀.
