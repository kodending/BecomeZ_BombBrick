# SR-01 저장 손상 감지·복구 — 완료

## 변경 결과

- 새 프로필은 원본·백업이 실제로 없고 복구용 임시/마이그레이션 파일도 없는 경우에만 생성한다.
- JSON 문법과 필수 필드, 버전, 몬스터 식별자를 확인한다. 빈 파일·빈 객체·중복 필드 등을 정상 저장으로 취급하지 않는다.
- 손상된 원본에 정상 백업이 있으면 원본을 `player_profile.unreadable.<UTC>.<GUID>.json`으로 보존하고 복구한다. 정상 백업을 손상 원본으로 덮어쓰지 않는다.
- 원본·백업 모두 손상됐거나 파일 접근 오류/더 최신 저장 버전이면 로드를 중단한다. 로드에 실패한 Store의 후속 Save도 성공적으로 다시 불러올 때까지 차단한다.
- 마을·전투·결과 화면에서 같은 로드 안내를 사용한다. 실패 시 재시도·저장 폴더 열기·메인 복귀를 제공하고 게임 입력/진행을 차단한다. 복구 성공 시 백업 이후 진행이 없을 수 있음을 안내한다.
- 한국어/영어 안내 7개를 로컬 번역 DB와 `Localization_Master!A1561:I1567`에 동일하게 반영했다.
