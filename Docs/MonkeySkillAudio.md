2026-10-24 변경: 4등급은 근두운 대신 **천상뇌우**를 사용한다. 현재 전투 수치는 **4초 안에 불규칙한 간격으로 낙뢰 4회**이며, 낙하 시각은 시전마다 새로 뽑아 해당 시전 동안 고정한다. 첫 낙뢰는 뇌우 시작 0.8초 이후이고 낙뢰 사이에는 최소 0.7초 간격이 있다. 최초 무대에서 소환음 1회와 해태 낙뢰음을 재사용하며, 실제 전장은 낙뢰마다 한 번, 총 4회 타격음과 전체 섬광·카메라 진동을 낸다. 각 낙뢰는 공격력 500% 피해·기절 1초이며 동일 적 기절 재적용 간격은 모든 뇌우를 합쳐 최소 1.2초다. 네 발 모두 적 위치를 우선 겨냥한다. 시전자 사망에도 소환된 뇌우의 소리는 계속되고, 전투 결과 이후에는 이미 재생 중인 소리가 자연스럽게 끝난다. 아래 근두운 항목은 이전 구현 기록이다.

기존 GameAudio 풀·볼륨 설정·적군 음소거 설정을 공유한다. Throw/Fall/Spin/Return/Summon/Dash는 Cast, 나머지는 Impact이며 원본 피치 1.0이다. 근두운의 세 번 시전은 선택한 기본/3등급 사운드를 그대로 사용한다. 이동음은 반복 루프 없이 가속 구간에서만 재생한다.

원숭이의 대상별 공통 스킬 Impact를 제외하고 실제 접촉 콜백에 음원을 연결했다. 광역 폭발·바운드가 대상 수만큼 중복 재생되지 않는다. 기본공격·크리티컬·일반 사망은 기존 공통 사운드를 사용한다. 스킬 수치·판정·이동·피해 시점은 변경하지 않았다.

낙하와 귀환은 기존 시각 효과의 전투 시계를 사용한다. 낙하 이전에 바람으로 튕겨 나간 열매는 이후 낙하/착탄 소리를 내지 않으며, 귀환 전에 튕겨 나간 바나나는 귀환 소리를 내지 않는다. 효과 완료/취소 시 추가 콜백도 정리한다.

## 음원 준비

Unity AudioClip.GetData로 원본을 읽고 48 kHz stereo 16-bit PCM 적용본을 만들었다. DecompressOnLoad·Preload, 무손실 PCM 임포트다. 원본 12개는 서로 다른 내용이며 변경하지 않았다.

앞 여백 약 43.6~44.8 ms를 제거하고 피크를 맞췄다. 시작 1 ms·끝 15 ms 페이드로 경계를 정리했다. 바운드는 원본 피크가 작아 약 11.1배 정규화했다. 아래는 파형 분석에 근거한 조정이며 직접 청취에 의한 음색 평가는 아니다.
