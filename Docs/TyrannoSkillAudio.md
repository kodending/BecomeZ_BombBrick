## 음원 준비

원본을 Unity AudioClip.GetData로 읽었다. WAV는 44.1/48 kHz stereo, MP3는 48 kHz stereo였다. 적용본은 모두 48 kHz stereo 16-bit PCM, DecompressOnLoad·Preload이며 44.1 kHz 소스는 길이·피치를 유지하여 업샘플링했다.

기본 내려찍기와 대멸종 충격은 원본 SHA-256이 동일하다. 원본 파일 10개 중 서로 다른 내용은 9개다. 대멸종 적용본의 음량·여운을 더 키우고 별도 확산음과 조합한다. 준비된 원본 10개는 가공 후에도 해시가 모두 일치한다.

짧은 MP3의 앞 여백은 약 44~46 ms를 제거했다. 물기는 약 36 ms, 전장 짓밟기는 약 26 ms를 제거했고 즉시 소리가 시작되는 기본/대멸종 WAV는 앞부분을 유지했다. 시작 1 ms 페이드, 짧은 음원 끝 15 ms·긴 충격음 끝 70 ms 페이드다. 긴 WAV는 50 ms 구간의 최대 RMS도 제한하여 밀도가 높은 전장 짓밟기가 나머지 소리를 압도하지 않도록 했다.
