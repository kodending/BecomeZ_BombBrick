# 지역 순환 피해 상성

기존 출현 풀을 몬스터의 출신 지역으로 사용한다. 순환 순서는 태초의 초원 → 독안개 습지 → 붉은 밀림 → 얼어붙은 고원 → 천공 성역 → 태초의 초원이다.

| 몬스터 출신 지역 | 유리한 맵 · 피해 ×1.2 | 불리한 맵 · 피해 ×0.8 |
|---|---|---|
| 태초의 초원 | 독안개 습지 | 천공 성역 |
| 독안개 습지 | 붉은 밀림 | 태초의 초원 |
| 붉은 밀림 | 얼어붙은 고원 | 독안개 습지 |
| 얼어붙은 고원 | 천공 성역 | 붉은 밀림 |
| 천공 성역 | 태초의 초원 | 얼어붙은 고원 |

출신 맵과 나머지 두 맵은 중립 ×1.0이다. 아군과 적군에 같은 규칙을 적용하며 대상 몬스터의 출신 지역은 배율에 영향을 주지 않는다.

평타, 스킬, 체력·방어력 기반 추가 피해, 일반 고정 피해, 몬스터가 부여한 지속 피해에 최종 피해 배율을 한 번 적용한다. 회복·보호막·공격력 수치는 변경하지 않는다. 이미 확정된 체력 손실을 전달하는 피해와 환경 독은 추가 증폭하지 않는다.

배율은 Expedition_Config_Master의 region_affinity_strong_damage_percent=120, region_affinity_weak_damage_percent=80에서 읽는다. 준비 화면은 현재 맵에서 유리·불리한 출신 지역을 표시하고, 아군·적 정보창은 개체의 현재 맵 상성을 한영으로 표시한다.

유리한 몬스터는 체력바 왼쪽에 녹색 위쪽 화살표, 불리한 몬스터는 빨간 아래쪽 화살표를 표시한다. 중립은 체력바 아이콘을 표시하지 않는다. 마을의 탐험덱·보유 몬스터 목록에는 선택한 맵 기준의 아이콘과 ×1.2/×0.8/×1.0을 표시한다. 진행 중인 원정은 해당 원정 맵을 기준으로 한다.

새 게임과 시작 동료의 전체 다시 뽑기에서는 8종을 중복 없이 새로 추첨한다. 기본 6마리의 기존 평균 B−~B+·이로치 없음 규칙과 추가 2마리의 기존 능력치·이로치 추첨 규칙은 유지한다. 이미 저장된 동료는 불러오기로 다시 추첨하지 않는다.
