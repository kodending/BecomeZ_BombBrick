# 기본공격 Hit 기준 전투 사운드 믹싱

2026-09-29 갱신: 선택 음원 177개를 새 적용본으로 교체하고, 같은 공통 믹서를 통해 205개 전체의 음량·재생 연결을 다시 확인했다. 기존 28개와 사망음은 사용자 지시로 보존했다. 현재 교체/검증 기록은 `Docs/CombatSoundReplacement_2026-09-29.md` 및 `Logs/AudioReplacement_2026-09-29/`를 기준으로 한다. 아래 수치와 파일 보존 설명은 2026-09-25 최초 믹싱 당시 기록이다.

2026-09-25. 기본공격 Hit의 기존 단독 음량을 기준으로 20계열 스킬 205개와 크리티컬·사망·기존 낙뢰/보조음을 공통 GameAudio 경로에서 조율했다. 선택 음원·가공 WAV·재생 길이·피치·발동 시점은 변경하지 않았다. 사용자 효과음/마스터 설정과 BGM/UI 음량도 변경하지 않았다.

## 기준과 보정

기준은 `Audio/Combat/Feedback/basic_hit.wav`: peak 0.779968, 최대 50ms RMS 0.281187, 재생 gain 0.28. 단독 재생과 effectsVolume=1에서 출력 RMS 기준은 약 0.078732이다.

각 클립의 가장 큰 50ms 구간의 RMS를 기준 Hit에 맞춘다. 좌우 채널의 에너지를 평균하므로 역위상 스테레오를 조용한 소리로 잘못 판단하지 않는다. 희소한 짧은 피크를 지나치게 올리지 않도록 정규화 단계에서 기준 피크의 1.35배를 상한으로 둔다. 무음이나 PCM 읽기 실패는 기존 gain으로 안전하게 돌아간다. 이 측정은 짧은 효과음 레벨 비교이며 LUFS나 직접 청취 평가가 아니다.

클립당 PCM 분석은 최초 사용 한 번이고 이후에는 캐시를 사용한다. 전투 중 매번 파형을 읽거나 소리를 새로 생성하지 않는다. 원본이나 적용본 파일에 파괴적인 정규화를 하지 않아 음원을 교체하면 새 파형을 기준으로 다시 계산된다.

| 재생 종류 | 기본 gain | 기준 Hit 대비 최대 50ms RMS, strength=1 |
|---|---:|---:|
| 기본 Hit | 0.28 유지 | 100% |
| 일반 스킬 준비·발사 | 0.20 | 약 71%, -2.92dB |
| 스킬 접촉·폭발 | 0.30 | 약 107%, +0.60dB |
| 반복 보조음 | 0.12 | 약 43%, -7.36dB |
| 루프 유지음 | 0.11 | 약 39%, -8.12dB |
| 크리티컬 | 0.30 × 기존 strength 1.25 | 약 134%, +2.54dB |
| 사망 | 0.30 × 기존 strength 1.15 | 약 123%, +1.81dB |

피크 상한에 걸리는 음원은 위 값보다 조용하며, 각 스킬의 기존 strength·복제체 감쇠·보조음 감쇠는 계속 적용된다. 강한 스킬과 작은 잔상음을 똑같이 만들지 않는다. 크리티컬의 기존 pitch 변주와 사망음의 시작 샘플 2027은 유지한다.

## 동시 재생

기존 12개 음성 풀과 평타 6개 제한, 대상별 중복 방지 규칙은 유지한다. 동시에 재생 중인 전투음의 보정 gain × 파형 최대치 합이 0.85를 넘으면 전체 전투음만 비례 감쇠한다. 감소는 즉시, 복귀는 초당 gain 3의 속도로 완만하게 진행한다. 단독 평타는 감쇠하지 않고, 큰 묶음이 끝나면 기존 단독 음량으로 복귀한다. 이는 각 클립의 전체 피크를 사용하는 보수적인 전투음 상한이며 BGM/UI까지 합친 최종 출력 리미터는 아니다.

효과음 설정은 보정·합산 감쇠 이후에 적용된다. 일시정지 중에는 감쇠 계수도 유지한다. 설정 변경 시 보조 레이어에도 같은 볼륨을 적용한다. 새로 소리를 생략하거나 게임 난수를 소비하지 않는다.

## 측정 결과

기본 참조를 포함해 실제 PCM 211개를 읽었다. 동일 강도 1, 각 클립의 실제 재생 채널 기준으로:

- 접촉/폭발 82개: 이전 -9.10~+7.35dB → -4.39~+0.60dB. 중앙값 +0.60dB.
- 준비/발사 105개: 이전 -18.76~+3.18dB → -13.33~-2.92dB. 중앙값 -2.92dB.
- 반복 보조 13개: 이전 -15.19~-3.78dB → -10.11~-7.36dB. 중앙값 -7.36dB.
- 유지 루프 5개: 검치 당김·장풍 부유·그리폰 역풍·와이번 기본/용핵 분사, 모두 strength=1에서 약 -8.12dB.
- 대표 감소량: 장풍 압살 -6.75dB, 와이번 기본 분사 -6.75dB, 그리폰 날개 -6.10dB, 코가손 반격 -5.45dB, 그리폰 태풍 착지 -4.92dB. 실제 장면에서는 기존 strength와 동시 재생 감쇠가 추가된다.
- 211개 중 47개는 희소 피크 때문에 RMS 목표보다 피크 상한을 우선한다. 작은 준비음의 노이즈와 짧은 클릭을 무리하게 증폭하지 않기 위한 선택이다.
